## 1. 지역별 BGM 무드 맵

무드는 도시·권역별로 정의하되, **소싱 곡은 무드가 근접한 지역끼리 공유**할 수 있다(공유 계획은 5장). 템포감은 칩튠 기준 대략치(BPM)이며 소싱 시 허용 범위로 취급한다.

### 1-1. 왕도 + 도시 9 (worldview 6.4 연동)

| 정주지 | 무드 키워드 | 템포감 | 참고 스타일 (칩튠 전제) |
|---|---|---|---|
| **브란텔** (왕도) | 장엄, 권위, 차가운 질서 | 느림~보통 (80~100) | 궁정 행진곡풍 — 사각파 금관 팡파레 + 규칙적 저음 진행. 화려하되 "환영하지 않는" 위압감 한 스푼 |
| **그란시아** (곡창·문벌파) | 우아, 화려, 배타적 | 느림 (70~90) | 왈츠(3박자)풍 궁정 무곡 — 왕도 곡과 같은 계열이되 더 장식적. 아름답지만 거리감 있게 |
| **아르셀** (학술·호반) | 차분, 지적, 잔잔한 물결 | 느림 (60~80) | 서정적 아르페지오 — 삼각파 위주의 조용한 반복 악구, 도서관의 정적 |
| **살레노** (항구·상업) | 활기, 흥정, 뱃노래 | 빠름 (120~140) | 셔플 리듬 뱃노래/호른파이프풍 — 6/8박 또는 스윙, 왕국에서 가장 명랑한 곡 |
| **오란세** (순례·치유) | 평온, 성스러움, 포용 | 아주 느림 (50~70) | 성가풍 — 긴 지속음(사인/삼각파 오르간)과 단순한 선율. 종소리 모티프 |
| **미스란** (엘프 접경 교역) | 신비, 이국, 숲의 문턱 | 느림~보통 (80~100) | 펜타토닉/도리안 선법 선율 — 인간 도시 곡과 음계 자체를 다르게. 시안 발광(감응)의 소리 번역 |
| **두르간** (광산·드워프) | 묵직, 노동, 긍지 | 보통 (90~110) | 드워프 노동요풍 — 저음 사각파 리프 + 망치질 같은 강박 퍼커션. 용광로의 온기 |
| **하프나** (어항·냉해) | 무뚝뚝, 억셈, 겨울 바다 | 보통 (90~110) | 단조 뱃노래 — 살레노의 명랑함을 뺀 북구풍. 거친 파도의 반복 리듬 |
| **발크렌** (요새·군사) | 긴장, 규율, 흉터 | 보통 (100~120) | 군가/진군풍 — 스네어성 노이즈 퍼커션 + 단조 금관 모티프. 평시인데도 경계가 풀리지 않는 톤 |
| **노베라** (자유 개척·주 거점) | 활기, 희망, 어수선한 젊음 | 보통~빠름 (110~130) | 밝은 장조 컨트리/포크풍 — 플레이어가 가장 오래 듣는 "집" 같은 곡. 게임의 밝음 6을 대표 |
| *(카엘론 — 하사 도시)* | 재건, 회복, 조용한 긍지 | 느림→보통 | 노베라 곡의 모티프를 공유하는 느린 변주 — 영지 성장(재건 진행)에 따라 밝은 버전으로 교체하는 2단계 구성 제안 |

- 마을·부락(여울목, 잿골 등)은 개별 곡 없이 **권역 평화 곡 1종 공유** (소박한 목가풍). 하사 정주지(여울목→잿골→카엘론)만 성장 연출상 카엘론 계열 곡을 공유.

### 1-2. 필드 권역 (world-structure 1-1 연동, STYLE_GUIDE 4장 색조와 짝)

| 권역 (밴드) | 무드 키워드 | 템포감 | 참고 스타일 |
|---|---|---|---|
| 동부 변경 남측 (1~20) — 시작 지역 | 개척, 새싹, 모험의 첫걸음 | 보통 (100~120) | 밝은 장조 필드곡 — 게임의 첫인상. 황토 위 초록(재건)의 소리 |
| 중부 왕령 (18~27) | 목가, 평야, 정돈 | 느림~보통 (80~100) | 넓은 들판풍 — 여유로운 선율, 안전 지대의 소리 |
| 남부 해안·구릉 (25~35) | 볕, 파도, 여행 | 보통~빠름 (110~130) | 해안 필드곡 — 살레노 도시 곡과 같은 계열의 야외판 |
| 서부 실비엔 대수림 (33~47) | 깊은 숲, 오래된 것, 경외 | 느림 (60~85) | 신비 선법 + 앰비언트 성분 — 외곽은 신비, 심부(제단)는 성역의 정적. 미스란 곡과 모티프 공유 |
| 북부 강철산맥 (42~58) | 한랭, 바위, 고도 | 느림~보통 (75~95) | 한랭 필드곡 — 회청 팔레트의 소리. 갱도/카른두름 구간은 두르간 모티프의 어두운 변주 |
| 동부 변경 북측 — 옛 전선·재의 평원 (58~78) | 폐허, 상실, 그럼에도 전진 | 느림 (70~90) | 단조 필드곡 — 어둠 4의 주 무대. 어둡되 호러가 아닌 "침울" (STYLE_GUIDE 5장 원칙의 오디오판). 낮은 지속음 + 드문 선율 |
| **균열 지대·악마 세력권** (78~96) | 오염, 이질, 지성 있는 적의 | 느림 + 불규칙 (60~80) | 불협화 아르페지오 + 반음계 모티프 — 암자색(#68386c) 발광의 소리. 악마 = "갈증"이므로 공포보다 **공허·갈망**의 톤 |
| 심연 회랑 (95~100, 엔드게임) | 이계, 최심부, 정적과 압박 | 아주 느림 (50~70) | 미니멀 다크 앰비언트 칩튠 — 선율을 거의 지우고 저음 펄스와 잔향 위주 |

- **소균열 던전(전 권역 재사용)**: 균열 지대 곡의 짧은 변주 1곡을 공용 던전 곡으로 사용 — 저레벨부터 "균열 = 이 소리"라는 청각 기호를 학습시켜 후반 악마 세력권 곡이 그 확장으로 들리게 한다.

### 2-2. 주야간 변주 정책 (확정 제안)

30분=1일, 야간 몬스터 ×1.2 시스템의 청각 신호. **원칙: "별도 곡"이 아니라 "같은 곡의 야간 처리"** — CC0 소싱으로는 곡마다 야간 편곡본을 구할 수 없으므로, Godot 오디오 버스 이펙트로 런타임 변주한다.

| 지역 등급 (world-structure 5장) | 야간 정책 |
|---|---|
| 안전 지대 (도시·마을·가도) | 같은 곡 유지 + BGM 버스 로우패스 필터(컷오프 22kHz→약 6kHz) + 볼륨 −4dB — "거리가 조용해진" 느낌 |
| 일반 필드 | 위와 동일 처리 (몬스터 강화의 은근한 신호) |
| **야간 활성 지역** (균열 외곽, 대수림, 옛 전선) | 로우패스 처리 대신 **야간 공용 필드 곡 1곡으로 교체** — 낮은 템포·단조의 "밤 사냥" 전용 곡. 위험 상승을 명확히 알린다 |
| **야간 전용 출몰 지역** (재의 평원 — 망령·오염 기사) | 야간 공용 곡의 어두운 변주 또는 동일 곡 + 앰비언트 SFX(바람·속삭임 노이즈) 레이어 강화 |

- 즉 야간용 **추가 곡은 1~2곡**만 소싱하면 된다 (전 지역 야간 편곡 대비 물량 최소화).
- 황혼/새벽 보간: STYLE_GUIDE 5-1의 CanvasModulate 보간 구간(게임 1시간)에 맞춰 로우패스 컷오프·볼륨을 **선형 보간** — 화면과 소리가 같은 속도로 저물게 한다. → tech-artist·systems-dev 연계.

## 3. 전환 규칙 (systems-dev 구현 기준)

### 3-1. 오디오 버스 구조

```
Master
 ├─ BGM   (야간 로우패스 이펙트는 이 버스에 장착, 평시 비활성)
 ├─ SFX   (전투·환경)
 └─ UI    (메뉴·시스템음 — 일시정지 화면에서도 재생되도록 분리)
```
- 옵션 메뉴 볼륨 슬라이더는 버스 단위 3종(BGM/SFX/UI) + Master. 기본값 0dB, 저장은 세이브와 별도의 설정 파일.

### 3-2. 전환 수치표

| 상황 | 규칙 |
|---|---|
| **지역 경계 (씬 전환)** | 나가는 곡 0.8초 페이드아웃 → 로딩 → 새 곡 0.8초 페이드인. **같은 트랙 ID면 전환하지 않고 이어서 재생** (권역 공유 곡 — 도시↔인근 필드 왕복 피로 방지) |
| **일반(잡몹) 교전** | **BGM 전환 없음** — 필드 곡 유지. 250시간 플레이에서 교전마다 곡이 바뀌면 피로가 크므로, 잡몹 긴장감은 SFX(예고 경고음·타격음)가 담당 |
| **전투 곡(S4) 트리거** | 정예 몬스터 조우 / 스크립트 무리 전투(방어전 등) / 퀘스트 지정 전투에서만: 필드 곡 0.3초 페이드아웃 → 전투 곡 0.5초 페이드인 |
| **전투 이탈·종료** | 종료 판정(대상 전멸 또는 어그로 해제 후 5초) → 전투 곡 1.5초 페이드아웃 + 필드 곡 1.5초 페이드인 (크로스페이드). 필드 곡은 **중단 지점에서 재개(resume)** — 처음부터 다시 틀지 않는다 |
| **보스전 인트로** | 보스 등장 연출 시작 시 기존 곡 0.3초 컷 → **인트로 스팅어(논루프 2~4초) → 루프 본편 무음 갭 없이 연결**. Godot 4의 `AudioStreamInteractive` 또는 스팅어 종료 시각에 본편 큐 방식 — 구현 방식은 systems-dev 선택 |
| **보스 격파** | 보스 곡 0.2초 컷 → 승리 스팅어(SFX 취급) → 3초 무음 후 필드 곡 페이드인 2초 |
| **최종전(S6→S7)** | 전쟁 페이즈 종료 컷신에서 S6 2초 페이드아웃 → 보스 인트로 규칙으로 S7 진입 |
| **워프** | 출발 0.5초 페이드아웃 → 도착 도시 곡 0.8초 페이드인 |
| **주야간** | 2-2 보간 규칙 (곡 전환이 필요한 야간 활성 지역은 크로스페이드 2초) |
| **컷신·대화 곡(S8/S9)** | 진입 1초 크로스페이드, 종료 시 원곡 resume |

- 공통 원칙: **모든 페이드는 dB 선형이 아닌 에너지 선형(등파워) 크로스페이드**로 구현 권장 — 교차 구간 볼륨 꺼짐 방지.
- 루프 규격: 소싱 곡은 심리스 루프 여부를 확인하고, 루프가 안 되는 곡은 Godot 임포트에서 루프 지점 설정 또는 편집으로 보정한다 (M2 작업).

## 4. SFX 카테고리 목록 (numpy 합성 골격)

전 파일 공통: 44100Hz / 16bit / 모노 WAV, `godot\assets\audio\sfx\`, 생성 스크립트는 `godot\assets\tools\`에 보존. 파일명 `sfx_<카테고리>_<이름>.wav`.

### 4-1. 전투 — 직업 10계열 타격감 구분 (jobs.md 2장 전용 무기 기준)

원칙: 계열 차별화는 이펙트와 마찬가지로 **색(음색·주파수 대역·리듬)으로 구분**한다. 기본 공격 타격음 + 스킬 시전음을 계열당 최소 2종.

| 계열 (무기) | 합성 방향 |
|---|---|
| 전사 (대검) | 저역 사각파 임팩트 + 노이즈 버스트, 피치 하강 스윕 — 묵직하고 느린 "쿵" |
| 기사 (한손검+방패) | 중역 금속성(사각파+짧은 링) — 가드 성공은 고역 금속 "챙", 저스트 가드는 별도 반짝임 톤 |
| 도적 (쌍단검) | 고역 노이즈 슬래시 극단타(≤80ms) — 2연타 리듬이 핵심 |
| 궁수 (활) | 시위 튕김(고역 플럭) → 화살 비행(노이즈 스윕) → 적중 3단 분리 |
| 마법사 (지팡이) | 삼각/사인파 상승 스윕(캐스팅) + 발사 펄스 — 원소별 피치 변형 |
| 소환사 (마도서) | 벨 톤(사인 배음 중첩) 소환음 + 지휘 지정 신호음. 환수 타격은 야수 계열 공용음 |
| 창술사 (창) | 짧은 노이즈 휘두름 스윕 + 고역 찌르기 임팩트 — 도적보다 길고 전사보다 가볍게 |
| 격투가 (너클) | 초단타 저역 펀치(50~60ms) — 연타 리듬감, 오의는 연속 펄스 |
| 룬각인사 (룬해머) | 금속 타격 + 전자적 룬 가동음(짧은 아르페지오 비프) — 장치 설치/기동/회수 3종 |
| 감응자 (정령석) | 스탠스별 3계열 — 불(노이즈 크래클), 바람(화이트노이즈 스윕), 물(사인 물방울). 스탠스 교대음 별도 |

**공통 전투음**: 플레이어 피격 / 몬스터 피격(히트스톱 약·중·강 3단 대응 3종 — combat.md·STYLE_GUIDE 6-2 짝) / 크리티컬 / 회피 대시 / **적 공격 예고 경고음**(텔레그래프 `#ff0044`의 청각판 — 이 음도 예고 전용, 다른 용도 금지) / 몬스터 사망(소형·중형·대형·보스 4종) / 그로기 진입 / 펫 스킬(버프·공격·디버프 3종).

### 4-2. UI

커서 이동 / 확인 / 취소 / 탭 전환 / 창 열기·닫기 / 장비 장착·해제 / 구매·판매(골드 소리) / 불가(오류) / 대화 진행 틱.

### 4-3. 시스템

레벨업 / 전직 팡파레 / 스킬 포인트 사용 / 퀘스트 수락 / 퀘스트 목표 갱신 / 퀘스트 완료 / **숨겨진 퀘스트 발동**(신비 톤 — 과장 금지) / 도감 등록 / 도감 섹션 완성 / 칭호 획득 / 명성 상승 / 승급(하사) 대팡파레 / 아이템 획득 — **등급별 변형 C/B/A/S 4종**(S는 황금 반짝임 톤) / 워프 발동·도착 / 세이브 완료 / 왕국 이벤트 발생 알림.

### 4-4. 환경

문 열기·닫기 / 상자 열기 / 채집(약초·광석 2종) / 모닥불 루프(체크포인트) / 발소리 4종(흙·돌·풀·눈) / 물가·파도 루프 / 바람 루프(고지·평원) / 균열 앰비언트 루프(오염 저음 험) / 워프 게이트 대기 험 / 주야 전환 신호(도시 종소리 — 저녁 종).

- **추정 총량: 약 75~85개.** M2 수직 슬라이스 필요분(전사 1직업 + 몬스터 3종 + 기본 UI/시스템)은 약 25개 — 상세 목록은 M2 착수 시 구현 순서에 맞춰 확정.
- 앰비언트 루프류(모닥불·바람·균열)도 노이즈 필터링으로 numpy 합성 가능 — BGM과 달리 소싱 불요.

## 5. CC0 BGM 소싱 계획

### 5-1. 소스와 라이선스 기준

| 순위 | 소스 | 기준 |
|---|---|---|
| 1 | **OpenGameArt.org** (라이선스 필터 CC0) | 칩튠 팩 다수 — 예: Juhani Junkala 'Retro Game Music Pack' 등 검증된 CC0 팩 우선 |
| 1 | **itch.io 무료 음원 팩** | 페이지별 라이선스 명시 확인 — "CC0" 또는 "상업적 사용 가능·크레딧 불요" 명문만 |
| 2 | **freesound.org** (CC0 필터) | 스팅어·짧은 소곡 보충용 |
| 보류 | CC-BY 음원 | 출처 표기로 사용 가능하나 채택 여부는 디렉터 결정(6장) — 승인 전까지 **CC0만** 사용 |

- 개인 프로젝트(배포 없음)지만 라이선스 기준은 배포 가능 수준으로 유지한다 — 추후 방침 변경에도 안전.
- 기록: 채택 곡마다 **출처·작곡자·라이선스·URL·용도(슬롯)**를 `docs\art\ASSET_SOURCES.md`에 기록. (스프라이트용 `godot\assets\CREDITS.md`와 별도 관리, 최종 통합 여부는 art-director와 협의)
- 저장 위치: `godot\assets\audio\bgm\`, 파일명 `bgm_<슬롯>_<이름>.ogg` (용량상 WAV 대신 OGG 권장 — 임포트 규격은 tech-artist와 협의).
