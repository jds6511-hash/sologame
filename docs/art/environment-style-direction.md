## 1. 목표와 경계

동부 변경을 **사람들이 폐허 위에서 다시 살아가는 아늑하고 촘촘한 탑다운 픽셀 월드**로 읽히게 한다. 16px 타일, EDG32, 기존 화면 배율을 유지하며 수선한 건물, 밭, 물가, 길가의 생활 흔적을 **동선의 가장자리에 묶어** 밀도를 만든다. 플레이어가 싸우거나 이동하는 중심면은 차분하게 남긴다. 다른 게임에서는 온기·생활감·밀도의 *원리*만 참고하고, 에셋·타일 패턴·건물 배치·화면 구도는 베끼거나 따라 그리지 않는다.

| 지금 채택 | 뒤로 미룸 |
|---|---|
| 여울목 한 구역의 원본 타일·건물·소품 파일럿; 지면과 길의 가장자리 변화; 물가·울타리·초목의 묶음 배치; 전투 시야 검증 | 전 지역 재타일링, 잿골·노베라 실제 맵 제작, 계절·날씨·실내·군중 연출, 전체 캐릭터 최종 리디자인 |

이 파일럿은 **M4 저장/불러오기 착수 순서를 바꾸지 않는 병행 아트 작업**이다. M5 NPC·퀘스트, M6 경제가 요구할 생활 오브젝트의 기능은 각 마일스톤에서 결정한다. 이번 범위는 시각 언어와 검증 가능한 배치 계획이다.

## 2. 환경의 풍부함과 전투의 우선순위

**풍부함의 목표**는 화면 전체에 무늬를 흩뿌리는 것이 아니다. 한 장소마다 재질·수선 흔적·생업을 보여주는 2~4개 요소를 묶고, 건물·길·물가가 함께 여울목의 생활을 설명하게 한다. 지면은 면적이 넓을수록 조용해야 하며, 차이는 색 노이즈보다 경계 형태와 소품 실루엣에서 만든다. `STYLE_GUIDE.md` 3-2-3절의 대면적 지면 `σ_L ≤ 10`, 초원 단색조 처방, 체커·흰색 금지, 물 예외와 6장의 색 위계를 그대로 따른다.

**전투 가독성의 보호선**은 장식보다 우선한다. 플레이어·적의 1px 외곽선, 투사체, 아이템 드롭, 공격 예고가 어떤 배경에서도 먼저 읽혀야 한다. 환경에는 적 예고 전용 `#ff0044`를 쓰지 않고, 여울목 물에는 스킬색 `#2ce8f5`를 쓰지 않는다. 배경의 작은 고채도 점이 드롭·투사체처럼 보이거나 높은 소품이 발·공격 범위를 가리면 배치 또는 색을 줄인다. 낮과 밤, 이동과 실제 교전 화면에서 함께 판정한다.

### 요소별 제작 규칙

| 요소 | 풍부함을 만드는 방법 | 읽힘·제작 제약 |
|---|---|---|
| 지면 타일 | 기존 `grass_*`, `dirt_*`, `stone_floor`, `tilled_soil`의 재질 정체성을 유지하고 가장자리·닳은 면을 소수 변형으로 확장 | 넓은 면에 규칙적 체커나 독립 고대비 점을 반복하지 않는다. 새 대면적 타일도 3-2-3절 검증 대상에 등록한다. |
| 길 | 노베라 방향 **2타일 도로**는 다져진 중심과 불규칙한 흙·풀 경계로 구분한다. 북쪽 오솔길은 좁고 거친 재질로 구분 | 도로 중앙의 장식은 최소화하고, 관문·갈림길·여울로 이어지는 선을 한눈에 따라갈 수 있게 한다. 장식으로 통행 폭을 줄이지 않는다. |
| 물 | 기존 `river_water`의 확정된 청색을 지키고 둑의 모서리, 얕은 여울, 드문 잔물결로 물가를 설명 | 현재 지도는 y=13~15의 **3행 물줄기**인 반면 가이드의 물 예외는 연속 폭 2타일 이하이다. 아트 적용 전에 실제 연속 수면 폭을 실측해 불일치를 해소한다. 단순히 3행 전체를 같은 물로 넓히거나 충돌을 바꾸지 않는다. |
| 초목 | 낮은 풀·관목·갈대를 군집으로 두고, 키 큰 나무/수관은 부락 외곽의 쉼터나 화면 테두리에 제한 | 전투 포켓·길·여울 입구에는 높은 수관과 진한 꽃무늬를 놓지 않는다. 꽃은 초원 타일의 기존 색/면적 제한을 따른다. |
| 소품 | 장작·수레 자국·바구니·물통처럼 생업이 드러나는 소품을 집 앞이나 밭 가장자리에 묶는다 | 1개씩 무작위 살포하지 않는다. NPC·드롭·상호작용 표시와 같은 크기·색의 가짜 신호를 만들지 않는다. |
| 건물 | 수선한 목조 집, 공동 작업/창고, 접수·쉼터의 **2~3개 실루엣**을 원본 디자인으로 만든다. 지붕 높이·벽 재질·문 위치로 용도를 구별한다 | 출입구와 우회 경로가 읽혀야 한다. 문 앞·광장 중앙·전투 구역에 지붕/간판이 캐릭터나 예고를 덮지 않는다. |
| 밀도 | 안전한 부락 안쪽과 길·물가의 가장자리는 촘촘하게, 관문 밖 교전면과 주요 통로는 성기게 한다 | 한 화면에서 먼저 길·출입구·전투 주체, 다음에 생활 소품이 보이도록 검수한다. 소품 수보다 **비어 있는 바닥의 연속성**이 우선이다. |

## 3. 지역별 차이

| 지역 | 환경 언어 | 현 단계 |
|---|---|---|
| **여울목** | 떠나기 전의 집. 밭·수선한 목재·낮은 돌담·공동 작업 흔적·여울을 묶어 가난하지만 돌보는 부락으로 만든다. 이후 복구권을 받을 장소이므로 시작부터 주민의 생활이 느껴져야 한다. | **유일한 파일럿 구현 대상**. 기존 48×36 시작 맵의 부락 안전 구역과 물가 일부에서 검증한다. |
| **잿골** | 옛 전선에 닿은 폐허를 되살리는 마을. 남은 석재·검댕 흔적과 새 목재·정돈된 재건 구획을 대비시켜, 여울목보다 무겁고 계획적인 복구를 보여준다. | 방향만 기록. 마을 하사 시점/맵 설계와 함께 별도 검증한다. |
| **노베라** | 새로 모인 개척자와 모험가의 활기. 동부 팔레트 중 가장 밝은 목재, 서로 다른 상점 정면, 깃발과 조합 표지를 사용하되 광장·주도로는 넓게 읽힌다. | 방향만 기록. M5 NPC·의뢰와 M6 경제 흐름에 맞춰 실제 배치를 설계한다. |

## 4. 여울목 1차 파일럿

**고정 입력:** [시작 맵](../design/levels/eastern-frontier-start-map.md)의 부락 x=2~17·y=22~33, 동문 x=17·y=27~29, 광장 x=6~13·y=25~31, 노베라 방향 도로 y=27~28, 여울 x=8~10을 출발점으로 한다. 기존 플레이어/NPC/몬스터 마커와 퀘스트 좌표를 옮기지 않는다. 현재 `eastern_frontier_tileset.json`은 4×4 아틀라스 16키, 시작 씬은 `Ground` `TileMapLayer` 하나이며 충돌 키는 `river_water`, `stone_wall`, `rock_small`이다. 부락 안쪽은 양쪽 밭과 광장이 이미 대부분을 차지한다. 건물 2종의 실제 배치 공간이 부족하면 **장식용 밭 면적만 조정**하고 광장·동문·마커·통행 폭은 지킨다. 아래는 **추가 제작 목표**이지 현재 구현 상태가 아니다.

| 제작 묶음 | 1차 산출 기준 |
|---|---|
| 지면 | 현행 초원·흙·석재 바닥을 기준으로 가장자리/닳은 면 변형 4~6타일. 새 키와 팔레트·대비 검증 범위를 매니페스트에 명시한다. |
| 길 | 2타일 주도로의 좌우 경계·꺾임과 오솔길 접점 4~6타일. 중앙은 차분한 흙으로 남긴다. |
| 건물 | 수선한 집, 작업/창고, 접수·쉼터 중 **2개 필수·3개째 선택**. 문과 주변 바닥을 포함한 서로 다른 실루엣의 다중 타일 원본 에셋. |
| 울타리 | 기존 `wood_fence`와 이어지는 직선·끝·모서리·문/빈틈 변형. 밭 경계에 집중한다. |
| 작은 소품 | 장작, 바구니, 물통, 상자, 작업대 등 5~7종. 한 작업 장소에 2~4종을 묶는다. |
| 물가 | 둑 직선·모서리·여울 접점과 절제된 잔물결. 기존 통행 가능한 여울과 물 충돌은 유지한다. 3행 수면과 2타일 예외의 충돌을 먼저 판정한다. |
| 초목 | 낮은 풀 2~3형, 관목 2형, 물가 갈대 1~2형, 외곽용 큰 실루엣 1형. 길·교전면에는 낮은 형만 쓴다. |

**제작 순서:** (1) 현재 여울목의 낮/밤·관문 밖 교전 화면을 기준 캡처하고 통로/스폰/퀘스트 지점을 표시한다. (2) 원본 타일·건물 실루엣을 4배율 정지 프리뷰에서 먼저 판정한다. (3) 기존 Pillow 타일 생성기와 JSON 매니페스트의 키/아틀라스 크기를 함께 확장하고, 시작 맵 생성기의 고정 좌표를 보존한다. 장식이 지면 셀을 덮어야 하면 현재 Godot 씬에서 이미 쓰는 `TileMapLayer`를 **비충돌 장식 레이어**로 추가하는 방안을 구현 단계에서 검토한다. (4) 부락 안쪽과 물가에만 배치하고 낮/밤·전투·이동을 확인한 뒤 범위를 늘린다. 신규 건물 충돌이나 상호작용은 이 파일럿의 전제가 아니다.

### 통과 기준

1. **밀도·정체성:** 같은 4배율 화면에서 수선한 건물 2종 이상, 생업 소품 군집, 밭/여울의 경계가 서로 다른 역할로 읽힌다. 부락이 현재의 바닥·벽·깃발 조합보다 생활 공간으로 보이는지 기존 화면과 나란히 판정한다.
2. **길찾기:** 부락 출발 → 동문 → 2타일 도로, 동문을 나와 돌아가는 북쪽 오솔길 → 여울의 연속 경로를 장식 없이 읽을 수 있다. 부락 북쪽 성벽을 새 출구로 오인하게 만들지 않는다. 장식으로 통행 폭을 줄이지 않고 기존 여울·관문·퀘스트 지점에 도달한다.
3. **전투:** 관문 밖 뿔토끼 구역과 물가 북쪽 교전 화면을 낮/밤에 확인한다. 플레이어·적·투사체·드롭·공격 예고를 모두 즉시 구별할 수 있고, 가림·가짜 신호·환경 전용색 침범이 없다. 문제가 생기면 먼저 장식을 제거/이동한다.
4. **기술적 회귀 없음:** 팔레트·대면적 지면 대비 검증을 통과하고, 시작 맵의 기존 충돌 키·마커 좌표·주요 통로가 유지된다. 월드 입력/동선 회귀 검증과 게임 내 실제 이동 확인을 함께 기록한다.

## 5. 캐릭터 모션과 후속 제작 경계

**지금 바로 고칠 시각적 기능 결함:** 걷기·공격 중 무기 손잡이가 손에서 떨어짐, 공격 방향과 무기 방향 불일치, 프레임 간 무기 순간이동/뒤집힘, 조준→공격 연결 끊김, 모션 접촉 시점과 타격 판정 불일치. 이 항목은 아트 미화가 아니라 전투 신호와 조작감의 결함이며 발견 시 해당 모션을 우선 수정한다. 환경 파일럿이 이를 덮어서는 안 된다.

**전체 캐릭터 리디자인 단계까지 미룸:** 체형/비율 재설계, 모든 직업의 최종 의상·실루엣, 자세의 미적 완성, 머리카락·옷의 보조 동작, 무기 원근과 최종 명암·색감. 이번 작업에서 캐릭터 PNG·애니메이션·전투 코드는 변경하지 않는다.

## 6. 실행 체크리스트

- **단기 — 여울목 파일럿:** 기준 화면과 통로 도면 캡처 → 원본 형태 시트 제작 → 건물 2종과 요소별 최소 세트 제작 → 매니페스트/생성기 변경안 확정 → 부락 한 화면에 시험 배치 → 대비·동선·전투 가독성 판정.
- **중기 — 검증 후 확장:** 통과한 규칙을 지역별 재사용 키트로 정리하고, M5의 실제 NPC/의뢰 동선에 맞춰 여울목 소품을 조정한다. 노베라와 잿골은 각 맵/기능 설계가 준비될 때 별도 파일럿으로 연다.
- **후기 — 리디자인 단계:** 전 지역 아트 전환, 계절/날씨/실내·환경 애니메이션, 직업 전체의 최종 캐릭터·무기 외형을 별도 아트 마일스톤에서 다룬다.
