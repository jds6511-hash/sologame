# 지역별 환경 아트 제작 기준 — 생활·여행·마법

- 최종 수정일: 2026-09-28
- 담당: Codex / 아트 방향 정리
- 의존: [세계관](../design/worldview.md) 6·7장, [스타일 가이드](STYLE_GUIDE.md), [환경 파일럿](environment-style-direction.md), [제작선](art-pipeline-candidates.md)
- 변경 이력: 2026-09-28 디렉터의 지역별 특색·《장송의 프리렌》의 여행 감각·마법도시 요청 반영.
- 상태: **제작 지침과 제안 상세**. 기존 도시의 위치/기능은 세계관 정본, 아래 건축·소품·구역 구성은 아트 제안이다. 새 도시·퀘스트·마법 시스템을 확정한 문서가 아니다.

## 1. 목표

장소마다 사람들이 어떤 땅에서 무엇으로 살아가는지가 보이는 탑다운 픽셀 세계를 만든다. 한 왕국이라는 재료·픽셀 규칙을 공유하되, 마을과 사냥터의 지형·실루엣·생업·역사·생활 마법을 구별한다. 《장송의 프리렌》은 **여행 중 장소의 변화, 오래된 흔적과 현재의 일상, 생활 속 마법이라는 디렉터가 원하는 경험의 참고**다. 특정 도시·탑·거리 배치·건축 장식·문양은 옮기지 않는다. 롬스테드의 재질/밀도, Hearth and Hamlet의 아늑한 생활 군집, 《영주님은 방치중》의 미래 캐릭터 참고 역할을 대체하지 않는다.

지역 차이는 지붕 색만 바꾸거나 몬스터 종류만 교체해서 만들지 않는다. 새 지역마다 아래 제작 카드를 채운다.

| 필수 항목 | 제작자가 답할 질문 |
|---|---|
| 지형과 진입 | 강·경사·숲·도로가 왜 이곳에 정착하게 했는가? 들어올 때 무엇이 먼저 보이는가? |
| 큰 실루엣 | 이름을 가려도 알아볼 랜드마크1개, 보조 실루엣2개는 무엇인가? |
| 재료 | 주재료2개·보조재료1개, 지붕/벽/기초의 접합과 낡는 방식은? |
| 생활 | 주된 생업1개·보조 생업1개, 작업→보관→운반 흔적은? |
| 시간의 흔적 | 오래된 것·수선한 것·최근 더한 것이 어디서 만나는가? |
| 마법 | 누가 쓰며 무슨 일을 돕는가? 유지·수리 흔적과 접근 제한은? |
| 길과 교전 | 주도로·골목·상호작용 접근·교전면·가림 금지 영역은? |
| 빛과 소리 | 낮/밤의 초점과 환경음 후보. 전투 신호보다 조용한가? |

공용 문·창·울타리 연결부·작은 용기 등을 재사용하고, 지역당 랜드마크1개와 전용 소품군2~3개에 제작비를 집중한다. 화면마다 독자 타일셋을 만들지 않는다. 공용 골격/지역 재료/생활 소품을 분리하며 지역 수는 기존 로드맵을 따른다.

## 2. 정주지별 제작 카드

아래 색 표현은 분위기 방향이다. 실제 색은 STYLE_GUIDE4장의 권역 서브팔레트에서 선택한다. 새128색 팔레트가 승인됐다는 뜻은 아니다.

| 장소·핵심 인상 | 실루엣·재료 | 생활·역사·마법 | 피할 것 |
|---|---|---|---|
| **여울목 — 서로 돌보는 재건 부락** | 낮은 수선 지붕, 목재/거친 돌 기초, 여울의 낮은 둑. 접수 쉼터를 작은 표지로 구분 | 장작·공동 솥·빨래·수선 도구·밭의 물통. 오래된 기초 위 새 목재. 마법은 귀한 휴대 도구 정도의 후보로 제한 | 궁전 같은 크기, 모든 집의 같은 지붕, 네온 조명, 길 위 잡동사니 |
| **잿골 — 상처를 남긴 계획적 복구** | 남은 석벽·낮은 굴뚝·재건 비계, 검댕 석재와 새 지붕 대비 | 폐자재 선별→목공 작업→수선 집의 연속. 보강 표식은 작업장 한 군집에만 | 모든 바닥을 검게 만들기, 여울목을 회색으로만 바꾼 복제 |
| **노베라 — 개척과 교역의 활기** | 넓은 주도로, 조합의 큰 지붕, 창고·상점 차양. 밝은 목재/석재 받침 | 수레 바퀴 자국·짐 무게 재는 곳·임시 증축·다양한 간판. 마법은 측량·운반 보조 기구 후보 | 학술 도시로 성격 변경, 모든 상점 간판을 발광, 현재 입구 프로토타입을 완성 도시로 표기 |
| **아르셀 — 호수와 연구가 일상인 학술 도시** | 석조 회랑·단계형 연구탑·호수 수로. 청회 석재/회벽/목재 창틀 | 계측 장치·약초 건조대·마도구 수리·낡은 관측 시설. 아래3절의 생활 마법 중심 | 도시 전체를 공중에 띄우기, 전면 보라 네온, 프리렌 속 도시의 탑 배치 재현 |
| **발크렌 — 개척 전선의 관문 요새** | 두꺼운 성벽·통제 관문·수선된 망루 | 보급 적재·검문 동선·벽의 옛 손상. 제한된 방어 설비 | 노베라와 같은 열린 장터 구도, 통행문과 벽의 모호한 충돌 |
| **살레노 — 물류와 상인의 항구** | 창고 긴 지붕·부두 말뚝·차양 | 밧줄·화물 분류·염분 자국·거래판. 물결/깃발 움직임은 가장자리 | 물과 상자의 무차별 반복, 항구 중앙 전체를 반짝임으로 채우기 |
| **두르간 — 광산과 장인의 도시** | 낮고 묵직한 석조·공방 굴뚝·광석 운반선 | 광석→가공→납품의 흔적. 드워프의 룬은 도구/구조물에 새기는 표현 | 일반 마법도시와 동일한 공중 책/수정 장식, 화약 산업으로 오인할 설비 |
| **하프나 — 어업·조선의 거친 해안** | 선박 골조·긴 작업 지붕·바람막이 | 그물 수선·목재 건조·닻과 작은 배. 살레노보다 작업 흔적 강조 | 살레노의 무역 창고를 색만 바꿔 재사용 |
| **미스란 — 숲과 교역의 경계** | 숲 가장자리를 따르는 길·작은 교역 마당 | 약초·목재·교환 물품, 숲 쪽 낮아지는 건물 밀도 | 정본 근거 없는 엘프 거대 수상 도시 추가 |
| **브란텔·그란시아** | 브란텔은 제도 중심의 넓은 축선·기념 건축, 그란시아는 곡창의 저장 시설과 가문 저택 대비 | 공적 기관의 질서와 생활 골목의 차이. 장식의 크기/관리 상태로 계층 표현 | 두 곳 모두 ‘부유한 금색 도시’로 통일 |
| **카엘론 — 하사 이후 책임지는 도시** | 기존 도시 골격과 복구 구획이 함께 읽히는 실루엣 | 생활·행정·생산 구역을 함께 보여줌. 하사 전후 변화는 같은 건물의 수선 단계로 계획 | 입장 즉시 새 성 전체 생성, 실제 영지 시스템 이전에 업그레이드 구현으로 표기 |

오란세 등 나머지 지역은 정본의 별도 역할을 확인한 뒤 같은 카드로 확장한다. 이 표를 근거로 종교/종족 설정이나 도시 기능을 바꾸지 않는다.

## 3. 아르셀 마법 학술 도시 상세안

### 3-1. 도시를 이루는 세 공간

1. **생활·시장 쪽**: 석재 기초 위 소박한 주거, 약초상·필기구점·마도구 수리점 후보. 수로 옆 빨래/물통/작업대를 두어 마법만 전시한 테마파크가 되지 않게 한다.
2. **학술 회랑 쪽**: 같은 돌 규격의 아케이드·정원·낮은 연구동. 연구 분야는 창문·작업물·정원 구성으로 구별한다. 주 통로는 회랑 기둥 사이로 끊기지 않게 읽힌다.
3. **호반 관측 지점**: 단계형 연구탑1개와 수면 쪽 계측 시설을 대표 실루엣으로 사용한다. 높은 부분은 화면 위쪽 장식에 두고 발밑 길/전투 판정면을 가리지 않는다. 실제 퀘스트/건물 출입은 맵 설계에서 별도 결정한다.

마을의 공동 시설과 기관의 잘 관리된 시설을 대비해 마법 접근성의 차이를 표현한다. 출신과 권력의 벽이라는 아스터의 주제를 낮은 담·문·관리 상태로 드러내되 새로운 출입 규칙이나 마법 계급을 이 아트 문서에서 확정하지 않는다.

### 3-2. 생활 마법 소품 후보

| 후보 | 시각적 작동·생활 흔적 | 제작·게임플레이 경계 |
|---|---|---|
| 가로등 | 석재 받침/교체 가능한 내부 부품, 작은 고정 광원 | 점멸/펄스 금지. 공격 예고·드롭색 사용 금지 |
| 물 공급 장치 | 수로/저수조와 연결, 밸브·청소 도구·석회 자국 | 처음에는 정지 프롭. 물리적 수류·새 상호작용 시스템을 요구하지 않음 |
| 지맥 계측기 | 받침에 고정한 눈금/바늘과 기록대 | 숨결 연구의 시각안. 지맥 발전소나 무한 동력 확정 아님 |
| 약초 작업장 | 건조대·유리병·차광 천, 작은 보호 덮개 | 떠다니는 입자보다 색/재료로 구별. 효과가 게임 버프처럼 보이지 않게 함 |
| 운반 보조 장치 | 고정 궤도/받침이 보이는 화물 작업대 | 공중 부유는 후속 연출 후보, 정적 원본부터 검수 |
| 오래된 관측 시설 | 마모된 문양, 새로 덧댄 금속, 잠긴 보관함 | 문양을 구체 작품에서 복제하지 않는다. 중요한 조작물처럼 보이면 실제 기능 여부를 명시 |

희귀한 마법은 한 화면의 중심 장치1개와 보조 시설로 표현한다. 마법도시라고 길 전체에 마법진을 깔지 않는다. 주거·생활 도구·사람의 흔적이 화면의 대부분을 이루고 마법은 그 일을 돕는다.

### 3-3. 낮과 밤

낮에는 밝은 회벽·청회 지붕·식생·수면으로 공간을 구분하고, 밤에는 입구/창문/가로등의 작은 빛으로 길을 잇는다. 대면적 발광·전면 보라 안개·바닥에서 회전하는 원형 효과는 금지한다. 기존 밤 변조에 새 광원을 더할 경우 플레이어/적 외곽선 대비와 어두운 적 실루엣을 다시 검사한다. 픽셀 밖 블룸·부드러운 그라디언트는 현행 룩에 자동 도입하지 않는다.

## 4. 사냥터의 차이와 여행 중 연결

아래는 기존 동부 변경 지형을 구체화하는 **시각 유형**이며 새 맵5개를 추가하는 요구가 아니다. 실제 스폰/AI/보상 수치는 바꾸지 않는다.

| 유형 | 지형·흔적 | 전투 공간·길찾기 |
|---|---|---|
| 부락 옆 방목 초지 | 낮은 풀, 끊어진 울타리, 소수 먹이통, 밟힌 흙 | 넓은 교전면·귀환문 시야. 소품 뒤에 작은 토끼를 숨기지 않음 |
| 버려진 경작지 | 끊긴 고랑, 무너진 창고 기초, 덤불에 덮인 농기구 | 고랑 방향이 통행을 오인시키지 않게 함. 교전면에는 높은 작물 없음 |
| 강변 여울 | 자갈·갈대 군집·낮은 둑·마른 표류목 | 여울은 밝기만이 아닌 바닥 형태로 표시. 수면 반짝임이 투사체와 경쟁하지 않음 |
| 숲 가장자리 | 수관 군집·그루터기·뿌리·벌목 흔적 | 주요 이동선 위 수관 금지. 나무 그림자로 예고를 숨기지 않음 |
| 균열 인근 폐허 | 훼손된 석재·불규칙한 오염 경계·생장이 뒤틀린 식물 | 위험감은 외곽/구조에서 만들고 실제 공격 예고색은 비워둠. 오염 데칼에 판정이 없다면 장판처럼 깜박이지 않음 |

전환은 마을 울타리→사람이 다니는 흙길→줄어드는 생활 흔적→야생 지형의 순서로 이어지게 한다. 문명권 밖을 표현하려고 적 밀도나 피해량을 임의 증가시키지 않는다. 각 구간에는 같은 랜드마크를 다른 각도에서 다시 볼 수 있는 시야 지점을 고려하되 실제 배치는 길찾기 검수 후 결정한다.

## 5. 픽셀 제작·밀도·전투 보호 규칙

- 현행16px 타일·28×36 인체·1920×1080/zoom4를 기준으로 형태를 판단한다. 건물 원본은 여러 타일 크기로 만들고 한 장짜리 도시 그림을 축소해 잘라 넣지 않는다. 발밑 앵커·높이·그림자 방향을 공용 시트에 명시한다.
- 지면은 넓고 조용한 덩어리, 생활 소품은 가장자리2~4개 군집, 랜드마크는 화면의 방향 표지로 배치한다. 반복되는 체커·모든 셀의 작은 고대비 점은 반려한다.
- **교전면/주 이동로/대화·줍기 접근 반경**은 먼저 마스크로 표시한다. 미술 배치로 기존 통행 폭·퀘스트 지점·관문40px 대화 접근을 줄이지 않는다. 장식 전용층과 충돌층을 구분하고, 고형 벽처럼 보이는 통과 가능한 건물은 교전면에 배치하지 않는다.
- 전투 예고 `#ff0044`는 환경에 금지. 적/플레이어 스킬/마나 역할색의 기존 제한을 유지한다. 마법도시는 예외가 아니다. 지역 차이가 전투 신호의 의미를 바꾸지 않는다.
- NPC·아이템 드롭과 비슷한 실루엣/색의 장식은 피한다. 높은 물체가 몸/무기/예고를 가리면 이동 또는 제거가 우선이며 새 투명화 시스템이 있다고 가정하지 않는다.
- HUD는 최종 재설계 대신 같은 플레이 장면에서 점유 면적/글자 크기/목표 안내 겹침을 비교한다. 기존 입력·정보·가독성을 보존하고 해상도/카메라 변경과 동시에 섞지 않는다.
- 손에서 뜨는 무기, 방향 오류, 프레임 크기/위치 점프, 타격 시점 불일치는 즉시 수정 대상. 최종 캐릭터 얼굴·체형·의상·보조 동작은 별도 리디자인으로 유지한다.

## 6. 첫 산출물과 승인 기준

**현재 우선순위는 여울목 한 화면의 시각 시제품**이다. M6 설계 문서는 보관하고 제품 구현 확대 전 방향을 확인한다. 이는 G3/G4/G5 통과 선언이나 전 지역 아트 교체 승인이 아니다.

1. 여울목 실제 낮/밤/교전 캡처 위에 길·접수원·관문·상호작용 접근·가림 금지 영역을 표시한다. 최신 구현 좌표를 사용하고 옛 지도 수치를 그대로 믿지 않는다.
2. 기존 환경 파일럿의 지면/도로·건물2종(3종째 선택)·울타리·소품5~7종·물가·초목 최소 키트를 만든다. HUD 점유율 비교는 별도 A/B 화면으로 둔다.
3. 아르셀은 **같은 카메라 감각의 분위기 보드1장+랜드마크/생활 마법 소품 시트1장**까지만 설계 샘플로 제작한다. 실제 맵 구현은 후속이며 여울목과 동일화되지 않는지 확인하는 용도다.
4. 산출물마다 원본/규격/도구·모델/수정 이력/출처·이용 조건/타일 접합/알파 가장자리/충돌 footprint를 기록한다. 생성 프롬프트만으로 재현 가능하다고 주장하지 않는다.
5. 이름표를 가린 여울목·노베라·아르셀 보드에서 생활과 건축의 차이를 설명할 수 있어야 한다. 실제 게임에서는 낮/밤 각각 플레이어·적·투사체·드롭·예고를 구별하고 주요 경로를 걸어 통과한다. 예쁜 정지 콘셉트만으로 플레이 화면 통과를 선언하지 않는다.

이번 문서 작업에는 새 이미지 생성·런타임 에셋 교체·맵/전투/UI 코드 변경이 없다. 제작 도구 선택은 [비교 및 시험 계획](environment-tool-evaluation.md)을 따른다.
