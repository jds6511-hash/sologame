## 원인과 수정

기존 4프레임 시트는 첫 검 각도가 -115도, 다음이 70도이고, 런타임은 판정 내내 프레임1을 고정했다. 잔상은 움직여도 검은 185도 떨어진 두 그림으로 교체됐다. 사용자 지적을 최종 미적 리디자인까지 미룰 항목으로 취급하지 않는다.

- 모험가·전사·현재 전사 시트를 공유하는 검투사의 `attack`, `attack2`에 8프레임을 사용한다. 3타 폴백과 공격형 스킬도 같은 시트를 사용한다. 전용 검투사 모션 제작을 완료했다는 뜻은 아니다.
- 선딜0~1 → 판정2~4 → 회수5~7. 판정 시계의 진행률로 프레임을 선택하므로 공격 속도·히트스톱은 기존 시계를 따른다. 판정 시간·대미지·사거리 수치는 변경하지 않는다.
- 각 셀은 **64×64**, 몸은 기존 **28×36**을 `(18,14)`에 패딩한다. 몸의 원본·축소율·스프라이트 오프셋 `(0,-18)`·충돌 크기는 유지한다. 28px 몸 캔버스 상한을 무기 회전 공간에 적용해 칼날을 짧게 자르지 않는다.
- 시작/종료 셀은 기존 대기 셀을 그대로 사용한다. 중간 몸 프레임은 외부 LPC 원본의 기존 변환 결과를 재사용한다. 새 캐릭터를 생성하거나 다른 게임 에셋을 쓰지 않는다. 라이선스는 [기존 출처 기록](ASSET_SOURCES.md)의 LPC 항목을 따른다.
- 무기 손은 몸만 렌더한 프레임에서 정한 손 근방의 실제 피부 픽셀에 고정한다. 최대3px 탐색 한계를 벗어나면 생성 실패. 후면2타에서 손이 완전히 가려지는 원본 자세는 손이 드러나는 직전 자세로 유지한다.
- 칼날은 길이22px로 그리며 머리 앞을 가로지르는 부분은 머리 뒤로 가린다. 머리 회피를 위해 손잡이를 이동시키지 않는다. 후면은 몸 뒤에 무기를 그린다.
- 왼쪽 기본 공격은 몸·검의 `flip_h`와 함께 잔상 회전도 반전한다. 궁수·걷기·차지 홀드 PNG는 변경하지 않는다.

## 재생성과 검증

`godot/assets/tools`에서 실행:

1. 원본 몸을 변경했다면 기존 `gen_player_lpc.py`를 해당 직업 범위로 실행한다.
2. `python gen_sword_sweep.py` — 몸을 읽고 두 공격용 `_sweep.png`만 출력한다.
3. `python gen_player_spriteframes.py` — 검 공격만 64×64·8셀로 연결한다.
4. `python -m unittest test_sword_sweep test_player_walk_grips test_weapon_placement test_player_archer_art`.
5. Godot 임포트 후 `test_player_sword_sweep.gd`, `test_player_melee_swing_vfx.gd`, 기존 전투 회귀 및 전체 GUT를 확인한다.
6. `docs/qa/tools/sword_sweep_probe.gd`로 60Hz 2타·4방향을 렌더한다. 손 연결·중간 궤적·대기 복귀는 정지 샘플과 연속 재생을 함께 확인한다.

한 프레임의 손 좌표 일치만으로 휘두르기 품질 통과를 선언하지 않는다. 최종 팔 관절·체중 이동·옷과 머리 흔들림은 이후 리디자인 범위다.
