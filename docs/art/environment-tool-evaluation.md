# 환경 제작 도구 선택 — Higgsfield와 기존 제작선

- 변경 이력: 2026-09-28 공식 기능과 저장소 시험 기록을 구분해 비교.

## 결론

**콘셉트와 분위기 탐색에는 Higgsfield를 보조 후보로, 엔진용 픽셀 타일/소품에는 PixelLab 시험+수작업 정리+기존 임포트 검증을 권고한다.** 현재 채택된 LPC/직접 작화/Pillow 제작선을 Higgsfield로 전면 교체할 근거는 없다. 이는 출력물을 동일 조건으로 비교한 성능 순위가 아니라 작업 종류에 따른 권고다.

사용자가 말한 '기존에 사용한 곳'은 저장소에 기록된 PixelLab·SpriteCook 시험을 기준으로 해석했다. 실제 런타임은 LPC 몸·직접 작화 무기와 Pillow 환경이 주력이다. PixelLab은 아직 조건부 후보, SpriteCook은 이전 시험 반려이며 시험했다는 사실과 채택을 구별한다.

## 공식 기능과 프로젝트 판단

2026-09-28 공식 공개 문서를 확인했다. 구독 요금·속도·생성물 품질 우열·이용권 보장은 이번 비교 범위가 아니다. 실제 결제/편입 전에 사용하는 모델·요금제의 조건을 확인한다.

| 용도 | 확인한 기능/이력 | 권고와 미검증 사항 |
|---|---|---|
| 마을 전경·건축·마법 생활 콘셉트 | Higgsfield는 이미지 생성, 스타일/구도/팔레트 조정, 영역 편집을 안내 | 서로 다른 방향의 시안을 탐색하는 보조 도구. 실제 픽셀 자산 품질은 이번에 생성 검증하지 않음 |
| 작업 흐름 구성 | Higgsfield Canvas는 이미지/영상/편집 노드를 연결 | 무드보드 반복에는 활용 후보. Canvas 호출은 표준 생성과 과금이 다를 수 있어 사전 확인 |
| 탑다운 타일·캐릭터 방향·애니메이션 | PixelLab 공식 API는 탑다운 타일셋·캐릭터·애니메이션 기능을 제공 | 엔진용 제작 후보로 목적이 더 잘 맞는다는 판단. API가 있다는 것과 접합/모션 품질 보장은 다름 |
| 기존 PixelLab 실측 | 2026-09-16 보고:16px Wang 지원, 일부 걷기에서 장비 소실·비율 불일치 | 환경/소품은 별도 시험 가능. 캐릭터는 기존 연속성/비율 게이트 통과 전 채택 금지. 옛 수치를 현 버전 재시험 결과로 주장하지 않음 |
| 기존 SpriteCook 실측 | 다색·가변 캔버스·정지 출력으로 당시 반려 | 재시험 근거 없이 반려를 해제하지 않는다. 사용자가 이 도구를 뜻했다면 기존 도구 유지 권고 대상이 아님 |
| LPC·직접 작화·Pillow | 현재 원본/규격/검증 경로가 있음 | 조립·팔레트 정리·접합 검사·재현에 유지. 더 좋은 미술 구도/재질을 자동 보장하는 도구로 오해하지 않음 |

Higgsfield의 픽셀 스타일 안내를 16px 접합 타일, 고정 팔레트,4방향 무기 접점 보장으로 읽지 않는다. 해당 보장은 확인한 공식 페이지에서 검증하지 못했다. 반대로 픽셀 스타일 생성 자체를 지원하지 않는다고 단정하지도 않는다.

## 실제 비교를 할 최소 묶음

유료 대량 생성 전에 동일한 원본 지역 카드로 다음만 시험한다. 구도/건축 초벌과 엔진용 자산을 별도 평가한다.

- 여울목 수선 집1종·울타리 모서리·물통/장작 소품군, 아르셀의 수로용 마법 장치1종.
- 콘셉트 보드: 생활 기능·지역 차이·큰 실루엣·우리 세계관 적합성 확인. 예쁜 전경만으로 채택하지 않음.
- 엔진 시트:16px 격자/기존 캐릭터 상대 크기/투명 배경/일관 광원·시점/타일 가장자리와 코너 접합/낮·밤 가독성 확인. 고해상도 그림을 단순 축소한 이미지와 구분.
- 같은 횟수의 초안·수정 시도를 기록하고 **채택한 자산 수, 실패/재생성 수, 수작업 보정 시간, 실제 사용 크레딧**을 비교한다. 싼 한 장보다 게임에 편입하는 전체 비용으로 결정한다.
- 캐릭터 애니메이션은 이번 환경 비교에 끼우지 않는다. 무기 손 접점·방향·크기 연속성은 별도 기존 게이트로 시험한다.

권고 순서: 지역 카드→선택적으로 Higgsfield 콘셉트→형태/재료 확정→PixelLab 또는 직접 픽셀 작화→Pillow 등으로 조립/검증→Godot 동일 장면 A/B. 새 구독을 필수로 요구하지 않는다. 도구 시험 출력은 런타임 편입 전 출처 대장에 실제 사용 자산처럼 기재하지 않는다.
