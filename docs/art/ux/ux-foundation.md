## 1. 설계 원칙 (근거)

1. **전투 중 손은 항상 전투에**: 실시간 액션이므로 전투 관련 입력(이동/공격/스킬/회피)은 왼손 WASD 주변 + 오른손 마우스에 고정한다. 메뉴 단축키는 전투 키와 겹치지 않는 키(I, C, K, J, M, B, ESC)에 배치한다.
2. **통합 메뉴 구조**: 인벤토리/장비/스킬/도감/퀘스트/지도는 별개 창이 아니라 **하나의 풀스크린 통합 메뉴의 탭**이다. 어떤 단축키로 열어도 같은 메뉴의 해당 탭이 열리며, 탭 간 이동이 자유롭다. (250시간 볼륨 게임에서 창 간 이동 횟수가 매우 많으므로, 창 관리 비용을 없앤다.)
3. **통합 메뉴를 열면 게임 일시정지**: 싱글플레이이므로 메뉴 중 시간·전투 정지. 실시간 전투 중 안전하게 아이템/지도를 확인할 수 있다. (게임 내 시간 30분=1일도 함께 정지 — systems-designer 시간 시스템 문서에 동일 규칙 반영 요청)
4. **정보 위계 — 상시 표시는 "초 단위 판단에 필요한 것"만**: HP/MP, 스킬 쿨다운, 회피 가능 여부, 주변 지형(미니맵), 현재 목표(퀘스트 트래커), 게임 내 시간만 HUD에 상시 표시. 골드/경험치 수치/스탯/명성 등 "분 단위 판단" 정보는 통합 메뉴로 내린다.
5. **접근성 기준선**:
   - 본문 최소 글자 크기 **16px**, 보조 정보(수치 라벨 등) 최소 **13px** (1280x720 기준).
   - 텍스트 대비 **4.5:1 이상**, 대형 텍스트(24px+)는 3:1 이상.
   - 색만으로 상태를 구분하지 않는다: HP/MP는 색+위치+아이콘, 쿨다운은 어두운 오버레이+숫자, 아이템 등급(S/A/B/C)은 색+등급 문자 병기.
   - HUD 전체 토글 키 제공(스크린샷·연출 감상용).

## 2. 조작 체계

### 2-1. 기본안: 왼손 키보드 + 오른손 마우스

combat-options.md A안 2-5절을 기준으로 하고, 메뉴·시스템 키를 추가 확정한다.

#### 전투·이동 (문맥: 필드/전투 중)

| 입력 | 기능 | 비고 |
|---|---|---|
| W / A / S / D | 이동 (8방향) | 키 리매핑 지원 전제 |
| 마우스 이동 | 조준 (캐릭터가 마우스 방향을 바라봄) | |
| 마우스 좌클릭 | 기본 공격 (마우스 방향) | 꾹 누르면 연속 공격 |
| 마우스 우클릭 | 보조 공격 / 가드 (직업별) | 직업 시스템 문서 확정 시 상세화 |
| 1, 2, 3, 4 | 스킬 슬롯 1~4 | |
| Q, E | 스킬 슬롯 5~6 | |
| R | 궁극기 (스킬 슬롯 7) | |
| Space | 회피 (대시, 무적 프레임 0.2~0.3초) | 이동 방향으로 대시 |
| Shift (홀드) | 걷기/달리기 전환 | 기본 달리기, 홀드 시 걷기 (제안 — systems-designer 확인) |
| Tab | 타겟 고정 / 해제 (가장 가까운 적) | 고정 중 다시 누르면 다음 적 |
| F | 상호작용 (대화, 채집, 문, 상자) | 대상 근접 시 대상 위에 `[F]` 프롬프트 표시 |
| 5, 6 | 소비 아이템 퀵슬롯 1~2 (물약 등) | 제안 — 소비 아이템 사양 확정 시 조정 |

#### 메뉴·시스템 (문맥: 항상)

| 입력 | 기능 | 비고 |
|---|---|---|
| ESC | 일시정지 메뉴 열기 / 열린 화면 닫기(뒤로) | 어떤 화면에서든 "한 단계 뒤로"의 만능 키 |
| I | 통합 메뉴 — 인벤토리 탭 | Inventory |
| C | 통합 메뉴 — 캐릭터(장비+스탯) 탭 | Character |
| K | 통합 메뉴 — 스킬 탭 | sKill |
| J | 통합 메뉴 — 퀘스트 저널 탭 | Journal |
| M | 통합 메뉴 — 지도 탭 | Map |
| B | 통합 메뉴 — 도감 탭 (아이템/몬스터/펫/칭호 4개 하위 탭) | Book |
| ← / → 또는 마우스 클릭 | 통합 메뉴 내 탭 전환 | 통합 메뉴가 열린 상태에서 |
| F5 / F8 | 퀵세이브 / 퀵로드 | 세이브 사양 확정 시 슬롯 규칙 상세화 |
| H | HUD 표시 토글 | 접근성·스크린샷용 |
| Enter | 대화 진행 / 확인 | 대화 중 좌클릭과 동일 |

- **영지 관리 화면**은 단축키가 아니라 **영지 내 집무실 오브젝트/집사 NPC와 상호작용(F)** 으로 진입한다. 근거: 영지는 중반 이후 해금되는 콘텐츠이고, 원격 관리 허용 여부(영지 밖에서 관리 가능한가)는 시스템 설계 사안이므로 M1에서는 현장 진입만 확정한다. → **디렉터 결정 필요 아님, systems-designer 협의 사항**.
- **상점 화면**은 상인 NPC와 대화(F) → 대화 선택지 "거래한다" → 상점 화면 진입.

### 2-2. 대안: 키보드 전용

마우스가 불편한 환경/사용자를 위한 프리셋. 설정 화면에서 "키보드 전용 프리셋"으로 일괄 전환한다. 조준은 마우스 대신 **이동/마지막 입력 방향(8방향) + Tab 타겟 고정**으로 대체한다.

| 입력 | 기능 | 기본안 대응 |
|---|---|---|
| ← ↑ ↓ → (화살표) | 이동 (8방향, 조준 방향 겸용) | WASD + 마우스 조준 |
| Z | 기본 공격 / (비전투 문맥) 상호작용 | 좌클릭 + F |
| X | 보조 공격 / 가드 | 우클릭 |
| A, S, D, F | 스킬 슬롯 1~4 | 1~4 |
| Q, W | 스킬 슬롯 5~6 | Q, E |
| R | 궁극기 | R |
| Space | 회피 (대시) | Space |
| Tab | 타겟 고정 (고정 중 공격은 대상 방향 자동 조준) | Tab |
| C, V | 소비 아이템 퀵슬롯 1~2 | 5, 6 |
| ESC, Enter, F5/F8, H | 시스템 키 — 기본안과 동일 | |
| I, K, J, M, B | 메뉴 단축키 — 기본안과 동일 | ※ C는 퀵슬롯과 충돌하므로 캐릭터 탭은 **P**(Profile)로 대체 |

- 키보드 전용에서는 **타겟 고정의 비중이 커진다**: 고정 대상이 있으면 공격·스킬이 대상 방향으로 자동 조준된다. 논타겟 정밀 조준(장판 설치 위치 등)은 조준 방향 고정 거리 기준으로 단순화 — 스킬 상세 설계 시 스킬별 조준 규칙에 반영 요청 (systems-designer).
- 두 프리셋 모두 **전 키 리매핑**을 설정 화면에서 지원한다 (M2 이후 설정 화면 상세 설계에 포함).

|---|---|

## 8. M2 이후 상세 설계 과제

아래 화면은 의존 시스템 문서 확정 후 화면별 개별 문서로 상세화한다 (`docs\art\ux\` 하위, 파일명 예: `screen-inventory.md`).

| 순번 | 과제 | 의존 문서 (대기 중) |
|---|---|---|
| 1 | 인벤토리 탭 상세 (칸 수, 정렬/필터, 등급 표시, 장비 비교 툴팁) | 아이템 시스템 (economy/systems-designer) |
| 2 | 캐릭터 탭 상세 (스탯 목록, 장비 슬롯 수, 칭호 장착, 명성 표시) | 스탯·직업·칭호 시스템 |
| 3 | 스킬 탭 상세 (전직 트리 표현, 슬롯 배치 UX) | 직업 10개·3차 전직 설계 |
| 4 | 도감 탭 상세 (4개 하위 탭 공통 템플릿, 수집률, 미발견 표시) | 도감 데이터 스키마 |
| 5 | 퀘스트 저널 상세 (메인/서브 분류, 수백 개 검색·필터, 트래커 지정) | 퀘스트 구조 (quest-designer) |
| 6 | 지도 상세 (월드↔지역 2단계, 도시 8개+ 표기, 빠른 이동 여부) | 월드맵 구조 (level-designer) |
| 7 | 상점 상세 (구매/판매, 가격 표시, 일괄 판매) | 상점 경제 (economy-designer) |
| 8 | 영지 관리 상세 (수입, 시설, 규모 승급 표현) | 명성·영지 시스템 |
| 9 | 대화 UI 상세 (초상, 선택지, 로그, 자동 진행) | 대화 데이터 포맷 (narrative-designer) |
| 10 | 세이브/로드·설정 상세 (슬롯 수, 리매핑 UI, 접근성 옵션) | 세이브 사양 (systems-dev) |
| 11 | 타이틀·사망·왕국 이벤트 고지 연출 | 아트 스타일 가이드 (art-director) |
| 12 | 펫 명령 UI, 전직 화면 | 펫·전직 시스템 |
