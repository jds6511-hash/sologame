## 제작 경로

`godot/assets/tools/generate_yeoulmok_native_kit.py`가 정수 좌표로 직접 작화한 프로젝트 원본이다. 공용 EDG32만 사용한다. 외부 그림을 복제하지 않았고, 앞선 image_gen V1/V2를 축소·양자화·가공한 결과도 아니다. 이번 제작에는 image_gen·Higgsfield·PixelLab을 호출하지 않았다. CC0 외부 소싱 항목으로 취급하지 않는다.

`environment.png`는 160×128 RGBA 시트, `manifest.json` v3는 스프라이트별 영역·앵커·부지 정보다(게임 저장 버전과 무관). 64×64 셀의 수선 집/작업장, 32×32 셀의 물통·상자·장작·바구니·작업대, 16×16 셀의 초원2/흙길2/울타리3/관목2/갈대1이 있다. 셀 크기는 그림의 실체 크기와 다르다. 소품은 건물에서 독립적으로 배치할 수 있다.

## 엔진 계약

- 원본 1px = 월드 1px, 카메라 zoom4 유지. 매니페스트 좌표는 각 잘린 셀의 좌상단 기준이다.
- 건물 anchor/threshold `(32,60)`, wall_bottom `60`. 이미지 bbox 추정 대신 작화 시 지정한 문턱과 벽 바닥을 쓴다. 문턱 아래 3px 계단은 충돌 밖이다. 문은 현재 장식이며 실내 진입 기능이 없다.
- 집 origin `(72,424)`, footprint `(12,36,40,24)` → 월드 `(52,400,40,24)`.
- 작업장 origin `(248,424)`, footprint `(12,40,40,20)` → 월드 `(228,404,40,20)`.
- 지붕은 벽보다 돌출하며 충돌을 추가하지 않는다. 건물 노드 z0/발밑 y-sort가 가림을 처리한다. `roof_bounds`는 지붕 전체 투영의 외접 범위다. 집 처마 행36~38은 벽 충돌 위에 투영되며, 이를 제거하거나 충돌을 축소하지 않았다. `visible_wall`은 실제 드러난 벽(집 행39~59/작업장40~59)이고 지붕과 겹치지 않는다. 충돌 footprint를 보이는 벽 픽셀의 bbox라고 해석하지 않는다.
- 소품 5종은 7개 인스턴스로 배치하고 발밑 y-sort에 참여한다. 전부 장식이며 별도 충돌·획득·상호작용은 없다. 소품을 지나갈 수 있는지의 체감은 직접 플레이에서 확인한다.
- 벤치 원점은 `(218,488)`로 이동했다. PNG의 실제 alpha>0 bbox로 귀환점·관문지기·접수원·시작점과 동문 발밑 띠를 검사한다. 이전 `(244,470)` 배치가 귀환점을 포함하는 음성 대조도 실행한다.
- 환경 표면은 별도 z−1 비충돌 노드다. 현행 타일 키의 atlas 0행0~3열(초원/흙길)만 x3~21/y23~32 안에서 시각적으로 덮는다. 물·벽·경작지의 데이터/충돌은 건드리지 않는다. 현행 아틀라스 키 배치가 바뀌면 이 대응도 갱신해야 한다. 울타리6개·관목3개·갈대2개는 별도 장식이며 기존 도형 울타리/관목은 중복 표시하지 않는다. 울타리 끝/코너와 관목0은 시트 후보만 만들고 현재 월드에는 미배치다.
- 제품 씬·타일·저장 형식은 그대로다. 시제품에서 불러오기·새 캐릭터·지역 이동 시 제품 월드가 다시 생성되어 키트가 사라진다. `user://yeoulmok_art_pilot` 저장 격리는 기존 실행기를 따른다.

## 재현

```powershell
python godot/assets/tools/generate_yeoulmok_native_kit.py
python docs/qa/tools/test_yeoulmok_native_kit.py
godot --path godot --resolution 1920x1080 --script ../docs/qa/tools/yeoulmok_art_pilot_probe.gd -- --native-kit
# 직접 조작용, 동일한 검사를 끝내고 창을 유지한다.
godot --path godot --resolution 1920x1080 --script ../docs/qa/tools/yeoulmok_art_pilot_probe.gd -- --native-kit --interactive
```

자동 출력은 ignored `docs/qa/screenshots/yeoulmok-art/native-kit/`에만 저장한다. 선별 증거만 별도로 보관한다. 기존 생성 후보는 `--candidate`로 별도 실행하고 두 옵션을 섞으면 월드 생성 전에 거부한다.

## 판정 범위

팔레트·이진 알파·정수 배율·문턱 앵커·벽 충돌 계약을충족하는 제작 예시다. 앞선 풍부한 콘셉트와 동등한 미술 완성도라는 뜻은 아니다. 캐릭터와의 비례, 작업장/집의 구별, 아늑함과 생활 밀도는 디렉터 판단 대상으로 남긴다. 길/초원 경계와 물가 직선 경계는 이번 시제품에 추가했다. 다양한 지형의 전용 코너 타일·지역 전체 지면 전환은 아직 미완료다. 공격 예고·투사체·드롭의 동적 가독성과 G3/G4/G5도 미판정이다.

## 2026-09-28 접합 확장과 리뷰 반영

- 변경 이력: 굴뚝 포함 전체 그림 영역 검사·벤치 작물 가림 보완 후 접합 타일8종 추가.
- 집 roof_bounds는 [7,4,51,35]로 굴뚝까지 포함한다. steps [25,60,16,3]을 추가하고 모든 불투명 픽셀이 roof_bounds/visible_wall/steps 합집합 안에 드는지 검사한다.
- 실제 작물도 CROP_PATCHES에서 그리며 같은 사각형과 소품 가림을 검사한다. 벤치의 이전 두 좌표에서 귀환점/작물 겹침이 발생함을 음성 대조한다. 세로 동선 x194~206(끝 제외)도 보호한다.
- 원본 지면 교체는 탐색190칸 중 실제49칸으로 유지한다. 변형 선택은 좌표 해시로 변경했다. 전체 맵 지면을 교체한 것이 아니다.
- 새 타일은 road/shore 각각 북동남서4종. 알파가 있는 픽셀은 해당 셀 경계 안쪽2px에만 존재한다. 접합 탐색은 x1~25/y12~32이며 길은 초원과 이웃한 흙길, 물가는 초원/흙길/모래톱과 이웃한 물 셀 안쪽에만 표시한다. 실제 배치 길21·물가52개다. 물의 통행 가능 영역을 넓히지 않는다.
- 기존 수면 그림과 대면적 광장은 유지한다. 전용 모서리 그림은 없으며 두 방향 띠를 겹쳐 코너를 표현한다. 원본 지면과 시제품 표면의 바깥 경계 질감 차이는 남아 있다.
- Python6/6, GD3 검사, native/기본/candidate 렌더 통과. Pillow 경고는 get_flattened_data 사용으로 해소했다. 실제 이동/전투 판정으로 확대 해석하지 않는다.
