## 제품 변경

- 상점(판매 상품), 가방(보유품), 착용 장비를 세 탭으로 분리했다. F는 상점, B는 가방. 왼쪽에서 선택 → 오른쪽 설명/가격/장착 전후 옵션 → 확인/취소 → 하단 결과와 골드 변화 순서다. 미장착 빈 칸은 해제하지 않으며 구매 실패 이유·포션 사용키·상인 부재를 안내한다. 모든 상태 변경은 기존 `EconomyRuntime.act`를 사용한다.
- 확인 화면에 상품 이름을 표시하고, 선택 상품을 목록 안에 드러내며, M6 안내는 창을 열면 숨긴다. 공통 버튼의 키보드 포커스에는 금색 테두리를 추가했다.
- 지역 이동은 걷기·이동용 대시·대시 충전을 허용한다. 실제 명중/피격 이후에만 전투 5초를 적용한다. 공격·스킬 시전·보스/사망 및 전투 스킬 재사용 대기/버프 제한, 저장 정지 조건은 유지한다.
- 궁수 화살은 몸 중심에서 커서를 향한다. 가까운 적의 발로 갑자기 꺾이는 근접용 자동 스냅을 제외했다. 연발은 최초 발사 방향 유지. 근접 공격의 스냅은 유지한다.
- 상단 저장 버튼은 숨기고 F6 메뉴·자동저장 토스트를 유지한다. 디렉터는 위 이동/조준/상단 버튼 세 항목 수정 시 G3~G5 통과를 지시했다. [판정 기록](g3-g5-functional-evidence.md).
