## 리뷰 표현의 적용 범위

- R8 약20h·이벤트1회는 비례 축소 가정이지 새 일정이나 확정 수입이 아니다. 최대 공급과 실제 수행량도 다르다. 시계 pause를 고려한 두 번째 리뷰의 정정이 우선한다.
- 18,612는 디렉터의 초반 완화 지시가 반영된 현행 수치다. 약51분은 계산 모델 결과이며 실제 플레이 시간 승인을 주장하지 않는다.
- 레벨/직업/성장 배분을 유지하고 EXP 필요량만 바꾸면 vitals 산식 변경은 불필요하다. 누적 EXP 보존으로 레벨을 바꾸는 정책을 택할 때는 HP/MP 등 결과 상태를 다시 검토한다.
- 기존 V1/V2 틀은 재사용하지만 `SUPPORTED`에3을 넣는 것만으로 완료되지 않는다. 출력 버전·세션 자동 저장·직접 codec 경로와 구 규칙 원본 검증도 함께 점검한다.
