## 질문별 판정

### 1. 반격이 실제 피해·생존·유효 공격자일 때만 시작되고, 경직·그로기·점액 사망 분기를 보존하는가 — 보존한다
- [rabbit_monster.gd](../../../godot/scripts/ai/rabbit_monster.gd)·[rift_slime_monster.gd](../../../godot/scripts/ai/rift_slime_monster.gd)의 `take_damage`는 먼저 부모(`super.take_damage`)를 호출한다. 따라서 경직·그로기·사망(점액 핵 파괴/자폭 분기)은 기존 경로를 그대로 탄다.
- 반격은 그 뒤에 아래 조건을 모두 만족할 때만 시작한다.
  - 몬스터가 살아 있다.
  - HP가 실제로 줄었다.
  - 공격자가 유효하고, 삭제 예정이 아니며, 자기 자신이 아니다.
- 화살 명중도 [player_attack_resolver.gd](../../../godot/scripts/combat/player_attack_resolver.gd)가 공격자를 플레이어(`_player`)로 넘기므로 궁수도 반격 대상이 된다.

### 2. 조준·박치기·쿨다운, 대상 해제·사망·거리 이탈에서 반격과 귀환이 안전하고 예고를 재시작하지 않는가 — 그렇다
- 토끼: 박치기(`MELEE_SWING`) 중에 맞으면 상태를 바꾸지 않는다. 박치기가 끝난 뒤 반격 중이면 도주 대신 다시 추격한다.
- 점액: 조준(`AIM`)이나 쿨다운 중에 맞으면 상태를 바꾸지 않는다. 추격 중에도 이미 시작한 조준과 쿨다운은 끝까지 진행하고, 새 조준은 대기 상태(IDLE)에서만 시작한다.
- 지속 조건(`MonsterBase._can_continue_retaliation`)은 대상이 유효하고 살아 있으며, 몬스터와 대상이 모두 스폰 지점 16타일 안에 있을 때다. 어긋나면 조준을 초기화하고 귀환(`RETURN`)한다.
- 저장 안전: 토끼의 저장 차단 예외는 "인지 범위 밖 평시 배회(`WANDER`)"뿐이다. 추격·귀환 중에는 저장을 막는다.

### 3. 기존 종의 반격을 구분한 문서와 검증 범위가 정확하고, 달리기 QA 수정이 제품 입력 경로를 우회하지 않는가 — 정확하다
- 설계 문서가 들개·거미·강도·임프의 기존 피격 추격과 이번에 추가한 토끼·점액 반격을 종별로 구분했다.
- [test_travel_convenience.gd](../../../godot/test/player/test_travel_convenience.gd) 수정은 테스트 쪽 입력 정리와 "다음 물리 프레임에서 누르기 확인"뿐이다. 제품 입력 경로는 그대로다.

## 이전 검토 정정

`1b5113c` 검토에서 Claude는 "`MonsterBase.last_attacker`는 기록만 되고 쓰이지 않아, 맞은 몬스터가 추격하는 경로가 없다"고 적었다. 실제로는 들개·거미·강도·임프 계열이 다른 경로로 피격 추격을 이미 하고 있었고, 추격이 없던 종은 토끼와 점액뿐이었다. 당시 표현은 범위를 넓게 잡은 것이었다. Codex의 종별 정정이 맞다.

## 참고

### 참고 1. 궁수 사거리와 반격 범위의 관계
- 궁수 기본 사거리는 10타일이고, 반격 추격 한계는 스폰 지점 기준 16타일이다. 따라서 이제 인지 범위 밖에서 쏘아도 토끼·점액이 쫓아온다. 앞선 검토 참고("반격 없이 사냥 가능")는 해소됐다.
- 다만 점액 투사체 사거리(5타일)보다 궁수 사거리가 길어, 거리를 유지하며 뒤로 물러서면서 쏘면 반격을 피할 수 있다. 의도한 궁수 플레이인지 2막 균형 때 판단하면 된다.

### 참고 2. 귀환 중 재피격
- 귀환(`RETURN`) 중에 다시 맞으면 `take_damage`가 상태를 `CHASE`로 바꿔 다시 추격한다. 16타일 경계 근처에서 계속 쏘면 귀환과 추격이 반복될 수 있다. 무한 반복이 플레이에 문제가 되는지는 체감 때 확인하면 된다.
