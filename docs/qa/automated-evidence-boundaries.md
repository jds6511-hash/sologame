# 자동 검증 증거의 공통 범위

- 2026-10-02 / Codex. 의존: [운영 규칙](../../AGENTS.md), [결정 기록](../DECISIONS.md). 변경 이력: 통합 요청서의 반복 제한 설명을 이 문서로 분리.

| 증거 | 확인 범위 | 별도 판정 |
|---|---|---|
| GUT·API 세션 | 모델·이관·실패 처리·스냅샷 복원 | 화면 조작·사람 체감 |
| 준비 상태(fixture) | 특정 장·레벨·의뢰 상태의 후속 경로 | 이전 과정을 실제 완주했다는 증거가 아님 |
| 버튼 신호·액션 입력 | 연결된 제품 처리·이동·공격·상호작용 경로 | OS 키 전달·네이티브 확인창 클릭 |
| 정지 렌더 | 해당 위치·상태의 화면 | 동적 교전 가독성·미술 승인 |
| 사전 고정 반복 배치 | 기록된 코드와 회차의 결과 | 전체 난수 배치·장시간 안정성·통과 확률 보장 |

실패한 회차를 버리고 성공한 표본만 모으지 않는다. 준비 상태·API 호출·정상 입력을 검토서에서 구분한다. 실제 저장은 별도 승인이 없는 한 QA 복사본에서만 시험하며 원본의 전후 해시가 달라지면 통과로 기록하지 않는다.

`verify_all.ps1`의 전투 검사는 `-Combat` 옵션이며 제품 채택의 필수 조건이 아니다. 기본 검증의 이동·사냥 실패 가드도 창을 띄우고 실제 포인터를 움직일 수 있다. `-Combat` 전투 조작 역시 포인터를 움직이므로 다른 수동 조작과 동시에 실행하지 않는다. 디렉터 체감은 3장 이후 1막 종료에서 한 번으로 모으며 자동 증거로 대신 승인하지 않는다.
