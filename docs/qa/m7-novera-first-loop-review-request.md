## 이번 묶음

기존 노베라 입구는 보존하고 거점64×48/외곽80×48을 추가하는 안이다. 지역별 크기·출입구별 귀환 좌표·지도 관문 안내와 기존 A~D 연결 의뢰4개를 합쳐 Lv6→10·첫 전직·경제 정비·저장 복원까지 다룬다. 2장 전체/M7 전체 완료는 아니다.

보고 EXP15,000은 기존 초안 배정이며 추가 증액 아님. 1장 최소3,820과 합쳐18,820으로 Lv10 기준보다208 높다. 2장 메인 보고21,977 중 뒤2건6,977을 남긴다. 의뢰 골드2,250은 장 풀22,680에서 차감, 공훈500은 후반 장 마무리에 유지한다. 골드/시간 체감은 미검증이다.

현재 코드의 위험 지점을 대조했다: RegionRegistry는 map당 도착점1개, QuestNavigation은 현 월드 목표 조회/MQ05 fallback, SaveSchema는 지역·의뢰 카탈로그를 참조한다. 새 콘텐츠를 전역에 추가해 과거 검증까지 넓히지 않도록 버전별 규칙 선택과 격리 V6 후보를 제안한다. V4/V5 기본 경로와 기존 슬롯은 유지한다. M6 채택을 승인한 것으로 해석하지 않는다.

## 대조·재현

`git diff --check a304215..대상` 및 문서의 참조 경로 확인. 코드/데이터 변경이 없으므로 GUT·전투 배치를 재실행하지 않았다. 수치: `2000+3000+4500+5500=15000`, `3820+15000-18612=208`, `roundi(36628*0.6)-15000=6977`, `22680-2250=20430`. 새 기능 테스트 통과나 30~45분 도달을 주장하지 않는다.

## 검토 질문

1. 기존 A~D를 4개 메인으로 배정한 범위와 2장 후반 EXP/골드/공훈 유보가 정본 예산·서사와 양립하는가?
2. 출입구별 간선/도착점·다른 지역 목표 안내·토벌 source 분리가 실제 수락→보고→전직 동선을 닫는가?
3. V6 후보 및 버전별 지역/의뢰 검증 계약이 V1~V5 원본 의미와 기본/M6 저장 격리를 지키는가?

이 설계 검토 뒤 구현은 지도·NPC·의뢰·저장 전체를 한 번에 전달한다. 낮음 보완만 별도 검토하지 않는다.
