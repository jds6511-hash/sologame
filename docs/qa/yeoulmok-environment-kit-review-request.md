첫 측정에서도 드로콜과 화면 동일 결과는 같았다. **드로콜 감소는 확인했으나 FPS 향상은 입증하지 않는다.** 간격은 process_frame 사이 벽시계 시간으로 VSync/OS 대기·제한을 포함하며 GPU/CPU 작업 시간과 다르다. 순서는 항상 교대→묶음이고 표본120개라 통계적 성능 보장도 아니다. 움직이는 AI/투사체 부하·입력 체감·저사양 기기는 미측정. 표면 Sprite2D 수1,840은 줄지 않았으며 제품화 시 TileMapLayer 등 별도 검토가 남는다.

재현: 기존 native 실행 명령 뒤 `--surface-profile` 추가. `SURFACE_PROFILE_CONTEXT`와 위치별 `SURFACE_PROFILE` JSON이 stdout/지정 로그에 나온다. 자동 저장·입력 주입·제품 데이터 편집은 하지 않는다.
