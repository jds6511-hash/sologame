# 여울목 환경 표면·소품 가림 통합 검토

- 날짜: 2026-09-28 / 담당: Codex / 기준: `13a6e4c`
- 변경 이력: 원본 키트 리뷰 통과를 반영하고 다음 환경 타일 제작/배치까지 진행.

## 수신 리뷰 대응

1. `roof_overhang` 이름을 `roof_bounds`로 변경하고 `visible_wall`을 별도 기록했다. 집 처마 행36~38은 벽의 물리 footprint 위에 투영된다. 실제 그림 범위를 줄여 쓰거나 기존 충돌을 바꾸는 두 제안 대신, 투영 범위와 보이는 벽을 구분했다. 검사도 보이는 벽과 지붕의 분리·벽 끝 열의 실제 알파·문/계단의 실제 픽셀을 읽도록 추가했다. 전체 그림을 의미별로 자동 분류하는 검사는 아니다.
2. 벤치를 `(244,470)`→`(224,488)`로 이동했다. 실제 PNG bbox로 소품7개와 보호지점4개·동문 발밑 띠를 검사한다. 이전 위치로 환산하면 귀환점이 bbox 안에 들어감을 확인해 검출기의 음성 대조를 남겼다. 귀환 좌표 정지 렌더도 추가했다(실제 지역 왕복 실행과 구별).

## 다음 작업까지 구현한 범위

- 시트를 160×128로 확장: 초원2·흙길2·울타리3·관목2·갈대1, 총10타일 추가.
- 별도 비충돌 표면 레이어에 시작 마을 주변 초원/흙길만 표시한다. x3~21/y23~32, 현행 atlas 0행0~3열만 대상. 원래 TileMap 셀·충돌·물·성벽·의뢰 마커는 유지한다.
- 울타리6·관목3·갈대2 배치. 기존 도형 울타리/관목 중복 표시를 끈다. 끝/코너 울타리와 관목0은 시트에만 존재한다.
- 지면4종의 Rec.601 σ≤10·색별 평균 대비차≤40·흰색 금지·초원 녹색2종 제한을 검사한다. 타일별 정적 대비이며 스크롤 패턴이나 실제 전투 가독성 판정은 아니다.

## 변경 파일

`generate_yeoulmok_native_kit.py`, 키트 PNG/manifest/README, `yeoulmok_native_kit.gd`, `yeoulmok_art_pilot.gd`, `test_yeoulmok_native_kit.py`, `yeoulmok_art_pilot_probe.gd`, 이 문서와 진행 문서2개, 선별 증거3장. 제품 씬·저장·게임플레이 코드는 변경하지 않았다.

## 검증

- 신규 검사 최초 실행: 2 failures+1 error(시트 크기·구필드·tiles 미존재). 수정 후 **Python4/4 통과**.
- PNG/JSON 재생성 SHA-256 동일.
- 변경 GD3: gdformat unchanged, gdlint 성공.
- 새 키트/기본 도형/기존 생성 후보 모두 exit0, 각각 PASS. 새 키트 false0/SCRIPT ERROR0, 이전 벤치 가림 재현 true.
- 마지막 추가 귀환 캡처 포함 새 키트 재실행도 exit0/PASS.
- 전체 GUT·대화형 직접 조작은 이번에 실행하지 않았다. 작업 중 자동 들여쓰기 편집이 줄바꿈 차이로 실패해 미적용됐으며, 명시적 패치 후 위 렌더를 재실행했다.
- Pillow `getdata` 사용에 대한 향후 버전 폐기 경고가 있다. 현재 실행은 통과하며 무경고라고 주장하지 않는다.

명령은 [키트 README](../art/concepts/yeoulmok/native-kit/README.md)의 기존 생성/테스트/`--native-kit` 명령을 사용한다. 자동 캡처는 ignored 경로에만 기록한다.
