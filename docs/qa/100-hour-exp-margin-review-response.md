# EXP 여유 리뷰 반영 — 누적 공급 정정과 정본 목표

- 대상 `ff86d89` + `6214f34`. 판정: 정본 EXP 공급 목표에 반영 가능.
- 세 관문 최소1%와 기준 최종전 진입Lv98 명시는 수용했다. 제품/C1 적용·저장 호환·실제 플레이 승인은 아니다.

## 60,000 이동의 출처 정정

리뷰의 **S7→S11** 처방은 G80에서 효과가 없다. G80 식에는 `bonus[7]+bonus[11]`이 들어가므로 `440,000+2,060,000=2,500,000`으로 기존과 같다. G40만60,000 줄고 G80 여유는222,608에 남는다.

대신 **S12→S11**로60,000을 앞당겼다. S7은500,000 유지, S11은2,060,000, S12는2,799,780이다. 총5,359,780·G40·G95·포스트스토리 잔여는 불변이다. G80 기준/A/B 공급은31,817,200/30,235,009/28,539,808, B 여유282,608(약1.00013%). 요구된 최소282,572보다36 높다. 이것은 명목 모델 기준이며 광범위한 콘텐츠 편차를 견딘다는 뜻은 아니다.

## 최종전 레벨과 반영 파일

기준/A/B 최종전 진입98/96/95를 문서·도구에 고정했다. 보스95 유지 vs98 조정은 밸런스 승인 항목이며 지금은95 유지다.98로 자동 상향하면 B 경로의 난도가 변하므로 피해/스탯/회복·재시도까지 비교해야 한다.

성장·퀘스트 정본에 공급 총량·지급 위치를 실제 설계 목표로 추가하고, 컨셉/성장/퀘스트/공훈/경제/로드맵의 오래된 “생략 부족이 남음” 안내를 모델 통과/배선 미완료로 갱신했다. 수치 원본은 [여유 계약](../design/100-hour-exp-margin.md) 한 곳이다. 제품 데이터와 과거 증액 전 표는 바꾸지 않았다.

## 검증

1. 도구의1% 조건을 세 관문에 적용한 뒤 기존 표로 실행: **G80 margin below1%, exit1** 재현.
2. S12→S11 이동과 G80 표를 수정해 재실행: **EXP_MARGIN_MODEL_PASS, exit0**, 세 관문 B 여유521,943/282,608/578,104 및 최종 진입98/96/95 확인.
3. 기존 기초 풀 회귀·최종전 후 보상 제외·포스트스토리 잔여 검사 유지. 실제 엔진/GUT/플레이는 실행하지 않았다.

동일 리뷰를 다시 기다리지 않는다. 다음은 명시적 필수 의뢰 지급 순서·보상 버전 계약과 구 곡선 저장 호환 설계다. 현행 G4/G5 직접 플레이 이월은 유지한다.
