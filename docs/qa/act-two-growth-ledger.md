# 2막 성장 장부 — 기능 완료와 성장·분량 판정 분리

2026-10-03 / Codex. [승인 계획](../design/act-two-plan.md), [100시간 예산](../design/100-hour-progression-budget.md). 전투 자동 완주·사람 체감 기록이 아닌 **낮/C1 산술 모델**이다. 각 의뢰를 따로 수락하고 목표 처치 뒤 즉시 보고하며 기준 서브도 수행한다. 동시 수락·밤·추가 사냥이면 값이 달라진다.

|---|---:|---:|---:|---:|---:|---:|
| 1막 기존 표본 | — | 2~3장5,032 | 기존 기록 | 79,291 | 13 | 2~3장25,155 |
| 4장 모델 |79,291|5,655|198,351|283,297|19|79,353 |
| 5장 모델 |283,297|10,497|410,663|704,457|27|165,501 |

4장은 일반 Lv16 멧돼지6·Lv18 허수아비6·Lv21하피3을 별도목표로 센다. 5장은 예정 드롭 레벨24/27/29와 레벨차 배율을 반영해15처치다. 같은 출처 목표를 동시에 수락하면 필요한 총 처치 수가 줄어들 수 있으므로 위 모델이 최소 처치수 보장은 아니다. API 세션의 초기EXP는 이 모델을 fixture로 넣으며 실제 입력으로 앞 장을 완주한 결과라고 주장하지 않는다.

알려진 부족: 보고 예산은 정확하지만 처치 풀85,008/175,998 전체가 최소 목표에서 지급되지 않는다. 참고 종료레벨22/30보다3레벨 낮고, 시간예산5h/6h를 입증하지 못한다. 이를 자동레벨·무료EXP 주입이나 의무 반복사냥으로 덮지 않는다. 6장까지 기본/서브생략 경로와 장비 구매력을 모아 중간 체감에서 우선 판단한다. 부족을 ‘검증 통과’로 닫지 않는다.

변경 이력: 2026-10-03 4~5장 기본 산술을 별도 장부로 기록. 6장 수치·서브생략 A/B·실전 소요시간은 아직 미산출이다.
