- 2026-10-02 / Codex. 기준 `d9c9d9c`, 대상 **`f2348d6`** (로컬 완료·미푸시). [디렉터 결정](../DECISIONS.md), [구현 계획](../design/systems/content-integration-plan.md).
- Claude 결과는 `docs/qa/reviews/f2348d6.md`에 작성한다. 이번 묶음은 2장 기본 합류 승인에 따른 구현이며, 반복 직접 플레이나 3장 설계 재승인을 요청하지 않는다.

## 변경 요약

**제품:** 의뢰 13건·지역 5곳·관문 8개·NPC·표식·서식지를 통합 콘텐츠 목록으로 연결했다. 제품 월드는 기본 월드를 직접 상속하고 정적 씬으로 경제 컴포넌트를 배선한다. 기존 후보 월드의 `set_script` 사슬을 사용하지 않는다. 동결 후보 파일은 구 검증과 비교용으로만 남겼다.

제품 저장은 **형식 V6 / 콘텐츠 개정 1**이다. V1~V5는 동결 원본 검증 → 이관 → 통합 검증 순서다. 미래 개정·알 수 없는 ID·지역 잠금·의뢰 선행·공훈 합계를 검사하고 미래 개정은 백업으로 우회하지 않는다. 과거 QA 후보 V6/V7은 호환 대상이 아니다. 실제 저장을 불러오기만 해서는 쓰지 않으며 이관 후 직접 저장 전 자동 저장을 막는다.

`게임 실행.exe` 하나에서 기본 게임과 1·2·3장 준비 상태를 고른다. 준비 상태는 `user://product_chapter_preview`만 쓰며 3장 콘텐츠는 아직 없다. 과거 실행기는 ignored 보관 폴더로 옮겼다. 상태 표·결정 기록·인계·과거 이력을 분리했다.

**QA:** `verify_all.ps1`로 GUT·기존 API/이관·제품 2장 중간/완료 복원·실패 가드·실제 V4/V5 복사본 이관·원본 전후 해시를 묶었다. 오래된 M5·파일 중단 probe의 버전 기대값과 빈 QA 폴더 정리도 고쳤다. 파일 중단은 종료 직전 마커·정상 반환 금지·후속 파일 복구를 함께 검사한다. 자동 조작의 [공통 한계](automated-evidence-boundaries.md)는 그대로며 `-Combat`은 참고 옵션이다.

## 검증

**verify_all 107/107·exit0**, GUT **1,162/1,162**. 실제 V4 슬롯1·V5 슬롯3 복사본 이관/재시작 통과, 원본 6개 해시 불변. [상세 결과](content-integration-evidence.md). 시작 화면과 2·3장 준비 진입 렌더, 단일 exe smoke를 별도 확인했다. API 완료 준비·버튼 신호·실제 조작 증거를 혼동하지 않는다. 새 아트·체감·전투 반복 표본은 이번 검증 범위가 아니다.

기존 probe 종료의 Ogg 잔존은 verbose에서 알려진 Ogg 클래스만 확인되고 정확한 리소스 잔존 문구가 맞을 때만 비차단 경고로 JSON에 남긴다. 일반 ERROR/SCRIPT ERROR는 실패다. 기본 실패 가드도 실제 창·포인터를 사용한다. 오디오 잔존 해소를 주장하지 않는다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File docs/qa/tools/verify_all.ps1
```
