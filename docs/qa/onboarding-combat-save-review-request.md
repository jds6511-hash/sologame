## 구현과 원인

새 캐릭터로 대화 수락·실제 공격을 연결하자 `body_entered → attack_hit → take_damage → died → _spawn_item → add_child`에서 `Can't change this state while flushing queries` 엔진 오류가 발생했다. 기존 드롭 확률 단위 검사와 완료 fixture를 사용하는 여행 검증에서는 지나지 않았던 실제 물리 콜백이다.

`DropSystem`의 보상 판정과 `item_dropped` 신호 시점은 유지한다. 충돌 Area의 **인스턴스 생성과 월드 추가 모두** 메시지 큐로 넘긴다. 월드가 먼저 해제되면 예약 대상도 해제되고, 트리에서 빠졌거나 삭제 예약된 경우에는 추가하지 않는다. 새 월드를 검색해서 드롭을 옮기지 않는다. 드롭 확률·수량·골드 계산·퀘스트 신호·저장 형식은 바꾸지 않았다.

좌측 계약 리뷰의 잔상 주석은 flip_h가 아닌 방향을 근거로 정정했다. 잔상 동작과 PNG는 불변이다. 기존 원본 좌우 비교만으로 오른손 일관성을 보장할 수 없어, **전사 손 교체는 여전히 미해결**이며 전용 원화의 칼날/잔상 방향 검수를 남긴다.
