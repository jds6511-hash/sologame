## 변경

**제품:** 기본 main_scene와 `게임 실행.exe`를 M6/V5 제품 환경으로 연결했다. 새 게임·지역 이동·불러오기에도 같은 환경을 유지하며 기본 경로는 `user://saves`다. V1~V4 원본 검증 → 메모리 이관 → 명시 저장 시 V5/구 파일 백업 순서다. 로드만으로 슬롯을 재작성하거나 후보 파일을 복사하지 않는다. 손상 계정으로 경제 런타임이 없어도 F6가 기존 오류를 반환하도록 null 접근을 막았다. 기존 V4 검증기·후보 경로 규칙은 유지한다.

M7/V7 외곽 BGM은 필드 곡을 사용한다. V7 선택 의뢰를 공유 카탈로그에서 Journal의 문자열 UI 메타로 옮겼다. 지도·대화·추적·지역 이동이 같은 선택을 읽고, 미수락은 수락 NPC·진행/보고는 보고 NPC를 안내한다. 저장 버전·보상은 불변이다.

**QA:** 제품 전용 이관 fixture/렌더와 기존 M6 조작기를 재사용하는 제품 어댑터 추가. 실제 사용자 저장은 열거나 수정하지 않았다. 이전 `b666e49` 첫 점 생략의 `test_move`·거리별 구간 한도도 함께 검토한다([기록](m6-m7-adoption-evidence.md)).
