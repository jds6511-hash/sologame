## 1. 실행 방법 — **주의: 메인 씬이 지정돼 있지 않다**

`godot\project.godot`의 `[application]`에 `run/main_scene` 키가 **없다**(git 이력상 한 번도 없었다). 따라서 `godot`만 실행하면 게임이 뜨지 않는다. **씬 경로를 직접 줘야 한다.**

```bash
# 시작 지역 (게이트 본 세션 — G3-1·G3-3·O-1·O-3·O-4·O-6 관찰)
godot --path godot res://scenes/world/eastern_frontier_starting_area.tscn

# 신규 적 필드 (O-2 숲거미 군집 · O-7 포효 임프장)
godot --path godot res://scenes/world/m3_new_enemy_field.tscn
```

이 결함 자체는 게이트 판정 대상이 아니다(개발 편의 문제). 다만 정식 빌드 전에는 반드시 채워야 한다 — 게이트 후 처리 항목으로 등재할 것.

## 3. 운영 제약 — 반드시 지킬 것

- **2차 전직 관찰은 F11(전사 계통) 경로로만 가능하다.** `data\jobs\`에 궁수 상위 계통 데이터가 없다 — 디렉터가 M4 이월로 확정했다(D3-10). **Lv10에서 궁수를 고르면 Lv40에서 후보가 0개**다. 2차 전직을 볼 세션에서는 전사를 골라라.
- 레벨 점프는 정상 경로다 — `PlayerProgression.add_exp`에 필요 경험치를 넣는 방식이라 레벨업 시그널·스탯 성장·스킬 포인트 지급·전직 판정이 모두 정식으로 발생한다. 즉 **성장감 관찰(O-6)에 써도 유효하다.**
- 궁수 원거리 판정(G3-2)은 Lv10 전직 후 별도로 봐라.

## 6. 결과 기록 — 이 6분류로 나눠 적을 것

외부 리뷰(4.2절) 권고다. 분류를 섞으면 원인 진단이 어긋난다.

| 분류 | 뜻 | 기록 |
|---|---|---|
| **Blocker** | 진행이 막히거나 크래시 | |
| **전투 손맛** | 타격감·반응성·모션 | |
| **밸런스** | 수치 — TTK·난이도·성장 속도 | |
| **UX·가독성** | 화면에서 정보를 못 읽음 | |
| **메타 루프 부재** | "다음에 뭘 할지 모르겠다" | |
| **폴리시** | 있으면 좋은 다듬기 | |

**메타 루프 부재를 별도 분류로 둔 이유**: 현재 퀘스트·NPC·세이브가 없다(코드 0줄). 20~30분 플레이 후 다음 행동이 안 떠오른다면 그건 **전투가 나빠서가 아니라 목표 시스템이 없어서**다. 그 둘을 섞으면 엉뚱한 곳을 고치게 된다.
