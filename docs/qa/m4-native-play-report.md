## 발견 및 제한

1. **시작 지점에서도 저장 거부가 발생했다.** 새 캐릭터 생성 후 공격하지 않고 건물 앞에 정지한 상태에서 슬롯 2 저장이 `적에게서 떨어진 안전한 곳에서 저장하세요`로 거부됐다. 메뉴를 닫고 게임 시각 00:08→00:14 동안 기다린 뒤 같은 위치에서 재시도하니 성공했다. 화면에는 토끼형 개체가 보였지만 어느 개체가 차단했는지는 특정하지 않았다. `save_safety.gd`는 스포너의 모든 Node2D 자식을 거리 기준으로 검사한다. 안전 지역/개체 분류에 대한 후속 판단 근거이며, 이번 QA에서 기준은 바꾸지 않았다.
2. **조작 도구의 문자 키 전달 한계.** K 입력 로그는 `key=75 physical=4194313 device=16 menu_skill=false`였다. 프로젝트는 물리 키 코드를 사용한다. 따라서 이동·스킬 메뉴가 반응하지 않은 것을 게임 결함으로 확정하지 않는다. 입력 매핑을 QA 편의로 바꾸지 않았으며, 장비·강화 및 이동 위치 복원은 남겨둔다.
3. **종료 경고.** 재실행 후 로드·새 캐릭터를 거친 프로세스를 종료했을 때 `6 ObjectDB instances` 및 `2 resources still in use`가 출력됐다. 이번 UI/QA 런처 경로의 관측이며 기존 headless seed 16/4와 별개다. 원인·재현 범위는 미확정. 저장 유실은 관측하지 않았다.
4. 최초 1280×720 창 시도에서는 HUD가 잘리고 버튼 조작을 확인하지 못했다. 전체 화면에서 위 절차를 완료했다. 작은 창의 레이아웃과 좌표 전달 문제는 분리 진단이 필요하다.
