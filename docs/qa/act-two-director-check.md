# 2막 종료 체험 — 9장 구현 검증 후 사용

- 작성: 2026-10-03 / Codex. 대상: 디렉터. [2막 계획](../design/act-two-plan.md), [9장 설계](../design/systems/chapter-nine-defense.md).
- 기능 회귀·저장 복원은 자동 검증과 독립 검토로 처리한다. 이전 장을 다시 완주할 필요는 없다. 이번 체험은 재미·난이도 판단을 모으는 약30분 표본이다.

`게임 실행.exe`의 **9장 시작 체험**을 선택한다. 이전 의뢰 완료·레벨·골드가 준비된 QA 세션이며 실제 저장과 분리된다. 준비 캐릭터의 직업은 자동으로 바꾸지 않으므로 V에서 전직하고 사용할 무기를 착용한다. 필요하면 기존 기본 게임 저장으로 이어서 플레이해도 된다.

1. **도시 방어·보스(약15분):** 대피 구역의 진행·피격 중단이 이해되는지, 지원 장치가 도움이 되는지, 군후의 예고를 보고 피할 수 있는지 확인한다. 전사와 궁수 계열 중 평소 쓰던 직업으로 먼저 판단한다.
2. **성장·전투(약5분):** 현재 레벨과 장비에서 일반 적·군후 처치 시간이 지루하거나 급격히 어려운지 본다. 궁수는 먼 거리에서 공격했을 때 적의 반격·추격이 납득되는지 확인한다. 준비 상태는 전체 성장 속도를 증명하지 않는다.
3. **의뢰·영지(약10분):** 현장 보고가 왕복 부담을 줄였는지, 단서 오답 비용이 불쾌하지 않은지, 두 영지의 투자·주문·수입에 다시 이용할 이유가 있는지 본다. 이미 확인한 저장·상점 버튼을 반복 검사할 필요는 없다.

응답은 **2막 승인 / 조건부 / 보류 + 불편한 점**이면 충분하다. 새 아트·전사 좌측 원화·최종 미감은 후속이며 이번 기능 구현으로 승인했다고 기록하지 않는다.

변경 이력: 2026-10-03 9장 설계 검토 참고3에 따라 보류한 체감 항목을 한 번의 체험으로 모았다.
