## 제품

보고 EXP410,663(메인246,398/서브164,265), 골드135,150, 공훈1,150. 아르셀 입장에는MQ05-02, 도서관에는03완료를 요구하여03의 아르셀 보고가 자기 자신을 잠그지 않는다. 실제 플레이어 캡슐을 사용한 경로 검사로5지역의 NPC·표식·출구 접근을 확인했다.

살레노·아르셀 최초 방문 개방과 워프/귀환을 연결했다. 목적지 단가는 고정 참고Lv26/30, 기존 인접25/횡단60 규칙을 쓴다. 도시 UI는 등록 목록을 읽으며 도시 추가 때 버튼 목록을 중복 수정하지 않는다.

형식은V7 유지, 콘텐츠 개정4다. 생성기가 의뢰/지역 최초 개정 목록을 만든다. V7개정3 파일에5장 의뢰·지역·개방도시를 섞으면unsupported_content로 거부한다. 기존V7개정3은 파일 내용 변경 없이 불러올 수 있고 다음 정상 저장에서 개정4가 기록된다. V1~제품V6 동결 경로는 유지한다.
