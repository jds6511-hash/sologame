# 1막 종료 체감 확인 — 3장 구현 뒤 한 번

- 2026-10-02 / Codex. 디렉터 결정: 2장 기본 합류 후3장까지 개발하고,1막 종료에약30분 체감을 모아 확인한다. 지금 직접 플레이 요청이나 자동 일정 등록이 아니다.
- 변경 이력: 매 묶음 재완주 대신 대표 구간 한 번으로 범위를 고정.

| 시간 배분(가이드) | 확인할 경험 |
|---|---|
| 약5분 | 2장 시작 준비: 지도/의뢰 안내만으로 목적지를 찾고 상점에서 정비 |
| 약10분 | 원하는 전직으로 외곽/던전 전투. 명중·피해 가독성, 사거리·추격·포션 부담 |
| 약10분 | 3장 준비 상태: 대피·방어·현장 복귀·향사와 첫 영지의 변화 |
| 약5분 | 성장 속도·왕복 피로·불편한 안내를 정리하고 승인/조건부/보류 판단 |

준비 상태는 실제 저장과 분리하며 앞 장 재완주를 요구하지 않는다. 저장·복원·거래·보상 중복은 자동 검사로 확인하고 이30분을 같은 기능의 재검사로 쓰지 않는다. 최종 미감/완성 아트 평가는 리디자인 이후로 남긴다.

`게임 실행.exe` → **3장 시작 체험**을 선택하면 Lv11·2장 완료 준비 상태로 노베라 조합 거리에서 시작한다. 접수원 급보 수락 → 여울목 관문지기 보고 → 방어 현장 대피 → 집결지의 **방어 재개 [F]**에서 무리별 교전 → 그림자 흔적 조사 → 노베라 문장원 심사 순서다. 전직은 V로 선택할 수 있다. 최종 보고 후 C에서 향사·복구권을 확인한다. 서브는 하사 조건이 아니므로 전부 할 필요가 없다.

성장 참고: 이전 2장 완주 표본은 42,828 EXP(Lv11), 처치분2,380이었다. 3장 API 피해 fixture에서 보고33,811+처치2,652를 더하면79,291 EXP(Lv13)이다. 이는 정상 공격으로 걸린 시간이나 난이도를 증명하지 않는다. 원래 2~3장 처치 풀30,187 대비 표본 처치5,032로 차이가 크므로 실제 성장 속도에 대한 의견을 남긴다.

결과는 재미·난이도·성장감·길 찾기별 한 줄이면 충분하다. 이 자리에서는 기능을 처음부터 다시 검사하거나 최종 미감을 판정하지 않는다. 1막 체감 판정 전에는 2막·영지 경영으로 범위를 늘리지 않는다.

변경 이력(2026-10-02): 3장 대표 동선과 재개 조작, 누적 성장 수치를 반영.
