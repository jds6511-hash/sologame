# 1막 종료 체감 확인 — 3장 구현 뒤 한 번

- 2026-10-02 / Codex. 디렉터 결정: 2장 기본 합류 후3장까지 개발하고,1막 종료에약30분 체감을 모아 확인한다. 지금 직접 플레이 요청이나 자동 일정 등록이 아니다.
- 변경 이력: 매 묶음 재완주 대신 대표 구간 한 번으로 범위를 고정.

| 시간 배분(가이드) | 확인할 경험 |
|---|---|
| 약5분 | 2장 시작 준비: 지도/의뢰 안내만으로 목적지를 찾고 상점에서 정비 |
| 약10분 | 원하는 전직으로 외곽/던전 전투. 명중·피해 가독성, 사거리·추격·포션 부담 |
| 약10분 | 3장 준비 상태: 대피·방어·현장 복귀·향사와 첫 영지의 변화 |
| 약5분 | 성장 속도·왕복 피로·불편한 안내를 정리하고 승인/조건부/보류 판단 |

준비 상태는 실제 저장과 분리하며 앞 장 재완주를 요구하지 않는다. 저장·복원·거래·보상 중복은 자동 검사로 확인하고 이30분을 같은 기능의 재검사로 쓰지 않는다. 최종 미감/완성 아트 평가는 리디자인 이후로 남긴다.

3장 구현 시 대표 위치/실행 방법을 업데이트한다. 지금 미구현3장을 체험 가능한 것처럼 안내하지 않는다. 결과는 재미·난이도·성장감·길 찾기별 한 줄이면 충분하며 통합 결정을 DECISIONS에 기록한다.
