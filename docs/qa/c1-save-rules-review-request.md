- 설계 리뷰는 반영했다. 이번 요청은 새 규칙/검증기 구현 대상이다. C1 제품 곡선·V3 배포 승인 요청이 아니다.

1. 구 규칙 스냅샷99개·스킬 비용/관문이 현행 V1/V2 의미를 보존하는가? 후보 수식 및 초반18,612 보존이 맞는가?
2. 지원 버전 확인→규칙 객체 인자 전달→의뢰 V2/V3 검증 경계에 누락이 있는가? 교차 호출과 JSON 버전 처리에서 이전 규칙이 남거나 정상 백업이 거부되는가?
3. `candidate_character_error`만 V3를 검사하고 실제 codec/store는 계속 거부하는가? 검증만으로 payload·플레이어·파일이 변하지 않는가?
4. 기존 계정/거래/콘텐츠 오류와 직업·실지출·vitals 검증이 약해졌는가?
5. 단위 B 착수 전에 필요한 보완이 있는가? 실제 혼합 세대 파일 복구와 V3 쓰기는 C 단위로 남겼다.
