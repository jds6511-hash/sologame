# M7 첫 구간·2장 후반 채택 확인

> **2026-10-02 운영 변경:** 아래 두 구간 직접 완주는 개발 진행의 필수 조건이 아니다. 기능 증거/독립 검토를 유지하고 체감 평가는 큰 마일스톤으로 모은다. 이 문서는 원할 때 확인하는 선택 체험 안내다. M7 기본 채택 승인으로 자동 해석하지 않는다. 다음 3장 설계를 진행하며, 매 묶음 디렉터에게 재완주를 요구하지 않는다. 변경 이력: 반복 직접 테스트 요구 철회.

- 작성/최종 수정: 2026-10-01 / Codex.
- 근거: [기존 완주 증거](m6-m7-adoption-evidence.md), [첫 구간 설계](../design/systems/m7-novera-first-loop.md), [후반 설계](../design/systems/m7-chapter-two-closure.md).
- 변경 이력: M6 기본 반영 직접 확인·독립 검토 통과 후 M7의 두 채택 범위를 정리.

## 현재 판정

M6/V5는 디렉터가 기존 저장 불러오기, 구매/착용, 저장 후 재실행의 세 항목에 **“123 다 잘된다”**고 확인했고 `99491bd` 독립 검토도 통과했다. M6를 다시 승인 대기로 두지 않는다. M7/V6·후반 V7의 기본 반영 승인은 아직 별도다.

## 1. 첫 구간 — M7 노베라 테스트.exe

1장 완료·누적 EXP3,820·560골드를 준비한 노베라 입구에서 시작한다. 기본 게임이나 M6 저장을 가져오는 실행기가 아니다.

1. 동쪽 관문으로 조합 거리에 들어가 접수원에게 의뢰를 받는다.
2. 지도 **M**과 의뢰 **J** 안내로 외곽의 처치·조사 목표를 찾아, 접수원 보고까지 네 의뢰를 진행한다.
3. 네 번째 보고 후 Lv10과 전직 **V**를 확인한다. 왕복 거리, 적 강도, 포션/골드 부족, 목적지 안내가 불편한지 판단한다.
4. 중간에 F6 저장 후 종료·재실행·불러오기로 의뢰 진행과 위치를 이어 본다.

판정 범위: 첫 네 의뢰·거점/외곽·전직 도달 흐름의 기본 반영 허용 여부. 자동 검사는 이 흐름을 고정3회 통과했지만 사람의 길 찾기·반복 왕복 체감은 별도다.

## 2. 후반 — M7 균열 던전 테스트.exe

앞 네 의뢰 완료·누적 EXP18,820·2,810골드·공훈100 상태로 조합 거리에서 시작한다. 첫 구간을 다시 할 필요가 없다.

1. 접수원에게 **균열 안쪽의 기록**과 원하는 서브 의뢰를 수락한다.
2. 외곽의 균열 관문을 통해 던전에 들어가 처치·조사·기록 목표를 진행하고 돌아와 보고한다. 의뢰 선택을 바꾸면 지도와 추적 안내도 맞는지 확인한다.
3. **신참의 귀환**은 접수원에게 수락한 뒤 가레스에게 진행·보고한다. 장 완료 후 누적 공훈은600이다.
4. 던전에서 중간 저장·재실행 복원을 확인한다. 마지막 보고 뒤 미구현 3장으로 가라고 안내하지 않는지도 본다.

판정 범위: 후반 메인2·기본 서브2·던전 왕복·장 마무리의 기본 반영 허용 여부. 서브는 필수가 아니고, 완료해도 Lv12를 보장하지 않는다. 기존 자동 표본은 Lv11/누적 EXP42,828, 처치 EXP2,380이었다. 이것을 장 전체 성장 균형 검증으로 해석하지 않는다.

## 저장·피드백

- 두 실행기는 매번 준비 상태로 시작한다. 이어 할 때는 **F6 → 불러오기**를 사용한다.
- 첫 구간은 `user://m7_candidate_quick_play`, 후반은 `user://m7_closure_candidate_quick_play`다. 서로와 기본 `user://saves`가 분리된다. 슬롯을 직접 복사할 필요가 없다.
- 완성 아트·세부 상점 UI 평가는 기존 지시대로 보류한다.
- 결과는 **첫 구간 / 후반 각각 승인·수정 후 승인·보류**와 불편한 점만 적으면 된다. 한쪽 승인만으로 다른 쪽까지 승인하지 않는다.

기능 검토는 이미 통과했으므로 이 안내만으로 Claude의 별도 재검토를 요청하지 않는다. 채택 판단 뒤 기본 V5→V6→V7 배선/이관을 제품 묶음으로 구현·검증한다. BGM 종료 Ogg 잔존은 그 묶음에서 재현·해제 경로를 확인하며 현재 해결됐다고 주장하지 않는다.
