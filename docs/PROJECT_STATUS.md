## 6. 250시간 콘텐츠 배분 종합

세 문서(growth 5-3 / quest 9장 / collection 6장)의 배분을 대조한 결과 **총량 모순 없음**. 단 회계 프레임이 다르므로 아래처럼 읽는다.

| 축 | 배분 | 출처 |
|---|---|---|
| 성장 축 | 만렙(Lv100) 도달 약 **200h** + 만렙 후 완성 콘텐츠 순수 잔여 약 **50h** | growth 5-3 |
| 콘텐츠 축 (250h 전체) | 메인 65h(26%) + 서브 105h(42%) + 반복·이벤트 17h(7%) + 전직·히든 직업 8h(3%) + 히든 체인 3h(1%) + 퀘스트 외(자유 사냥·수집·영지·이동) 52h(21%) | quest 9장 |
| 만렙 후 50h 세부 | 몬스터 도감 14h / 아이템 도감 12h / 펫 10h / 칭호 6h / 영지 4h / 이벤트 순회 4h | collection 6장 |

- 정합 확인: ① quest의 퀘스트성 195h는 이동·전투 포함 계상이라 growth의 "경험치 활동 50%" 전제와 상충하지 않음 ② collection의 만렙 후 50h는 quest의 "퀘스트 외 52h" 안에 수납되는 관계(동일 계산법 명시됨) ③ 메인:비메인 ≈ 1:2.8 (story의 1:2.5 상정과 근사) ④ 퀘스트 경험치 45% 예산: 메인 3,600 + 전직 500 + 서브 20,400 ≈ 24,500마리분으로 quest 1장이 growth 곡선에서 정확히 역산함.
- 유의: 이 배분의 전제(서브퀘 평균 13분, 사냥 사이클 12초)는 M2 수직 슬라이스에서 실측 후 quest 9장·growth 5-3의 지정 레버로만 조정한다.
