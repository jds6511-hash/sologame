### 5-2. 기획 결정 — **남은 2건 (둘 다 비차단)**

## 6. 250시간 콘텐츠 배분 종합

세 문서(growth 5-3 / quest 9장 / collection 6장)의 배분을 대조한 결과 **총량 모순 없음**. 단 회계 프레임이 다르므로 아래처럼 읽는다.

## 8. M2 — 수직 슬라이스 범위 (초안 확정)

정합성 재검증으로 각 문서의 M2 지정 항목이 상호 정합함을 확인했다. 아래를 **M2 범위 초안 확정본**으로 삼고, 세부 일정·태스크는 M1 승인 직후 별도 M2 계획 문서(producer)에서 확정한다. 목표: **"전사 1직업 + 몬스터 3종으로 손맛 기준선을 만들고 디렉터가 직접 플레이하여 재미/난이도를 승인한다."**

| 영역 | 범위 | 근거 |
|---|---|---|
| 전투 코어 | 전사 1직업(스킬 규격 준수) + 몬스터 3종 + `HitFeedback` 타격 피드백 모듈(약/중/강 3프리셋) + 디버그 전투장 | combat 9-1·13장 |
| 손맛 게이트 | 타격감 기준선을 디렉터 플레이로 승인 → 프리셋 확산 (A안 확정 조건이었던 "튜닝 반복 기간"을 M2 일정에 반영) | combat-options 9장 |
| 맵 | 동부 변경 시작 지역(여울목~노베라 들녘, Lv1~12 밴드) 일부 + 타일셋 1종 | world-structure 2장, STYLE_GUIDE 8장 |
| 아이템·경제 | 스타터 아이템 표(economy 3-1) + 드랍·골드 공식 구현 | economy 3-1·12장 |

| 검증 | 데미지 공식·TTK·드랍/골드 유입 GUT 자동 테스트 | combat 13장, economy 12장 |

| **게이트** | **디렉터 직접 플레이 — 재미/난이도 승인** + 픽셀 스케일·팔레트 최종 확인(D-20) | 마일스톤 규칙, STYLE_GUIDE 9장 |
