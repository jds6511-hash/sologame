**현재 소스는 제품V7/개정6이며 7장 통합 검증 중**입니다. 마지막 완료 통합 검증은 개정5의 중간 체감 보완 `4c4b2c2`입니다. 기존 V1~제품V6는 동결 검증 후 이관하며, 같은V7의 이전 개정 진행도 보존합니다. 실제 저장에 새 장 완료나 보정 레벨을 넣지 않습니다.

4장 단일 검증120/120, 5장126/126은 완료했습니다. 6장 구현 체크포인트는 `a29824b`이며 [증거](qa/chapter-six-evidence.md)에 최종132/132·GUT1236/1236·실제저장6개불변을 기록했습니다. 시작 화면은1~6장 준비 체험을 제공하며 QA 경로만 사용합니다.

[2막 중간 확인](qa/act-two-midpoint-check.md)은4~6장 여행·전투·영지를 한 번에 다룹니다. 반복 재완주를 요구하지 않습니다. [성장 장부](qa/act-two-growth-ledger.md)는6장 기준경로Lv35/메인만Lv30과 G40 위험을 공개합니다. 보고 예산 일치가 시간·성장감 합격을 뜻하지 않습니다.

[2차 전직 상세 설계](design/systems/second-job-chapter-seven.md)는 `564e2cc`에서 통과했습니다. 7장 메인6·서브13건, 훈련장 시련2건, 명사수 집중·전용 스킬과 별도 프로세스 저장 검사를 통합하고 있습니다. 첫 보고 공식 B 공급은 Lv39로 G40보다127,360EXP 부족하며 보상 재배분 결정 전까지 그대로 공개합니다. [8장 남작 상세 설계](design/systems/chapter-eight-barony.md)는 다음 새 시스템 검토용 초안이며 구현하지 않았습니다. 9장 군후·추가 서브·새 아트도 미구현입니다.
