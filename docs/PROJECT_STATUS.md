## 현재 범위

[구조 통합 계획](design/systems/content-integration-plan.md)의 콘텐츠 목록·제품 월드·저장·실행기·검증·문서 정리를 하나의 제품 묶음으로 진행한다. 제품 V6는 과거 후보 V6와 다른 계약이며 후보 V6/V7 저장 호환은 포기한다. 실제 V1~V5는 동결 원본 검증 후 이관한다.

디렉터의 기존 M6 세 항목 직접 확인은 유효하다. 다음 매 묶음 직접 재완주를 요구하지 않는다. 2장 기본 합류 승인은 받았으며 재미·난이도·성장감은3장까지 끝낸 뒤1막 종료에30분 한 번으로 모은다.

검증 완료 결과와 대상 커밋은 통합 검토서로 연결한다. 이전 자동 완주 표본의1/3·2/3·3/3을 새로운 코드의 통과로 재사용하지 않는다. 전투 자동 조작은 참고 옵션이며 채택 조건이 아니다.

변경 이력: 2026-10-02 누적 ‘현행’ 문단을 이력으로 이동하고 상태 표 하나로 통합.
