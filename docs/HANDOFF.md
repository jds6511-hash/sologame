## 주의 사항

- 실제 `user://saves`는 검증 전후 해시와 복사본 시험을 위한 읽기만 허용된다. 이관 테스트는 QA복사본에서만 한다. 원본을 테스트 결과로 덮어쓰거나 복원/삭제하지 않는다. 실행 중 게임이 원본을 바꾸면 해시 검사를 실패로 남기고 원인을 구분한다.
- 기본 제품V6와 과거 후보V6는 다른 계약이다. 후보V6/V7은 호환 보존 대상이 아니다. 실제V1~V5의 원본 검증 순서는 보존한다.
- 테스트 준비 상태/버튼신호/API/정상입력 증거를 구분한다. -Combat은옵션이며 통과할때까지반복해표본을고르지않는다.
- 기존 타인 PNG9개·미추적파일·실행중 게임/과거프로세스는 임의 수정/종료/커밋하지 않는다. 명시경로만스테이징한다.
- BGM 종료 시 Ogg 잔존 경고는 발견 기록이며 해소를 주장하지 않는다. 이번 요청은 새 BGM/아트 범위 밖이다.
- 로컬 커밋과 원격 반영을 구분한다. 푸시하지 않았다면 미푸시로 기록한다.

변경 이력: 2026-10-02 과거 인계를 보관하고 다음 작업/주의 사항만 남김.
