## 주의 사항

- 실제 saves는 해시 확인·QA 복사본으로만 검사한다. 실행 중 게임이 파일을 바꾸면 불변 검증 실패로 기록하고 복원하지 않는다.
- V1~제품V6 동결 검증 의미와 V7 이전 콘텐츠 개정 검증을 유지한다. 콘텐츠 추가만으로 형식 버전을 올리지 않는다.
- API는 이전 진행·위치·피해·시간·재료 fixture를 쓴다. OS 클릭·전투 완주·장별 시간·장비 구매력을 입증하지 않는다. 기존 Ogg 종료 잔존은 미해결이며 로그에 별도 집계한다.
- 다른 작업자의 m5 PNG9개·로그·미추적 파일을 스테이징하지 않는다. 명시 경로만 커밋한다. 원문 리뷰를 수정하지 않는다.
- 커밋과 푸시는 각각 결과를 확인한다. 원격 origin/master의 기존 허용 범위와 현재 요청을 따르며, 성공하지 않은 푸시를 완료로 보고하지 않는다.
