## 2. 즉시 결정 대기 1건 — 여기서부터 시작해라

### 무슨 일이 있었나

지형 타일의 대면적 대비가 과해 눈이 피로한 결함이 있었다(게이트 세션의 재미/난이도 판정을 오염시킬 리스크). art-director가 규칙을 확정하고(`ae0c792`) pixel-artist가 구현했다(`bfcad22`).

**결과: 지표는 전부 통과했으나 초원이 초록으로 읽히지 않는다.** 같은 명도의 회청 `#5a6988` 30% + 적갈 `#be4a2f` 10%를 섞는 처방이라, 초원이 주황 반점밭(자갈·낙엽 더미)으로 보인다. 물은 밝은 청록 금지로 짙은 남색이 됐다.

측정치만 보면 초원이 σ_L 1.35로 10종 중 최우수다. **지표를 만족시키는 방향이 화면을 망친 경우다.**

### 이미 계산해 둔 대안 (재계산 불요)

초원을 같은 색조(초록)로만 만드는 배합 전수 계산 결과. 상한 σ_L 10을 통과하는 것은 **하나뿐**이다.

```
D  green 92% + deep_green 8%       σ_L  9.30  span 34.3   ← 유일 통과
A  green 95% + fresh_green 5%      σ_L 10.47
C  green 92% + 어둠 5% + 밝음 3%    σ_L 11.31
F  green 88% + 어둠 6% + 밝음 6%    σ_L 14.43
현행 커밋본(교차 색조)              σ_L  1.35
개정 전(원래 결함 상태)             σ_L 22.48
```

물은 청색 계열만으로 답이 없다 — 최소가 `blue 90% + navy 10%`로 **σ_L 14.40**, 상한 12 초과. 개울은 시작 지역에서 좁은 띠라 "대면적 지면" 분류 자체가 과했다고 본다.

### 권고 (디렉터 판단 대기 중)

**초원 2종은 D안으로 교체, river_water는 대면적 지면 분류에서 예외 처리.** 지시를 받으면 art-director에 배합표 정정 → pixel-artist 재생성 순서로 넘긴다. 디렉터가 "지금 상태로 직접 보고 판정한다"를 택할 수도 있다 — 그 경우 게이트 세션에서 초원 룩을 관찰 항목에 넣어라.

## 6. 절대 지켜야 할 작업 규칙

- **모든 산출물 한국어** (문서·게임 텍스트·커밋 메시지). 커밋 접두사 `feat:`/`fix:`/`docs:`/`chore:`.
- **스포일러는 `docs\design\spoilers\`에만.** 디렉터 보고에는 "반전 요소 작업 완료" 수준으로만 쓴다.
- **싱글플레이 PC 전용.** 멀티플레이·서버·PvP·수익 모델 작업 금지.
- **API 키는 환경 변수만** (`GEMINI_API_KEY`, `PIXELLAB_API_KEY`). 이 프로젝트는 `.env` 파일을 쓰지 않고 `.gitignore`에도 없다. 코드·문서·커밋에 하드코딩 금지.
- **`git add .` 절대 금지.** 에이전트마다 `git commit --only <자기 경로>`로 범위를 못박는다. 이 프로젝트에서 다른 에이전트의 스테이징을 흡수한 사고가 2번 있었다. 미추적 파일은 같은 명령에 `git add -N <경로>`를 먼저 붙여야 한다(`--only`가 미추적 경로를 거부한다).
- **`godot/project.godot`은 어떤 경우에도 스테이징하지 않는다.** `godot --import`가 설정 키를 지운 이력이 있다. 임포트 전 백업 복사 → 실행 후 diff 확인이 절차다.
- **커밋 금지 경로**: `godot/assets/tools/_raw_src/`, `docs/qa/screenshots/`, `_preview_*.png`, `.import` 파일.
- **서브에이전트에 `model:` 프론트매터를 넣지 않는다** — 디렉터가 설정한 세션 모델을 상속한다(2026-08-20 확정).
- **QA 리포트는 휘발성** — 지적 사항이 전부 반영되면 리포트 파일을 삭제한다.
- **BGM·음악 작업은 디렉터 별도 지시까지 착수 금지.**
- **토큰 절약**: 에이전트에 읽을 파일·절을 명시해라. 스크린샷은 리포트가 의심될 때만. 다만 **검증 자체를 생략하지는 마라** — 줄일 것은 중복 읽기다.

## 8. 이번 세션에서 실제로 밟은 함정 (반복 방지)

1. **`≤15` 목표를 팔레트 제약과 대조하지 않고 착수 지시로 넘길 뻔했다.** 동부 서브팔레트 3색(`#733e39`→`#b86f50`→`#e4a672`)만 보면 최소 명도차가 49.3이라 "EDG32에서 불가능"으로 보인다. 실제로는 온색 계열 **전체**의 인접 단차가 1.1~11.9까지 촘촘하다(`#d77643` 141.2 → `#c28569` 148.0 = 1.1). **팔레트 판단은 계열 전체를 보고 해라.**
2. **지표를 max-min으로 잡으면 픽셀 1개에 튄다.** 면적가중(σ_L)으로 바꾼 뒤에야 게이트로 쓸 수 있게 됐다. 다만 **σ_L 통과가 룩 통과를 뜻하지 않는다** — 이번 초원이 그 반례다. 아트 작업은 수치 게이트 + 4배 프리뷰 육안 확인을 **둘 다** 해라.
3. **커밋 범위를 파일명 패턴으로 고르면 호출 대상이 빠진다.** 과거 `a0113f4`가 사망 시퀀스만 담고 그것이 호출하는 `player_controller.gd`·`inventory_component.gd`를 빼먹어 월드 씬에서 터지는 트리를 커밋했다(`a1eee91`로 보충). **커밋 전 diff를 다 읽고 범위를 정해라.**
4. **`git commit --only`는 미추적 경로를 거부한다** (`did not match any file(s) known to git`). 같은 명령에 `git add -N`을 먼저 붙여라.
5. **`gdlint`는 클래스당 공개 메서드 20개 상한이 있고 테스트 함수도 공개 메서드로 센다.** 기존 테스트 파일에 함수를 더하다 상한을 넘으면 파일을 분리해라(`test_integrated_menu_death_block.gd`가 그렇게 생겼다).
6. **PNG 내용이 바뀌면 Godot 재임포트가 필요하다.** 안 하면 `No loader found for resource` 로 테스트가 대량 실패한다.
7. **Bash 도구로 한국어를 다룰 때 인코딩이 깨진다.** `PYTHONIOENCODING=utf-8` + `io.open(..., encoding="utf-8")`를 써라. Python 문자열에 Windows 경로를 넣을 때 `\a`가 BEL로 해석돼 `.claude\agents`가 `.claudegents`로 깨진 사고가 있었다 — 원시 문자열(`r"..."`)을 써라.

## 9. 테스트가 닿지 않는 구멍 (외부 리뷰 6.1·6.2절 검증 결과)

- **`player.tscn`에 `Inventory` 자식이 없다.** 월드 씬이 붙인다(`eastern_frontier_starting_area.tscn:40`, `m3_new_enemy_field.tscn:31`). `player.tscn`을 인스턴스화하는 씬 4개 중 2개만 붙이므로, 디버그 씬 2개(`debug_combat_arena.tscn`, `player_debug.tscn`)에서는 사망 시 골드 패널티가 **조용히 no-op**한다(`player_death_sequence.gd:115-118`이 null이면 return). 버그가 아니라 **테스트 커버리지 구멍**이다.
- **같은 종류의 배선 누락은 다른 곳에 없다.** `get_node_or_null` 대상 19종·하드 `get_node` 12건·`$자식` 참조 40여 건을 전수 대조한 결과 `Inventory` 외에는 전부 실재한다(autoload `HitFeedback`·`GameClock`·`BgmManager` 포함). 리뷰가 우려한 "같은 패턴이 다른 시스템에도 있는지"의 답은 **아니오**다. 재감사 불요.
