[증거](qa/chapter-four-territory-evidence.md)를 기준으로 통합 검토한다. `1207aeb` 설계는 [통과](qa/reviews/1207aeb.md)이며 원문을 보존했다. 할인은 공훈 구간, 구 저장 노베라 개방은 MQ-01-05 완료로 정정했다. 8장 남작 회계는 아직 구현하지 않았다.

검증은 `verify_all.ps1` 하나로 진행한다. GUT 1,219개 통과 후 기존 QA의 미래 버전 검사가 제품 V7을 거부하는 오래된 기대값임을 확인해 V8/V9로 수정했다. 실패 배치는 보존하며 최종 결과를 별도로 기록한다. 실제 저장은 해시 확인과 QA 복사본 이관만 한다.

## 주의 사항

- 새 묶음·커밋·다음 요청 직전 `docs/qa/reviews/`를 확인한다. 원문은 수정하지 않는다. 중간 이상은 우선 수정, 낮음·참고는 다음 제품 묶음에 반영한다.
- 실제 `user://saves`는 변경하지 않는다. 실행 중인 게임이 해시를 바꾸면 검증 실패로 남기며 원본을 복원하지 않는다.
- 제품 V6는 옛 QA 후보 V6와 다르다. V1~제품 V6는 동결 검증 후 V7로 옮긴다. 동결 카탈로그가 참조하는 기존 의뢰 리소스를 나중에 수정한다면 그 리소스도 동결해야 한다.
- API 진행은 위치·피해·이전 장 상태·시간 fixture를 사용한다. 정상 입력 전투 완주나 100시간 분량을 입증하지 않는다. 처치 EXP 부족과 실제 레벨은 보고 EXP 예산과 구분한다.
- Ogg 종료 잔존은 타입 근거가 있는 알려진 경고만 별도 기록한다. 일반 오류를 무시하지 않는다.
- 기존 PNG 9개·타인 미추적 파일은 수정·스테이징하지 않는다. 명시 경로만 커밋한다.
- 디렉터가 `origin master` 전송을 승인했다. 로컬 커밋과 원격 반영은 각각 확인한다. `게임 실행.exe`는 현재 소스와 설치된 Godot을 사용하는 실행기다.

변경 이력: 2026-10-03 설계 대기 문단들을 이력으로 옮기고 4장 통합 검증과 5장 후속 작업으로 갱신.
