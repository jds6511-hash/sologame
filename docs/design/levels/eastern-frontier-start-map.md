## 0. 환경 아트 파일럿 연계 (2026-09-14)

[환경 아트 방향 및 여울목 파일럿](../../art/environment-style-direction.md)은 **여울목 부락 안전 구역을 첫 시험 구역**으로 삼는다. 본 문서의 48×36 좌표, 동문·2타일 도로·여울의 통행, 플레이어/NPC/몬스터·퀘스트 마커, 기존 충돌 키는 파일럿의 고정 입력이다. 건물·울타리·소품을 시험 배치할 때도 길과 광장, 관문 밖 교전 시야를 우선 확인한다. 시각 파일럿만으로 새 건물 충돌이나 상호작용을 확정하지 않는다.

현재 맵 생성기의 `RIVER_Y = (13, 15)`는 물줄기를 **3행**으로 그리며, 여울 x=8~10만 모래로 통과시킨다. `STYLE_GUIDE.md` 3-2-3-6절의 `river_water` 예외는 **연속 폭 2타일 이하**다. 물가 타일을 늘리기 전에 실제 연속 수면 폭과 가이드 적용 범위를 함께 판정하고, 충돌·여울 동선을 임의로 바꾸지 않는다.

## 1. 좌표 체계

- 타일 크기 16px, 맵 그리드 **48열 × 36행** (월드 픽셀 크기 768×576px).
- 좌표 표기 `(x, y)` — x는 열(동쪽으로 증가), y는 행(남쪽으로 증가). 타일 (0,0)은 맵 좌상단.
- 화면 실효 가시 영역은 20×11.25타일(`PIPELINE.md` 1장) — 본 맵은 가로 약 2.4화면 × 세로 약 3.2화면 규모.
- 씬 파일: `godot\scenes\world\eastern_frontier_starting_area.tscn`
- TileSet 리소스: `godot\assets\tiles\eastern_frontier_tileset.tres` (소스 텍스처 `eastern_frontier_tileset.png`, 16×16, 4열×4행)
- 생성 스크립트(재현용): `godot\scripts\tools\generate_eastern_frontier_start_area.gd` — `godot --headless --script res://scripts/tools/generate_eastern_frontier_start_area.gd`로 재실행하면 동일 결과물을 재생성한다 (좌표 상수를 이 문서와 동일하게 유지).

## 2. ASCII 개요도 (구역 스케치)

실제 그리드는 48×36타일이며, 아래는 구역 배치를 파악하기 위한 스케치다(1칸 ≠ 1타일, 좌표는 3장 표 기준).

```
y=0   ┌──────────────────────────────────────────────┐  (맵 북쪽 경계 — 바위, 충돌)
      │        [균열 점액 지역]                        │
      │   ▲슬라임A   ●균열굴어귀(9,5)   ▲슬라임B       │  ← MQ-01-04 REACH 지점
      │        (균열 흉터 대지 + 폐허 잔해 + 바위)       │
y=10  │        │오솔길(x=9)                            │
      │  ══════╪═════ 여울목 개울물 (도섭 지점 x=8~10) │
      │        │                    [들개 마수 지역]    │
y=18  │        │              ▲DogPackA  ▲DogPackB      │
      │  ┌───┐ │  [뿔토끼 서식지/개척 농지]              │
      │  │부락│═╪══════ 대로(노베라 방향) ═══════════════╡→ 노베라 방향 출구(47,26~29)
y=27  │  │Ｎ★│ │ ▲RabbitA ▲RabbitB ▲RabbitC              │  (MP-3 범위 밖, 씬 전환 예정)
      │  │Ｐ⚑│ 대문(17,27~29)                            │
      │  └───┘                                          │
y=35  └──────────────────────────────────────────────┘  (맵 남쪽 경계 — 바위, 충돌)
      x=0                                              x=47
```

범례: `Ｎ`=NPC(조합 순회 접수원) `Ｐ`=플레이어 시작 지점 `⚑`=부락 중심(깃발, 거리 측정 기준점) `▲`=몬스터 스폰 마커 `●`=퀘스트 REACH 지점 `═`=대로/개울 `│`=오솔길

## 4. 충돌 지형 (TileSet 물리 레이어)

| 타일 키 | 인덱스 | 충돌 | 배치 목적 |
|---|---|---|---|
| `river_water` | 5 | 있음 (16×16 전체 폴리곤) | 여울목 개울물 — 도섭 지점 제외 전 구간 |
| `stone_wall` | 9 | 있음 | 부락 방벽 — 대문 구간만 개방 |
| `rock_small` | 14 | 있음 | 맵 경계 바위, 들개 지역 거친 지형, 균열 굴 어귀 테두리 |
| `riverbank_sand` | 6 | 없음 | 도섭 지점 — 강 통과 허용 지점 |
| 그 외 전 타일(`grass_*`, `dirt_*`, `tilled_soil`, `stone_floor`, `wood_plank`, `wood_fence`, `flag_banner`, `cracked_ground`, `rubble_stone`, `bush_small`) | — | 없음 | 배경/장식 |

- 물리 레이어 0의 `collision_layer = 1` — 플레이어 `CharacterBody2D` 기본 충돌 레이어(1)와 그대로 충돌하도록 커스텀 레이어 없이 기본값을 사용했다 (현재 프로젝트에 별도 물리 레이어 컨벤션이 없음 — 후속 태스크에서 레이어 체계가 정식 도입되면 재조정 필요).
- `wood_fence`(농지 경계 울타리)는 장식용으로만 배치했고 충돌을 주지 않았다 — MP-3 지시("물/방벽/바위")에 명시된 3종만 충돌 처리했다는 점을 알려둔다(공지 사항, 4-1 참고).

### 4-1. 알려진 단순화 사항

- 농지 울타리(`wood_fence`)는 시각적 구획선이며 통행을 막지 않는다. 통행 차단이 필요하면 후속 태스크에서 별도 충돌 추가.
- 들개 지역의 `rock_small`은 "거친 지형" 연출용으로 4곳만 고정 배치했다 — 통행로(대로·오솔길)와 스폰 마커 좌표를 침범하지 않도록 좌표를 수동 검증했다(6장 참고).

- 숲거미 계열은 **Lv10(밴드 8~16)**이므로 Lv1~4 권역(부락·뿔토끼 서식지·대로, y≥18)에는 두지 않았다. 여울목 개울(y=13~15, 도섭 지점 x=8~10만 통행)이 자연 게이트 역할을 한다.
- 무법자(Lv14)·노상강도(Lv20)·밀렵꾼(Lv36)·임프(Lv16)·포효 임프장(정예)은 본 맵 밴드(Lv1~12)를 넘어 **배치하지 않았다** — 근거는 `m3-new-enemy-placement.md` 3-1장.

- 균열 점액은 `world-structure.md` 4장 원 표에서는 "균열 외곽"(다음 지역, Lv10~18) 서식종이지만, M2_PLAN MP-3 완료 기준이 "점액 지역 구분"을 명시 요구하여 **균열 굴 어귀(균열 지형 최소 단위)에 한해 예외적으로 소수 배치**했다 — 저레벨 구간에서의 "위험 신호" 연출(`m2-monster-spec.md` 2장 각주)로 설계 의도에 부합한다. 균열 외곽 정식 서식지는 다음 지역 맵 문서에서 별도 배치한다.

## 8. MQ-01-04 거리 실측 (level-designer 확인 요청 회신)

`quest-structure.md` 3-2절 각주가 요청한 "부락~균열 굴 어귀 거리가 15타일 이상인지" 검증 결과다. 생성 스크립트 실행 로그(`_report_distances`)로 측정했다.

| 기준점 | 목적지 | 직선거리(타일) | 비고 |
|---|---|---:|---|
| 부락 중심 (깃발, 9,27) | 균열 굴 어귀 (9,5) | **22.0** | world-structure.md가 요구한 "부락 중심" 기준 |
| 플레이어 시작 지점 (9,31) | 균열 굴 어귀 (9,5) | **26.0** | 실제 플레이 체감 거리(뉴게임 시작점 기준) |
| 플레이어 시작 지점 → 균열 굴 어귀 (맨해튼 거리, 실제 이동 경로 하한) | | **26** | 대문(17,28) 경유 없이 오솔길(x=9)로 직행 가능한 최단 경로 하한치 |

- **결론: 15타일 이상 요건을 충분히 충족한다** (직선 22~26타일). 실제 도보 경로는 부락 대문(17,28)을 통과할 필요가 없다 — 대문 안쪽에서 서쪽으로 이동해 부락 외곽(x=2~17, y<22 구간)을 거쳐 오솔길(x=9)로 접근하거나, 대문을 나와 대로를 따르다 오솔길로 우회할 수 있다. 어느 경로든 여울목 개울물(도섭 지점 제한)을 지나야 하므로 실제 체감 이동 거리는 직선거리보다 더 길다 — `onboarding.md` 4장이 요구하는 "질주 힌트 트리거"가 자연스럽게 발동할 만한 장거리 동선으로 판단한다.
- 측정치는 생성 스크립트 실행 시 표준출력으로도 재현 가능하다(`godot --headless --script res://scripts/tools/generate_eastern_frontier_start_area.gd` 실행 로그의 "[MQ-01-04 거리 실측]" 절 참고).
