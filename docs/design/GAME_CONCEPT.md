## 개요

- 장르: 2D 판타지 RPG (Godot 4.x)
- 플랫폼: PC(Windows) 전용, **싱글플레이** (멀티/PvP/수익 모델 없음)
- 예상 플레이 시간: 약 **250시간** (디렉터 확정)
- 언어: 한국어 전용
- **전투 방식: 실시간 액션 (디렉터 확정)** — 상세는 `systems\combat-options.md`의 A안 기반
- 톤: **밝음 6 : 어둠 4** 판타지 (디렉터 확정)
- 플레이어 종족: **인간 고정** (디렉터 확정) — 엘프/드워프는 NPC·동료로 등장

## 세계관

- **한 줄 세계관**: 마수 대란으로 무너진 아스터 왕국에서, 이름조차 없던 유민이 공훈을 쌓아 귀족과 영주가 되어가는 이야기
- 판타지 세계 차용 — 종족: 인간, 엘프, 드워프
- **악마 종족 (디렉터 확정 2026-07-16)**: 적대 지성 세력 + **일부 중립 개체 존재**. 기본은 적 진영(중후반 주적·보스 층 강화)이되, 중립/우호 NPC 악마가 소수 존재 — 세계관 통합은 narrative-designer 설계
- **천상계 (디렉터 확정 2026-07-16)**: 심연의 대칭축으로 로어에 편입 + **후반(M3+) 콘텐츠 지역으로 예약** (만렙 전후 지역/던전). 메인 스토리 3막 구조는 유지
- **오란세 = 신성 도시국가 격상 (디렉터 확정 2026-07-16)**: 왕국의 지배를 받지 않는 독립 신성 도시국가 (천상계 신앙의 중심지). 그에 맞는 콘텐츠(순례/교단 퀘스트 등) 추가 — 상세는 narrative/systems/level 협의 설계
- **단일 왕국** 구도 (디렉터 확정) — 왕국 내 정주지 위계: 도시 – 마을 – 부락
- **도시는 8개 이상, 마을/부락은 그보다 더 많이, 도시마다 뚜렷한 특색** (디렉터 확정)
- 계급 사회
- **스토리에 반전 요소 필수** — 상세 내용은 `spoilers\`에만 기록하고 디렉터(사용자)에게 비공개. 디렉터가 직접 플레이하며 확인한다. (담당: narrative-designer)
- **반전 진입 방식 (디렉터 확정)**: 반전은 **숨겨진 퀘스트**를 진행해야 확인 가능 (예: 퀘스트 시작 아이템 습득으로 발동)
  - **완전 선택 사항 (디렉터 확정)**: 메인퀘스트는 숨겨진 퀘스트/반전을 전혀 몰라도 지장 없이 완주·엔딩 가능해야 한다. 엔딩까지 반전을 못 봐도 무방
  - 힌트는 **단순히 지나가는 수준**으로만 배치 (발견을 유도하는 장치 금지)

## 직업 시스템 (담당: systems-designer)

- 직업 총 10개, 그중 **히든 직업 2개** — 계열 목록 확정 (2026-07-15): 전사/기사/도적/궁수/마법사/**소환사**/창술사/격투가 + 히든 룬각인사/감응자. 소환사=독립 소환수 지휘, 감응자=정령 스탠스 변신으로 차별화
- 시작은 무조건 **모험가** → 10레벨 도달 시 전직
- **3차 전직**까지 가능 — **전직 구간 Lv10/40/80, 최대 레벨 100 (디렉터 확정 2026-07-15)**
- 레벨업마다 스탯과 스킬 향상 (자유 배분 없는 자동 성장 + 스킬 포인트, 디렉터 승인)

## 퀘스트 (담당: quest-designer, narrative-designer)

- 스토리를 이끄는 **메인퀘스트** 중심
- **최종전 구성 (디렉터 확정 2026-07-16)**: 최종전은 **1차전 = 우호 종족 연합 vs 적(심연 군단)의 대규모 전쟁**으로 시작하고, 이후 단계(보스전 등)로 이어진다
- **수백 개의 서브퀘스트**
- 일부 퀘스트는 명성 상승 수단 (계급 시스템 연동)

## 명성·영지 시스템 (담당: systems-designer, economy-designer)

- `명성`은 대중적 인기가 아니라, 왕국 기관 **문장원**이 개인의 **공훈부**에 기록한 공식 공훈의 총량
- 퀘스트·토벌·지역 보호처럼 국가에 보고할 수 있는 공훈으로 명성 상승
- 명성이 일정 수치에 도달하면 **부락 → 마을 → 도시** 순으로 하사받음
- 정주지 규모에 따라 수입 증가
- 도시(영지) 관리 콘텐츠 존재

## 아이템 (담당: economy-designer, systems-designer)

- 레벨 제한 존재
- 등급제: S / A / B / C
- 퀘스트 보상 또는 특정 몬스터 처치로만 얻는 **특수무기** 존재
- **장비 슬롯 8종 (디렉터 확정)**: 모자, 신발, 갑옷, 하의, 반지×2, 목걸이, 무기
- **제외 확정 (디렉터, 2026-07-16)**: 강화/제작 시스템, 내구도 시스템, 세트 아이템 — 셋 다 도입하지 않음
- **직업별 사용 가능 무기 종류가 다름 (디렉터 확정)**
- **스마트 드랍 (디렉터 확정)**: 직업 확정 후에는 자기 직업이 사용할 수 있는 무기만 획득됨
  - 절충: 무기 도감은 직업별 분리 집계 (자기 직업 무기만으로 완성 가능하게)

## 수집 콘텐츠 (담당: systems-designer)

- **개척자의 유산**: 캐릭터별 레벨·직업·퀘스트·명성·영지·장비·골드는 독립하고, 계정 도감·업적·외형·유산 포인트·편의 기능은 계승
- 후속 캐릭터는 첫 회차를 자동 완료하지 않으며 EXP·골드·명성 보너스와 지도·스킵·공용 창고 중심으로 더 빠르게 진행
- 1~5회차는 실질 편의·성장 보너스, 6~10회차는 외형·계정 칭호 중심. 직접 수치 상한은 EXP +25%, 골드 +10%, 명성 +15%, 선택 특전 이동 +5%
- 저장은 M4부터 `AccountSave`와 캐릭터 슬롯 10개의 `CharacterSave`로 분리 (`systems\pioneer-legacy.md`)
- 펫 시스템 — **전투 참여 확정 (디렉터)**: 기본적으로 전투에 참여하며 플레이어 버프, 적 공격 스킬, 적 디버프를 사용
- 칭호 시스템 — 약 **100개**, **획득 시 스탯 향상 (디렉터 확정)** (개당 효과는 인플레 방지를 위해 소소하게)
- **도감 시스템**: 아이템 / 몬스터 / 펫 / 칭호 (무기 도감은 직업별 분리 집계)

## 시간·이벤트 시스템 (담당: systems-designer, systems-dev)

- 게임 내 시간: 현실 **30분 = 게임 하루**
- **주간/야간 구분 (디렉터 확정)**: 야간에는 몬스터가 강해짐 (×1.2배, **보스 몬스터 제외**). 야간 보상(경험치/드랍) 소폭 상향 검토 — 수치는 systems-designer 설계
- 게임 한 달에 한 번 **랜덤 왕국 이벤트** 발생 → 수행 결과에 따라 명성과 골드 획득
