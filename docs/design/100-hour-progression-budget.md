## 1. 선택한 접근과 변경 범위

유지: 12장 핵심 사건, 세 영지, 10직업 장기 제작 목표, 만렙100·전직10/40/80, 캐릭터 독립/계정 계승, 현재3개 의뢰와 무기·전투 품질 기준. 삭제 확정된 도시·종족·직업은 없다. 감소시키는 제작 목표는 메인 세부 의뢰와 서브 수량이다. 전체 제작비60% 감소를 주장하지 않는다.

- 메인: 장별 합계 **61건** 제안. 기존 §3 표의 퀘 수는 실제로77건인데 §9에는75건으로 적혀 있다. 새 합계는 아래 명시적 목록으로 정합화한다. 아직 없는 의뢰를 합치거나 왕복을 줄이는 것이며 이미 배포된 ID 삭제가 아니다.

## 5. 골드 — 구매력 예산과 미검증 경계

경제 정본의 `g(L)=roundi(2×L^1.5)`, C급 장비 가격, 판매10%, 야간 골드 제외를 유지하는 초안이다. 위 골드 풀은 **현금 의뢰 보상만**이며 처치/판매/영지 수입은 포함하지 않는다.

- 1장1,130: 현재01~03 합270 +04의300 +05의560. 후자 둘은 권장Lv3/4와30/35마리분의 기존 문서에서 산출한 미구현 값이다.
- 2~12장: 메인300마리분 + 기준 서브1건30마리분을 표의 **고정 기준 레벨** 단가로 환산. 수령 레벨로 자동 재평가하지 않는다. 이 배분은 기존 메인150~300/서브20~40 범위 안이다.
- 이후20서브:600마리분=1,200,000 +반복/선택 의뢰300마리분=600,000. 추가30건·판매·영지 수입은 밖이다.
- 한 기준 단가 안에서 비교하면 C급 풀셋 약210, 포션80, 워프80, 재시도 여유50의 **420마리분**을4장 이후 의뢰 풀(최소450)로 감당할 여지가 있다. 2장은360풀에 풀셋210+포션60,3장은390풀에 풀셋210+포션60+워프30+재시도30을 배정한다. 이는 **가격 비교용 봉투**이지 실제 소비 횟수/거래 시점까지 입증한 장부가 아니다.
- 모든 장마다 풀셋 구매를 강제하지 않는다. 필수 장비·회복은 지역 진입 전 현금/현물로 확보되어야 한다. 예컨대2장 보상을 끝에서 몰아 주면 첫 전직 직후 구매력은 보장되지 않으므로 A~D와 전직 전후 거래 장부로 분할한다.
- 실제 가격은 거래 레벨·티어별이므로 기준 단가 표만으로 “돈 부족 없음”을 승인하지 않는다. M6에서 의뢰 수령/지급·구매 순서와 실제 가격을 사용해 최저 잔액, 포션/보스 재시도, 장비 운 나쁜 경우를 검증한다. 초기화150·재서임1,500·영지 투자2,500마리분은 이 필수 봉투 밖의 선택 소비다. 공훈 관문 통과에 시설 투자를 새로 강제하지 않는다.
- 사냥·판매 수입도 넣은 전체 장부에서 초과 잉여를 검토한다. 기존 생애8,300만/구간6,600마리분 표를 이 초안과 혼용하지 않는다. 영지 회수 최소30게임일 규칙은 유지하되53h 이후 실제 운영 시간/휴식 스킵 조건으로 효용을 평가한다.

## 6. 정본 적용과 검증 순서

1. Claude가 이번 구체 예산의 모순·누락·설계 가정을 검토한다. 이전 감사 통과를 새 수치 승인으로 간주하지 않는다.
2. 수정 후 `GAME_CONCEPT`·퀘스트 구조·성장·공훈/영지·경제·직업·스토리/월드·수집·로드맵·현황을 같은 결정 묶음으로 개정한다. 과거250h 측정/결정 이력은 보존한다. 데이터 적용 전 문서에서 “목표/구현값”을 분리한다.
3. 구 규칙 검증과 저장 변환을 구현·검증한 뒤 C1 또는 수정 곡선/보상을 적용한다. 초기0.45와 req9/10·18,612는 별도 판단 없이 변경하지 않는다.
4. 61메인/150서브의 ID 목록과 필수 접근 그래프를 구성한다. 지역/종족/직업에 따른 서로 배타적인 보상을 합산하지 않는다. 미구현 콘텐츠를 임의 지급으로 채운 테스트를 실제 완주로 기록하지 않는다.
5. 대표 구간(첫 전직, R8 전후, R10~3차, 최종전)을 일반 플레이로 측정한다. 대화 읽기·정비·사망 재시도 포함, 자리 비움 제외. 게임 시계도 따로 기록한다. G4/G5 이월은 독립 유지한다.

### 이번 설계 단위의 검증 범위

- `powershell -NoProfile -ExecutionPolicy Bypass -File docs/qa/tools/verify_100_hour_budget.ps1` 실행: **BUDGET_ARITHMETIC_PASS**, exit0. 세션 프로세스에만 실행 정책을 지정하며 시스템 설정을 바꾸지 않는다. 도구는 이 문서 표를 읽어 시간 합계100, 메인61/서브150, 공훈 선지급 없음·모든 관문 최소20%·서브 공훈20% 누락 시 요구량 통과를 확인했다.
