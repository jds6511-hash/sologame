## 완성할 플레이 흐름

J로 저널 열기 → 수락한 의뢰 목록/상태 확인 → 검색·상태 필터 → 상세에서 전체 목표·위치·보상 확인 → 현재 의뢰로 복귀 → Esc/J로 월드 복귀 → 진행/보고 뒤 갱신 → 저장·재실행 시 이력과 목표 복원.

현재 메인 의뢰만 제공되므로 메인1 고정 추적을 유지한다. 목록 선택은 상세 열람이고 HUD 추적 변경이 아니다. 서브2 추적·숨겨진 의뢰 탭은 해당 콘텐츠 도입 때 확장한다. 미수락/잠긴 의뢰를 목록에 미리 노출하지 않는다. 다음 수락 안내는 기존 접수원 projection이 허용한 의뢰만 보여 준다.

## 구현 계약

- Journal만 진행의 권위다. 표시 계층은 changed 신호마다 스냅샷을 읽고 매 프레임 조회하지 않는다. 표시 결과에 공유 Resource/진행 Dictionary 참조를 내보내지 않는다.
- 필터는 전체/진행 중(active+ready)/보고 가능/완료. 검색은 수락한 의뢰의 제목·목표·위치에 적용한다. 목록은 카탈로그 순서이며 숫자 인덱스 대신 stable ID로 선택한다.
- 상세는 모든 목표 카운트와 완료/현재/대기 상태, 접수원 보고 안내, 보상(완료는 수령 완료)을 표시한다. 저널에서 수락·진행·보고·보상 지급은 하지 않는다.
- 현재 의뢰 보기 버튼은 검색/필터를 해제하고 HUD의 active/ready 의뢰를 선택한다. 없으면 기존 다음 수락 안내를 표시한다. 완료 이력을 열람해도 HUD 메인 추적은 바뀌지 않는다.
- J/Esc/탭 전환은 기존 IntegratedMenu와 UiPauseArbiter를 재사용한다. 대화·저장 메뉴가 pause를 소유하면 저널을 겹쳐 열지 않는다. 텍스트 입력 중 J/I/C는 검색 문자다.
- 기존 V3 quests/counts를 그대로 읽는다. 검색·필터·열람 선택은 일시 UI 상태로 저장하지 않고 새 캐릭터/월드 바인딩 때 초기화한다. V1/V2 변환 및 V3 파일 계약 불변.
- MQ04 안내를 북쪽 오솔길 조사 표식으로 정정한다. 교전 중 사격 반경80px와 초기 인지64px를 구분하며 안전 구역을 추가하지 않는다. 다른 작업자의 추적 PNG9개는 유지한다.

## 실행·검증 순서

1. 표시·UI 계약 테스트를 먼저 작성해 미구현 실패 확인.
2. 공통 표시 함수·저널 탭·월드 바인딩·HUD 연결 및 MQ04 문구를 한 번에 구현.
3. 목록 비노출/필터/검색/목표 순서/완료 이력/캐릭터 재바인딩/상태 불변/메뉴 pause 회귀 검증.
4. 별도 프로세스 저장·로드에서 실제 저널 탭 상태를 확인하고 렌더 입력·레이아웃 검사. 전체 GUT·변경 GD 검사.
5. 결과·한계·변경 파일·커밋을 통합 검토 문서 하나에 남긴다. G4/G5와 실제 도보 플레이 판정은 자동 시험으로 대체하지 않는다.
