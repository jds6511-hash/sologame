# 현장 제출·흔적 조사·전사 자세 보완

2026-10-03 / Codex. 근거: [중간 체감 피드백](act-two-midpoint-feedback.md). 디렉터가 개선 후 다음 승인 개발도 계속하도록 지시했다.

## 구현 범위

1. 4~6장 서브 22건은 목표 완료 뒤 J 상세 화면에서 현장 기록을 제출한다. 기존 NPC 보고도 유지한다. 메인 보고·이전 장 서브는 현행대로다. 기존 `QuestController.report`가 선행·공간·금액·완료 여부를 재검사하고 지급한다. UI 선택만으로 수령하지 않으며 연속 클릭이 다음 의뢰까지 수령하지 않게 막는다. 사망 중 제출은 거부한다.
2. 지도는 현장 제출 가능한 완료 서브를 위해 NPC로 되돌아가라고 표시하지 않는다. 저널과 추적 안내는 J 제출을 알려 준다. 의뢰 ID·목표 count·순서·보상·저장 형식은 변경하지 않는다.
3. 5장 은폐 운송로와 6장 물길 대조는 주변 흔적을 관찰하고 올바른 지점으로 이동해 선택하는 현장 조사로 바꾼다. 오답은 설명만 제공하고 목표를 올리지 않는다. 정답 선택은 기존 INTERACT를 1회 기록한다. 성공 표시는 기존 count에서 재구성하고 추가 EXP나 아이템은 만들지 않는다.
4. 전사 이동은 여백을 확보한 셀에 낮은 검 자세를 그린다. 공격은 기존 판정 시계에 맞춰 체중 이동을 보강한다. 원래 손 접점·발 기준과 애니메이션 계약을 검증한다. 좌측 전체 원화가 없으면 현재의 일관된 미러 경로를 유지하며 손 교체 문제까지 해결했다고 주장하지 않는다.

## 검증과 후속

- 22건 정상 보상·재제출·미완료·메인/미지ID·사망 거부, J 버튼 연속 클릭, 저장 저널 재구성.
- 흔적 오답/정답/선행 목표/중복/재입장, 실제 충돌형 접근과 UI 일시정지 해제.
- 전사 프레임 범위·손 접점·결정적 생성·런타임 연결과 렌더 확인.
- 전체 GUT와 필요한 변경 경로 검증을 한 묶음으로 기록한다. 최종 미감 승인을 대신하지 않는다.
- 이는 반복 구조를 줄이는 첫 적용이다. 기존 36건을 모두 구출·방어전으로 다시 만들었다고 주장하지 않는다. 7장부터 같은 기능을 활용하고 조사/교섭/현장 사건/전투가 다른 역할을 갖도록 구성한다.

변경 이력: 2026-10-03 저장 진행 의미를 유지하는 현장 제출과 관찰 선택의 구현 범위를 정했다.
