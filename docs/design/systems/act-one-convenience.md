# 1막 후 이동·사거리·줍기 편의 묶음

- 2026-10-03 / Codex. 디렉터가 직전 제안의 구현을 승인했다. 기본 제품 V6/개정2의 콘텐츠·저장 형식은 유지한다.
- 변경 이력: 승인한 세 기능의 구현·검증 경계를 고정.

## 계약과 실행 계획

1. Shift: 평상시 이동 1.5배, 무자원·무쿨다운. 공격/조준/스킬/회피 속도는 기존대로. 설정의 누르기/토글 선택은 실행 세션 동안 지역 교체에도 유지하며, 달리는 상태 자체는 일시정지·사망·지역 교체 때 해제한다. 설정 영구 저장은 이번 범위 밖이다.
2. 기본 화살 8→10, 일반 스킬 8.5→10.5, 조준 10→12타일. 궁극기12·속도·피해는 유지. 적 인지 밖 원거리 명중의 반응은 기존 AI 계약을 조사해 제한을 기록한다. AI를 별도 재설계하지 않는다.
3. 발 위치 32px 안의 드롭을 F 한 번으로 수집. 센서는 위로 치우친 플레이어 캡슐을 포괄하도록 8→40px로 넓히고 실제 후보는 발 기준32px로 다시 제한한다. 같은 월드·시야가 열린 아이템만 포함한다. NPC/표식 상호작용 우선권, 가방 용량, 중복 지급 방지를 유지하고 프롬프트는 가장 가까운 한 곳에만 표시한다. 실패한 아이템은 남긴다.

## 작업 순서와 검증

- 이동/화살/드롭 회귀를 먼저 추가하고 기존 코드에서 실패 확인: Shift 실제 속도, 공격·조준 제외, 토글/해제, 다중 줍기·만석·벽·NPC 우선권.
- PlayerController 이동 연결, 설정 UI, 화살 리소스, WorldItem 그룹 조정과 프롬프트를 구현한다. 연결된 기존 경로에만 수정한다.
- 대상 GUT → 전체 verify_all → 게임 실행기 확인. 새 probe는 기존 검사로 확인 불가능할 때만 만든다.
- 기존 작업 공간과 다른 작업자의 PNG를 보존한다. 이미 합의한 이 저장소 작업 방식으로 명시 파일만 커밋하며 계획 승인을 재요청하지 않는다.
- 통합 요청서 한 건으로 검토한다. 키 변경·목표 화살표·가방 UI 리디자인은 이번 범위 밖이다.

## 진행 기록

- 계획 및 기존 코드 확인 완료. Shift는 입력 등록만 있고 소비자가 없었다. 기존 줍기는 각 드롭이 8px Area2D 안에서 F를 따로 읽는 방식이다.

- 대상 GUT37/37 통과. 기존 코드에서 신규7검사 중4건이 의도대로 실패하는 것을 확인한 뒤 구현했다. 추가 경계 검사는 토글/사망/조준, 둔화, 벽, 외부 월드와 거리를 다룬다.
- 정정(2026-10-03): last_attacker 필드만 조사해 피격 추격 전체가 없다고 기록한 것은 부정확했다. 들개·거미·강도·임프 계열은 take_damage의 attacker 인자로 이미 추격한다. 토끼·점액에는 반격 추격이 없어 후속 디렉터 요구로 보완한다. 기존 종별 추격 한계와 지형에 따른 도달 제한은 남는다.
