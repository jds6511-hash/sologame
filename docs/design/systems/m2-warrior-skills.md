## 2. 기본 공격 — 대검 2타 콤보

대검은 "느리지만 무거운 한 방"(`jobs.md` 2장 정체성)이므로 `combat.md` 7장의 기본 공격 기준(3타 콤보, 타당 1.0·3타째 1.3)을 그대로 쓰지 않고 **2타 콤보(무기별 2~3타, `combat.md` 3장 허용 범위)**로 차별화한다 — 매 타격이 더 무겁게 느껴지도록 타수를 줄이고 계수를 올렸다.

| 타 | 계수 | 판정 범위 | 선딜 | 판정 | 후딜 | 총 모션 시간 | 히트스톱 |
|---|---:|---|---:|---:|---:|---:|---|
| 1타 | 1.0 | 전방 부채꼴 90°, 1.8타일 | 0.15초 | 0.10초 | 0.25초 | 0.50초 | 약 (0.03초) |
| 2타(마무리) | 1.5 | 전방 부채꼴 120°, 2.0타일 | 0.20초 | 0.15초 | 0.35초 | 0.70초 | 중 (0.06초, 콤보 마무리) |

- 자원 소모 없음, 쿨다운 없음 (`combat.md` 7장 기준 공격 규격).
- 콤보 연계: 1타 후 0.6초 이내 좌클릭 재입력 시 2타로 연결, 미입력 시 1타로 리셋 (표준 콤보 윈도).

## 3. 우클릭 — 차지 강타 (홀드)

| 항목 | 값 |
|---|---|
| 유형 | 차징(홀드) — 이동 시 취소 (`combat.md` 3장 확정 규칙) |
| 홀드 시간 | 최소 0.3초 ~ 최대 1.2초 (풀차지) |
| 계수 | 홀드 시간에 선형 비례: 최소차지 1.6 ~ 풀차지 3.0 |
| 판정 범위 | 전방 부채꼴 150°, 2.2타일 |
| 슈퍼아머 | 홀드 시작 ~ 타격 종료까지 전체 유지 (`combat.md` 5-1 "슈퍼아머 스킬 시전 중" 규칙 — 경직 무시, 피해는 그대로 받음) |
| 후딜 | 0.5초(최소차지) ~ 0.7초(풀차지) |
| 쿨다운 | 9초 (차지 정도 무관 고정) |
| MP | 12% (최대 MP 대비) |
| 히트스톱 | **강 (0.10초, 고정)** — `combat.md` 5-3 "치명타·차지 강타·궁극기 = 강" 규정에 따라 차지 정도와 무관하게 항상 강 등급 |

- 설계 의도: 전사 정체성 "슈퍼아머로 밀어붙이기"의 핵심 스킬. 홀드 중에도 피해를 받으며 버티는 선택(딜 극대화)과 짧게 끊어 안전하게 치는 선택(생존 우선)의 트레이드오프를 만든다.
- `m2-monster-spec.md` 3-3장의 균열 점액 "코어 파괴" 기믹이 바로 이 스킬(또는 치명타)로 발동하도록 설계되어 있다 — 우클릭 차지 강타가 곧 몬스터 스펙의 강 프리셋 트리거.

## 4. 모험가 공용 스킬 3종 (Lv1~10, 전 직업 공용 — 본 문서에서 최초 확정)

전 직업이 동일하게 사용하며, 전직 후에도 슬롯 1·2·3에 그대로 남는다(`jobs.md` 3장 "직업당 스킬 15개" 구성의 기저).

| 쿨다운 | 5초 |
| MP | 8% |
| 판정 범위 | 전방 직선, 2.0타일 폭 1.0타일 |

### 4-2. 질주 (슬롯 2, 이동기)

|---|---|
| 계수 | 1.0 + 이동 (이동기 규격 1.0~1.5 하한) |
| 쿨다운 | 8초 |

| 항목 | 값 |
|---|---|

## 7. 히트스톱 프리셋 매핑 (G2-3 게이트 입력 자료)

| 프리셋 | 해당 스킬/공격 |
|---|---|
| 약 (0.03초, 흔들림 없음) | 기본 공격 1타 |
| 중 (0.06초, 약한 흔들림) | 기본 공격 2타(마무리), 강타, 질주, 분쇄 베기, 돌격 |
| 강 (0.10초, 중간 흔들림) | 차지 강타(고정), 대지 분쇄(궁극기), 치명타(전 스킬 공통) |
| 해당 없음 | 응급 처치, 결의의 외침 (타격 없는 자가 버프) |

- `m2-monster-spec.md` 5장의 몬스터별 프리셋 대표 배정과 짝을 맞추면: 뿔토끼=기본공격(약), 들개 마수=강타/분쇄 베기 등 일반 스킬 마무리(중), 균열 점액=차지 강타(강)로 자연스럽게 이어진다 — 디버그 전투장(CB-9)에서 3프리셋을 모두 짧은 시간 안에 검증 가능.
