## 1. 핵심 원칙

> **후속 캐릭터는 처음부터 강한 것이 아니라, 이미 걸어본 길을 더 빠르고 편하게 걷는다.**

- **캐릭터 진행은 독립**한다. 레벨, 직업, 퀘스트, 명성, 영지, 장비, 골드와 스토리는 새 캐릭터마다 다시 시작한다.
- **계정 업적은 계승**한다. 클리어 기록, 도감 지식, 업적, 외형, 계정 칭호, 유산 포인트와 편의 기능은 계정에 누적된다.
- 계승 보너스는 첫 회차의 전투·경제·승급 구조를 생략시키지 않는다. 1~5회차에서 속도와 편의를 단계적으로 높이고, 6회차부터는 외형과 명예 보상을 중심으로 한다.
- 직업 10계열을 각기 완주할 이유를 만들되, 특정 직업 클리어가 다른 직업의 직접 공격력·방어력을 올리지는 않는다.

## 2. 세계관 표현 — 문장원의 유산 회랑

문장원은 왕국을 구한 개척자의 공훈부를 **유산 기록**으로 봉인한다. 타이틀 화면의 계정 연대기와 왕도 문장원의 **유산 회랑**에서 역대 클리어 캐릭터의 이름, 최종 직업, 레벨, 영지, 엔딩 유형과 대표 외형을 볼 수 있다.

이 기록은 계정 플레이 이력을 세계관 언어로 보여주는 메타 공간이다. 새 캠페인의 일반 세계는 매번 정본 시작 상태로 돌아간다.

- 이전 캐릭터가 새 캠페인의 카엘론 영주나 메인 스토리 선행자로 직접 등장하지 않는다.
- 일반 NPC가 이전 캐릭터의 동일 사건을 이미 일어난 역사로 언급하지 않는다.
- 따라서 새 캐릭터도 유민으로 시작해 여울목·잿골·카엘론의 상승 서사를 온전히 경험한다.
- 유산 회랑의 석상·명판·추모 대사는 계정 기록을 보여줄 수 있지만 현재 캠페인의 사건 연대에는 편입하지 않는다.

이 분리는 “유민 출신 최초의 귀족”이라는 정본 서사와 다회차 기록이 서로 덮어쓰는 문제를 막는다.

## 3. 저장 소유권

### 3.1 AccountSave — 계정 공용

| 범주 | 데이터 |
|---|---|
| 식별·버전 | `account_id`, `account_save_version` |
| 다회차 | 총 클리어 횟수, 직업별 엔딩 기록, 유산 등급, 유산 포인트, 구매한 특전 |
| 수집 지식 | 몬스터·아이템·펫 발견 ID, 칭호 수집 기록 |
| 업적 | 계정 업적 ID, 달성 시각, 보상 수령 상태 |
| 외형 | 스킨, 무기·펫 외형, 프로필 장식, 특수 이펙트 |
| 계정 칭호 | 표시 전용 위업 칭호, 대표 계정 칭호 |
| 편의 기록 | 본 컷신·대화 ID, 튜토리얼 완료, 발견한 지역 정보 |
| 공용 창고 | 해금 상태, 슬롯 단계, 허용 아이템 스택 |
| 유산 회랑 | 클리어 캐릭터의 불변 요약 스냅샷 목록 |

### 3.2 CharacterSave — 캐릭터 전용

| 범주 | 데이터 |
|---|---|
| 식별·버전 | `character_id`, `character_save_version`, 표시 이름(기본값 `아렌`) |
| 성장 | 레벨, EXP, 직업, 전직, 스킬, HP/MP |
| 소유물 | 개인 인벤토리, 장비, 골드, 펫 보유·성장 상태 |
| 진행 | 퀘스트, 명성, 영지, 스토리·월드 플래그 |
| 이동 | 현재 맵·위치, 직접 활성화한 워프 지점 |
| 개인 칭호 | 이 캐릭터가 획득한 능력치 칭호와 누적 효과 |
| 개인 수집 실적 | 공유 도감 지식과 별개로 이 캐릭터가 직접 획득·처치한 ID와 개인 보상 수령 상태 |

### 3.3 저장 단위

- 계정 하나는 **캐릭터 슬롯 10개**를 가진다. 직업 10계열 완주 기록을 활성 캐릭터로 모두 보존할 수 있는 수다.
- 계정 파일 1개와 캐릭터 파일 최대 10개를 분리한다. 캐릭터 저장 실패가 계정 업적 파일을 함께 손상시키지 않게 각각 원자적으로 기록한다.
- 캐릭터를 삭제해도 이미 확정된 클리어 스냅샷과 계정 업적은 삭제하지 않는다. 공용 창고에 남은 허용 아이템도 유지한다.
- 모든 참조는 stable content ID를 사용한다. 씬 경로, 노드 경로, 번역 표시명은 저장 키로 쓰지 않는다.
- 계정 도감·업적 기록은 첫 캐릭터부터 AccountSave에 누적한다. 첫 엔딩 전에는 다른 캐릭터에 공유하는 UI와 유산 보상만 잠그며, 그전에 얻은 발견·업적을 버리지 않는다.

### 3.4 M4 필드 보충

양쪽 파일에 pending_transfer=null, applied_transfer_ids=[]를 예약한다. M4는 미완 거래가 있으면 로드를 거부하며 M11에서 저널 기반 중복 없는 재적용을 구현한다. 캐릭터는 play_seconds와 first_death_waiver_used도 저장한다. 계정 튜토리얼 완료는 누적 기록, 캐릭터 tutorial_done/hint_heal_done은 해당 회차 이행 상태다. 스킵 권한은 첫 엔딩 이후이며 M4에서 자동 부여하지 않는다.

## 4. 계정 공용과 캐릭터 전용 경계

| 시스템 | 계정에서 계승 | 새 캐릭터가 다시 수행 |
|---|---|---|
| 도감 | 발견 정보·그림·설명·힌트 | 실제 아이템·펫 획득, 개인 수집 보상 조건 |
| 업적 | 전부 | 없음. 계정당 한 번만 달성·보상 |
| 외형 | 전부 | 장비 성능과 획득 조건은 별개 |
| 칭호 | 계정 위업 칭호의 표시 권한 | 능력치 칭호와 승급·퀘스트 칭호 |
| 지도 | 이전에 발견한 지역의 지도 표시 | 직접 방문과 일반 워프 활성화 |
| 대화·컷신 | 이미 본 항목의 스킵 권한 | 퀘스트 상태와 선택 결과 |
| 레벨·직업 | 획득량 보너스와 정보 | 레벨업·전직 전체 |
| 명성·영지 | 획득량·비용 편의 | 공훈, 문장원 심사, 승급, 통치 전체 |
| 장비·골드 | 공용 창고의 허용 물품 | 개인 장비·골드와 경제 루프 |

## 5. 도감·칭호·업적 분리

도감 공유가 새 캐릭터의 능력치 보상을 자동 완성하지 않도록 세 층으로 나눈다.

1. **계정 도감 지식**: 한 번 발견한 항목의 정보는 모든 캐릭터가 본다.
2. **캐릭터 수집 실적**: 해당 캐릭터가 직접 획득·처치한 기록이다. 기존 100개 능력치 칭호와 캐릭터 수집 보상의 판정에 사용한다.
3. **계정 업적·위업 칭호**: 계정당 한 번 달성한다. 외형·프로필·표시용이며 능력치가 없다.

`collection.md`의 기존 칭호 100개와 총 능력치 예산 +65는 **캐릭터 칭호**에만 적용한다. `첫 번째 개척자`, `다섯 삶의 개척자`, `십계의 개척자` 같은 계정 칭호는 이 100개와 도감 완성률 분모에 포함하지 않는다.

## 6. 유산 등급 — 1~10회차

### 6.1 1~5회차 실질 보너스

아래 수치는 해당 클리어 횟수에서 적용되는 **누적 총값**이다. 서로 더하지 않는다.

| 클리어 | 유산명 | 누적 효과와 해금 |
|---:|---|---|
| 1 | **개척자의 첫 유산** | 계정 도감·업적·공용 창고·튜토리얼 스킵·유산 특전 해금, EXP +10% |
| 2 | **이어진 발자취** | EXP +15%, 골드 +5%, 이전 발견 지역 지도 표시, 본 일반 컷신 자동 스킵 옵션, 창고 2단계 |
| 3 | **왕국에 남은 이름** | EXP +20%, 골드 +10%, 명성 +10%, 이전에 발견한 주요 도시 중 1곳 조기 워프, 반복형 서브퀘스트 즉시 보고 |
| 4 | **계승자의 길** | 새 캐릭터 생성 시 유산 성향 1개 선택 |
| 5 | **대개척자의 유산** | EXP +25%, 골드 +10%, 명성 +15%로 수치 상한 도달, 공용 창고 최대 단계, 계정 외형과 `다섯 삶의 개척자` 칭호 |

- EXP +25%, 골드 +10%, 명성 +15%, 이동 속도 +5%가 계승 수치의 절대 상한이다.
- 명성 보너스는 공훈을 대신하지 않는다. 승급 퀘스트와 문장원 심사는 생략할 수 없다.
- 조기 워프는 계정당 발견 이력이 있는 주요 도시 한 곳만 새 캐릭터 생성 때 고른다. 나머지는 직접 방문해야 활성화된다.
- 반복형 서브퀘스트 즉시 보고는 이미 해당 유형을 한 번 정상 완료한 계정 기록이 있고, 새 캐릭터도 목표를 실제 완료했을 때만 사용할 수 있다.

### 6.2 네 번째 클리어의 유산 성향

새 캐릭터마다 하나만 고르며 캐릭터 생성 후에는 바꿀 수 없다.

| 성향 | 효과 |
|---|---|
| **탐험가** | 비전투 이동 속도 +5%, 지도 탐색 반경 증가 |
| **전투가** | 시작 회복약 3개 추가, 캐릭터당 첫 사망 1회의 골드 손실 면제 |
| **개척자** | 명성 보너스를 누적 상한 +15%까지 올리고 영지 시설 비용 −10% |

전투가의 첫 사망 면제는 부활 위치·HP/MP 규칙을 바꾸지 않고 골드 손실만 0으로 만든다. 사용 여부는 CharacterSave에 기록한다.

### 6.3 6~10회차 명예 보상

| 클리어 | 보상 |
|---:|---|
| 6 | 특수 무기 외형 |
| 7 | 희귀 펫 외형 |
| 8 | 캐릭터 생성 배경과 유산 회랑 배경 |
| 9 | 타이틀 화면 변화 |
| 10 | `열 번 길을 걸은 자` 계정 칭호와 프로필 장식 |

6회차 이후에는 EXP·골드·명성·이동·드랍 수치를 더 올리지 않는다.

## 7. 유산 포인트와 특전

| 조건 | 유산 포인트 |
|---|---:|
| 메인 엔딩 최초 완료 | +5 |
| 아직 기록되지 않은 일반 직업 계열로 엔딩 | +3 |
| 아직 기록되지 않은 히든 직업으로 엔딩 | +4 |
| 계정 도감 통합 80% 최초 달성 | +2 |
| 지정 고난도 보스 업적 | +1 |
| 숨겨진 퀘스트 체인 최초 완료 | +2 |

- 같은 직업·같은 업적 반복으로 포인트를 무한 획득할 수 없다. 조건별 stable achievement ID당 한 번만 지급한다.
- 클리어 횟수는 6장의 기본 패키지를 연다. 유산 포인트는 성장·개척·재산·편의 계열의 선택형 특전을 해금한다.
- 선택형 특전이 6장의 절대 상한을 넘길 수 없다. 공격력·방어력 직접 증가 노드는 만들지 않는다.

| 계열 | 허용 특전 |
|---|---|
| 성장 | 해금된 EXP 보너스 적용, 펫 대기 경험치 편의 |
| 개척 | 지도 정보, 명성 보너스 적용, 문장원 연출 단축. 승급 퀘스트 스킵 금지 |
| 재산 | 공용 창고, 소량의 시작 골드·회복약, 상점 매입가 편의 |
| 편의 | 튜토리얼·본 컷신·대화 빠른 진행, 목표 위치 표시, 조기 워프 선택 |

## 8. 공용 창고

- 첫 엔딩 완료 후 열린다. 그전에는 메뉴에서 잠금 이유만 표시한다.
- 공유 가능: 일반 재료, 소비품, 수집 아이템, 거래 가능한 일반 장비.
- 공유 불가: 메인퀘스트·전직·영지 핵심 아이템, 숨겨진 퀘스트 발동 핵심품, 캐릭터 귀속 특수 장비.
- 아이템 데이터에 `account_storage_policy`를 두고 `allowed`, `character_bound`, `progression_locked` 중 하나를 명시한다.
- 장비 레벨·직업 제한은 공용 창고에서 꺼낸 뒤에도 그대로 적용한다.
- 개인 골드는 직접 공유하지 않는다. 공용 창고를 이용한 허용 아이템 이전만 가능하다.
- 입출고는 여울목의 유산 창고함이나 지정 창고 NPC 앞에서만 가능하다. 타이틀과 원격 유산 화면에서는 보관 목록만 열람한다.
- AccountSave의 아이템 이동은 거래 ID로 한 번만 확정한다. 퀵로드나 강제 종료로 같은 아이템이 개인 인벤토리와 공용 창고에 동시에 남지 않게 한다.

## 9. 십계의 증명

조건은 일반 8계열과 히든 2계열, 총 10개 직업 계열로 각각 한 번 이상 엔딩을 완료하는 것이다.

보상:

- 특별 타이틀 화면
- `십계의 증명` 계정 업적과 `십계의 개척자` 계정 칭호
- 10계열 대표 무기 외형 세트
- 특별 펫 외형
- 계정 프로필 장식
- 유산 회랑의 전용 명판과 NPC 대사
- 새 캐릭터가 시작 부락에서 유산 회랑 메뉴에 접근할 수 있는 편의 기능

전투 스탯 보상은 주지 않는다.

## 11. 후속 콘텐츠 완료 검증 원칙

M4 완료 판정은 [저장 계약의 G4](save-load.md)를 따른다. 아래 1번의 레벨/인벤토리 격리와 7번 손상 격리는 M4에서 검사하고, 1번의 퀘스트/영지 및 2~6번 콘텐츠는 해당 시스템이 구현되는 M5~M15에서 검사한다. M4가 전체 유산 콘텐츠의 완료를 뜻하지 않는다.

1. 캐릭터 A의 레벨·명성·영지·퀘스트가 캐릭터 B에 복사되지 않는다.
2. 캐릭터 A가 발견한 도감 정보와 본 컷신 기록은 캐릭터 B에서 보인다.
3. 공유 도감 때문에 캐릭터 B의 능력치 칭호가 자동 지급되지 않는다.
4. 캐릭터 삭제 후에도 계정 업적·유산 포인트·클리어 스냅샷이 유지된다.
5. 공용 창고 금지 아이템은 넣기와 꺼내기 양쪽에서 거부된다.
6. 계승 보너스는 상한을 넘지 않고 승급·전직·메인퀘스트를 자동 완료하지 않는다.
7. AccountSave 손상과 CharacterSave 손상이 서로 전파되지 않는다.
