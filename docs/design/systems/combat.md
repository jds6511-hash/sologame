## 2. 핵심 전투 루프

```
이동으로 거리 조절 → 기본 공격(좌클릭, 마우스 방향) → 스킬 쿨다운·MP 확인 →
몬스터 예고 모션 확인 → 회피(Space 대시) 또는 직업 고유 대응(가드/카운터) →
스킬 콤보 → 직업 게이지(2차 이후) 소모 기술 → 처치 → 루팅(펫 자동 줍기)
```

### 2-1. 목표 시간 (밸런스 기준치 — 8장 곡선이 이 값을 보장)

| 대상 | 목표 처치 시간 | 비고 |
|---|---|---|
| 일반 몬스터(잡몹) | **3~8초 (기준 5초)** | 동렙, B급 장비 기준 |
| 정예 몬스터 | **약 30초** | 잡몹 HP ×6 |
| 보스 | **2~5분 (기준 3.3분)** | 잡몹 HP ×40, 패턴 학습형·페이즈 2개 |

### 2-2. 다수 교전 규칙

- 기본 교전 단위: **2~5마리 무리**. 무리 단위로 어그로 공유(1마리 피격 시 무리 전체 전투 돌입).
- **공격 토큰**: 동시에 공격 모션에 들어갈 수 있는 몬스터는 최대 **2마리**(보스전 잡몹 동반 시 1마리). 나머지는 포위·배회. → 다수전에서도 회피가 반응 가능한 난이도로 유지되는 핵심 장치.
- 몬스터 어그로 해제: 스폰 지점에서 일정 거리(추적 한계) 이탈 시 귀환 + HP 회복.

### 2-3. 주야간 전투 규칙 (디렉터 확정 + 보상 수치 설계)

게임 내 시간(현실 30분 = 게임 하루)은 **낮 20분 : 밤 10분(2:1)** — `reputation-territory.md` 4장에서 **확정** (탐험·마을 활동이 주가 되는 낮을 길게).

| 항목 | 주간 | 야간 | 근거 |
|---|---|---|---|
| 일반·정예 몬스터 HP/공격력 | ×1.0 | **×1.2 (디렉터 확정)** | — |
| 보스 | ×1.0 | ×1.0 (**제외, 디렉터 확정**) | 보스는 패턴 학습이 본체이므로 시간대 변수 배제 |
| 몬스터 경험치 | ×1.0 | **×1.2** | 야간 TTK 6.0초·피격 허용 8.3대로 리스크 +20% → 보상 동률 |
| 일반·정예 몬스터 **아이템 드랍률** | ×1.0 | **×1.15 (확정)** | `economy-foundation.md` 9장 채택 확정 — 아이템 드랍률 한정, **골드 드랍량 ×1.0**(인플레 방지), 보스 제외. 드랍은 누적 자산이므로 경험치(+20%)보다 보수적으로 |

- 야간 몬스터도 TTK 6.0초로 목표 범위(3~8초) 안이며, 8장 곡선 자체는 주간 기준으로 유지한다.
- 야간 효율 검산: 처치 속도 약 -8%(사냥 사이클 12→13초) × 경험치 +20% = **시간당 경험치 약 +10%** — "위험을 감수하면 조금 이득"인 소폭 상향. 플레이 시간의 1/3이 야간이므로 전체 성장 속도 영향은 약 +3~4%로 `growth.md` 경험치 곡선의 오차 범위 내.
- 야간 전용종(야행성 몬스터) 출현은 도감 수집 동기로 사용한다 — 패밀리 구조(9-2장)의 아종 슬롯 일부를 야간종에 배정.

### 2-4. 펫 전투 참여 규칙 (디렉터 확정)

펫은 **자동 AI 동반자**로 항상 전투에 참여하며(명령 3단계: 공격 우선/대기/귀환), 개체마다 아래 3역할 중 **주 역할 1개**를 가진다.

| 역할 | 행동 | 밸런스 상한 (기준선 대비) |
|---|---|---|
| 버프형 | 플레이어에게 주기적 버프 (공격력/이동속도 등) | 플레이어 능력치 +8% 이내, 가동률 50% 이내 |
| 공격형 | 적을 자동 타겟팅해 공격 스킬 사용 | 플레이어 DPS의 5~10% |
| 디버프형 | 적에게 디버프 (방어 감소, 둔화 등) | 적 능력치 -10% 이내, 보스 저항 50% |

- **8장 몬스터 곡선의 기준선은 "펫 없음"이다.** 펫 효과는 어떤 조합이든 실효 전투력 +10%를 넘지 않게 설계해, 펫이 TTK를 5초 → 4.5초 수준으로 단축하는 "보너스"에 머물게 한다 (목표 범위 3~8초 유지).
- 역할 차이는 수치가 아니라 **플레이 스타일 선택**(안정 버프 vs 화력 vs 보스전 디버프)으로 체감시킨다. 펫 획득/육성/도감 상세는 추후 펫 시스템 문서에서 설계한다.

## 3. 스킬 슬롯과 사용 규칙 (A안 2-2 확정)

| 슬롯 | 키 | 내용 |
|---|---|---|
| 기본 공격 | 마우스 좌클릭 | 무기별 2~3타 콤보, 자원 소모 없음 |
| 보조 동작 | 마우스 우클릭 | **직업 고유** (가드/차지/자세 등, `jobs.md` 3장) |
| 스킬 6칸 | 1, 2, 3, 4, Q, E | 쿨다운 + MP 이중 제한 |
| 궁극기 | R | 1차 전직 시 습득, 3차에서 각성 진화 |
| 회피 | Space | 대시 (4장) |
| 타겟 고정 / 상호작용 | Tab / F | 보스·정예 대상 락온(카메라 보조) |

- 스킬 유형 5종: **즉발 / 차징(홀드) / 설치(장판) / 이동기 / 버프·힐**.
- 캐스팅(차징 포함) 스킬은 **이동 시 취소** — "서서 쏘느냐, 움직여 피하느냐"의 긴장 유지 (A안 확정 사항).
- **[정합성 주석, 2026-07-27]** 위 "이동 시 취소"는 **캐스팅·차징 스킬과 직업 고유 차지 강타에만 적용**된다. **기본 공격 콤보는 예외**로, 3-1장 QoL에 따라 스윙 중 이동(평소 이동속도의 45%)이 허용된다. 즉 "서서 쏘느냐/움직이느냐"의 긴장은 스킬·캐스팅에서 유지하고, 매초 반복되는 기본 공격은 손맛(반응성) 우선으로 이동을 허용한다 — 두 규칙은 모순이 아니라 적용 대상이 다른 것이다.
- 스킬 계수·쿨다운·MP 규격은 7장.

### 3-1. 기본 공격 조작/QoL (전사 기준선, 디렉터 승인 2026-07-27)

gameplay-dev가 M2 전사 기본 공격 콤보에 손맛 향상 QoL 4종을 구현했다(커밋 `113fd1b`, 디렉터 승인). 아래 4종은 **전부 기본 공격 콤보 한정**이며, 스킬·차지 강타는 3장·5장의 기존 규칙('이동 시 취소', 캐스팅 긴장)을 그대로 따른다. 기준선은 전사이고, 나머지 직업으로 확산할 때 동일 규격을 사용한다.

| # | 기능 | 동작 | 채택 튜닝값 |
|---|---|---|---|
| 1 | **홀드 연타** | 좌클릭 홀드 감지(`is_action_pressed`)로 콤보 윈도우·스윙 타이밍을 존중해 다음 타를 자동 발동. 콤보가 끝난 시점에도 홀드가 유지되면 콤보를 자동 재시작 | **홀드 방식**(연타 불요), 콤보 윈도우·스윙 타이밍 불변 |
| 2 | **자동 조준 스냅** | 스윙 개시 시 마우스 방향 기준 **±35°·3타일 이내**의 가장 가까운 **살아있는** 몬스터로 조준을 스냅. 대상이 없으면 순수 마우스 방향 유지 | **±35° / 3타일 / 최근접·생존 개체** |
| 3 | **스윙 중 재조준** | STARTUP(시전 준비) 구간 동안만 방향 갱신을 허용, ACTIVE(판정) 진입 이후에는 방향 고정 | **STARTUP 한정 갱신, ACTIVE 이후 고정** |
| 4 | **공격 중 이동** | 스윙 중에도 이동 허용(구: velocity 0 정지). 평소 이동속도의 **45%** | 상수 `ATTACK_MOVE_SPEED_MULTIPLIER = 0.45` |

- **1·2·3은 손맛(반응성·정확도)만 개선**하고 전투 캐이던스(스윙 간격)·스킬 계수는 바꾸지 않으므로 8장 곡선의 TTK/DPS에 영향이 없다.
- **4(공격 중 이동)는 캐이던스는 불변이나 플레이어의 실제 피격 수를 바꾼다** → 재검증을 수행했고 **계수 0.45 유지로 확정**됐다(아래 "재검증 결과").
- 자동 조준 스냅의 ±35°/3타일은 "근접 잡몹 무리에서 의도한 대상을 놓치지 않을" 최소 범위로 잡되, 원거리·의도적 빗맞춤을 막지 않도록 좁게 유지했다. 이 값들(±35°/3타일/45%/홀드)은 **G3-1 손맛 게이트의 튜닝 대상**이다.

**재검증 결과 — '공격 중 이동' 계수 0.45 유지 (M3 Phase D-1, 2026-07-31)**

M2 게이트에서 남긴 재검증 트리거("정지 스윙 = 피격 감수" 전제가 무너져 설계보다 쉬워질 여지")는 **M3 Phase D-1에서 실측 재검증을 완료해 해소됐다** — 근거는 `m3-balance-phase-d.md` 2장.

- **판정: 계수 `ATTACK_MOVE_SPEED_MULTIPLIER = 0.45` 유지. 조정 레버 3개(① 0.45→0.3 하향 ② 페이즈 한정 ③ 몬스터 공격력 상향)를 모두 미채택.**
- 근거 ① **피격 예산이 무너지지 않았다** — 신규 7종 포함 전 10종에서 9.91~10.30대(5-1장 주석).
- 근거 ② **완화 경로가 M3 신규 행동 블록에 의해 이미 좁혀졌다** — 숲거미 도약(필요 이탈 1.375타일)·무법자 돌진(1.875타일)은 공격 중 이동의 도달 범위(0.890~1.261타일)를 넘어서므로 **공격을 멈추고 걷거나 대시해야만** 흘릴 수 있다. 남는 완화는 **근접 스윙 1종, 그것도 사거리 경계에 서 있을 때만**이다.
- 근거 ③ 0.3 하향은 그 근접 스윙 경계 이탈을 여전히 성공시키는 반면(0.494타일 > 필요 0.375타일) 둔화 조합만 사실상 정지로 만들어(기본의 18%) **손맛만 잃고 난이도는 그대로**다.
- **미해결로 남는 것**: "실제로 몇 대 맞는가"는 회피 숙련도에 전적으로 의존해 문서로 판정할 수 없다 → **G3-1 관찰 항목 O-1**(`m3-balance-phase-d.md` 9-2). 5-1장의 "10대"는 **치사성 캘리브레이션**이지 기대 피격 수가 아니다.

#### 3-1-1. 이동 속도 실질값 — 둔화·공격 중·조준의 중첩 (확정, 2026-07-31)

이동 감속은 **곱연산으로 중첩**된다. 조합 실질값이 어느 문서에도 없어 M3 Phase D-1 실측(`m3-balance-phase-d.md` 2-2)으로 확정한다. 기준 걷기는 4장의 **3.297타일/초**.

| 상태 | 타일/초 | 기본 대비 | 근거 |
|---|---:|---:|---|
| 기본 걷기 | **3.297** | 100% | 4장 대시 3수치에서 역산 |
| 공격 중 (×0.45) | **1.484** | 45% | QoL④ |
| 이동 둔화 (거미줄 −40%) | **1.978** | 60% | `m3-monster-spec.md` 3-2 |
| **둔화 + 공격 중** | **0.890** | **27%** | 둔화가 0.45에 **곱**으로 얹힌다 |
| 궁수 조준 스탠스 (×0.4) | **1.319** | 40% | 조준은 0.45를 **대체**한다(중복 적용 아님) |
| **둔화 + 조준** | **0.791** | **24%** | 조준이 0.45를 대체하되 둔화는 그 위에 곱해진다 |
| 회피 대시 | **8.571** | 260% | **둔화·공격 중 모두 면제**(무적 이동기) |

- **적용 규칙**: `speed = 걷기 × (1 − 둔화율)` 계산 후, 조준 중이면 `× 조준 배율`, 아니면 공격 중이면 `× 0.45`. 조준과 공격 중은 **배타**이며 둔화만 항상 곱해진다.
- **설계 함의 두 가지**: ① 공격 중 이동(1.484)은 **모든 근접 몬스터의 추격 속도(3.4~4.2)보다 느리다** — QoL④는 "도망" 수단이 아니라 "정지 판정에서 한 걸음 빠지기"다. ② 궁수 조준(1.319)은 공격 중 이동보다 **더 느리므로**, 카이팅 직업의 리스크가 근접보다 낮지 않다(둔화가 겹치면 근접 스윙조차 흘릴 수 없다) → G3-1 관찰 항목 O-5.
- **둔화의 카운터는 항상 대시**다(둔화 면제). 거미줄 쿨다운 5.0초 vs 대시 재충전 4.0초/충전이므로 단독 둔화는 수급이 맞는다.

### 5-1. 플레이어 피격

| 상황 | 경직 | 무적 | 비고 |
|---|---|---|---|
| 일반 피격 | 0.25초 | 피격 후 0.6초 | 넉백 소(0.5타일) |

- 피격 허용 횟수 밸런스 기준: **잡몹 10대 / 보스 스킬 4대** (8장 곡선이 전 레벨에서 이 값을 유지).
- **[재검증 완료, 2026-07-31 — 구 트리거 해소]** 이 피격 허용 예산은 **"정지 스윙 = 피격 감수"** 전제로 산출된 값이고, 기본 공격 QoL의 '공격 중 이동'(3-1장, 계수 0.45)이 실제 피격 수를 줄여 설계보다 쉬워질 여지를 남겼다. **M3 Phase D-1 실측으로 재검증 완료**: **피격 예산은 이동 계수와 독립**(산출식이 `몬스터 공격력 × 100/(100+플레이어 방어력)`과 최대 HP만으로 결정)이며, **신규 7종을 포함한 전 10종에서 9.91~10.30대로 유지**됨을 확인했다(`m3-balance-phase-d.md` 2-4). 정예(포효 임프장) 6.63대도 8-1의 정예 공격력 ×1.5 규격(10÷1.5=6.67)과 일치한다. 계수 0.45는 **유지 확정**, 조정 레버 3개 전부 미채택(3-1장 "재검증 결과").
- **"10대"의 의미**: 이 값은 **치사성 캘리브레이션**(몇 대 맞으면 죽는가)이며 기대 피격 수가 아니다. 들개 3마리 무리전만 해도 공격 토큰 2마리 기준 12.3초 동안 약 22회의 스윙이 발생하므로, "대부분 회피한다"가 애초의 설계 전제다.

#### 5-2-1. 잡몹 넉백 거리 (확정, M2 수치 공백 해소)

넉백은 실시간 액션에서 "맞았다"는 확실한 신호이지만, 거리가 크면 플레이어 자신의 콤보(무기 2~3타)가 빗나가 손맛을 해친다. 그래서 절대값은 작게 유지하고(플레이어 피격 넉백 0.5타일보다 항상 작음), 몬스터 체급에 따라서만 차등을 둔다.

**기준값 (표준 체급)**

| 타격 등급 | 넉백 거리 | 근거 |
|---|---:|---|
| 일반 타격 | 0.2타일 | 잡몹 근접 스윙 사거리(1.5타일)에 비해 미미해 플레이어 후속 타격이 계속 들어간다 — 콤보 유지 최우선 |
| 강타·치명타 | 0.45타일 | 5-2 표 "강타·치명타 + 넉백" 규정의 실제 수치. 타격감은 강조하되 플레이어 자신의 피격 넉백(0.5타일)보다 작게 유지 |

**체급별 넉백 저항 (신규 몬스터 확장 시 이 기준을 사용)**

| 체급 | 저항 계수 | 일반 타격 | 강타·치명타 | M2 적용 예 |
|---|---:|---:|---:|---|
| 경량 | ×1.5 | 0.3타일 | 0.7타일 | 뿔토끼 — HP가 낮아 콤보 유지 부담이 없고, 가볍게 날아가는 편이 트래시몹 처치감에 어울림 |
| 표준 | ×1.0 | 0.2타일 | 0.45타일 | 들개 마수 — 시작 지역 무리 1~2마리 상대의 기준값 |
| 중량 | ×0.5 | 0.1타일 | 0.25타일 | 균열 점액 — 시작 3종 중 HP가 가장 높고 물리적으로도 "물컹한 덩어리"라 밀림이 작음 |

- 넉백 방향: 피격 지점 기준 공격자(플레이어)의 반대 방향 수평 이동. 벽 등 지형과 충돌하면 즉시 정지(경직 시간 자체는 그대로 유지, 넉백 이동만 조기 종료).
- 정예·보스는 슈퍼아머이므로 넉백이 발생하지 않는다 (상단 5-2 표와 동일 원칙).
- 잡몹이 **연속 경직 3회 후 1.5초 슈퍼아머** 상태에 들어가면, 그 구간에는 경직과 함께 넉백도 발생하지 않는다 — 별도 예외 규칙이 아니라 슈퍼아머 정의(경직 무시)에 이미 포함된 결과다.
- 종별 배정은 `m2-monster-spec.md` 3장·6장 참조.
- **본 수치는 G2-1 디렉터 플레이 세션의 튜닝 대상이다** — 여기 값은 gameplay-dev/ai-dev가 데이터에 반영할 M2 확정치이며, 손맛 검증 후 프리셋 값만 조정될 수 있다(9-1장 타격 피드백 공용 모듈 방식과 동일하게, 절대값 조정이 전체에 일괄 반영되도록 구현할 것).

## 6. 데미지 공식

```
최종 데미지 = 공격력 × 스킬 계수 × 방어 감산 × 치명타 배율 × 위치 보정 × 랜덤 보정

  공격력      = 무기 공격력 + 주스탯×2 (주스탯은 무기 계열이 결정)          … growth.md 1장
  스킬 계수   = 기본 공격 1.0 기준 배율 (7장 표)
  방어 감산   = 100 / (100 + 대상 방어력)
  치명타 배율 = 1.5 (발동 확률 = 5% + 민첩×0.05%, 상한 40%)
  위치 보정   = 후방 공격 1.15 (도적 계열 핵심 보너스), 그 외 1.0
  랜덤 보정   = 0.95 ~ 1.05 균등
```

공식 선택 근거:

1. **감산이 아닌 제산형 방어**(100/(100+DEF)): 감산형(공격-방어)은 저레벨 구간에서 데미지 0이 나오거나 고레벨에서 방어 무의미화가 일어난다. 제산형은 방어력 100당 실효 HP가 일정 비율 증가해 전 구간에서 안정적이며, GUT 자동 테스트로 검증하기 쉽다.
2. 치명타 배율 1.5 고정: 실시간 액션에서 랜덤 폭사(×2 이상)는 회피 실력과 무관한 죽음을 만들므로 낮게 고정. 대신 발동률을 스탯·장비로 성장시킨다.
3. 랜덤 폭 ±5%: 액션에서는 조작이 분산의 주역이므로 수치 랜덤은 최소화(턴제라면 ±10%를 썼을 것).
4. 속성(불/얼음 등) 상성은 **v1에서 제외**. 도감·직업 볼륨이 이미 크므로, 속성은 M3 이후 확장 후보로 보류한다.

스킬 설계 시 아래 규격을 따른다. 규격 밖 스킬은 본 문서 개정 후에만 허용.

### 8-1. 산출 공식 (동렙 일반 몬스터 기준)

```
몬스터 HP(L)     = 기준 DPS(L) × 방어 감산 × 5          → 목표 TTK 5초 보장
몬스터 공격력(L) = 플레이어 최대 HP(L)의 10%가 실피해가 되도록 역산
                 = 0.10 × 플레이어HP(L) × (100 + 플레이어 방어력(L)) / 100
몬스터 방어력(L) = 0.5 × L
정예: HP ×6, 공격력 ×1.5   /   보스: HP ×40, 공격력 ×2.5
```

| 연결 | 방향 | 내용 |
|---|---|---|
| 전투 ↔ 직업 | 상호 | 스킬 규격(7장)이 직업 스킬 설계의 상한. 직업 고유 우클릭·게이지는 `jobs.md` |
| 전투 ← 성장 | 참조 | 플레이어 스탯·장비 공식(`growth.md` 1~3장)이 8장 곡선의 입력값 |
| 전투 → 경제 | 제공 | 시간당 처치 수(약 300마리 환산/시간, `growth.md` 5장)가 드랍률·골드 유입의 기준치 |
| 전투 → 도감 | 제공 | 9-2장 패밀리 구조 = 몬스터 도감 종 수(약 120종)의 근거. 야간종은 아종 슬롯에 배정(2-3장) |
| 전투 ← 시간 | 참조 | 주야간 규칙(2-3장): 야간 ×1.2·보상 상향. 낮 20분:밤 10분은 `reputation-territory.md` 4장에서 확정 |
| 전투 ← 펫 | 참조 | 펫 3역할 규칙(2-4장): 실효 전투력 기여 +10% 상한 — 초과 시 8장 TTK가 무너지므로 펫 상세 설계 시 준수 |

## 11. 경제 전제 교차 확인 — **완료 (2026-07-16)**

`docs\design\economy\economy-foundation.md` 작성 완료로 교차 확인 종료. 본 문서가 제공한 전제 5건의 반영 결과:

| 본 문서의 전제 | 경제 문서 반영 |
|---|---|
| ① 시간당 처치 약 300마리(환산) | 골드·드랍 유입 기준치로 채택 (economy 1장) |
| ② 기준 장비 = 동렙 B급 (`growth.md` 3장) | B급 = 등급 배율 1.00 기준선, "동렙 B급 8슬롯 자연 유지" 검산 성립 (economy 2-6장) |
| ③ 등급 격차 TTK ±40% 이내 | 등급 배율(C 0.85 / B 1.00 / A 1.15 / S 1.32) + 부옵 + 장신구 총합으로 검산 통과 (economy 2-2장) |
| ④ 야간 드랍 ×1.15 | **채택 확정** — 일반·정예 아이템 한정, 골드 제외 (economy 9장, 본 문서 2-3 확정 반영) |
| ⑤ 스마트 드랍·특수무기 규칙 | 드랍 슬롯 분포(economy 2-5장)·특수무기 2유형 규칙(economy 4장)으로 확정 |

- 경제 문서 머리말에 "전제 불일치 없음"이 명시되어 있으며, 포션 보스전 5회 하드 캡(economy 5-2)도 5-4장에 반영 완료.
