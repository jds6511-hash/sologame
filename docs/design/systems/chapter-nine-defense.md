## 1. 선택과 플레이 흐름

기존 3장 순차 무리만 복제하면 반복 토벌이 되고, NPC 체력/경로/영구 실패를 가진 호위 시스템까지 만들면 이번 범위가 커진다. **대피 구역 확보 + 현장 지원 조작 + 3단계 군후전**을 선택한다. 주민은 대피 장면과 완료 상태로 표현하며 실제 길찾기/피격 대상이 아니다. 주민 보호를 동적 NPC 호위 AI로 보고하지 않는다.

잿골에서 보급로를 따라 발크렌에 도착한다. 지휘소 한 곳에서 수락/보고하고, 현장 통신으로 메인01~04 보고를 허용한다. 마지막05만 지휘소에서 보고한다. 방어 도중 브란텔·노베라 왕복이나 시설 구매·전직·Lv60 자체를 요구하지 않는다. R9 공훈6,200과 MQ-08-05 완료는 최초 수락 조건이며 레벨 보정은 없다. 기준 공급7,800, 서브 공훈20% 손실7,280은 예산 모델이며 실제 저널을 검사한다.

## 4. 방어와 대피 상태

공통 EncounterController를 도입하고9장 데이터로 구동한다. 3장 기존 스폰 계약은 그대로 두고 기본값 회귀를 검사한다. 생성 수는 `목표 잔량 - 같은 source의 살아 있는 수`, 전체 활성 적 상한4다. 삭제 대기 개체도 자리를 점유한다. 신호 재진입 중에는 생성 잠금으로 두 번째 시작을 거부한다.

MQ09-02 각 구역은 F로 시작한다. 주민은 부채꼴 대피 표시로 표현하고 플레이어가 표시 원(반경48px) 안에서 살아 있고 입력 가능한 동안8초를 채우면 그 구역 INTERACT1을 기록한다. 구역 밖0.5초 또는 사망/월드 이탈이면 미완료8초만0으로 돌아간다. 피격은0.5초 동안 진척을 멈추며 공격·회피를 금지하지 않는다. 메뉴/대화 pause 동안 진척·적 행동 모두 정지한다. 주민 HP/영구 사망/숨은 시간 제한은 없다. 압박 적2개를 생성하되 **EXP·골드·아이템은 없고** 추가 자동 재출현도 없다. 쓰러뜨려 안전하게8초를 채우는 선택도 허용한다. 완료 구역은 다음 재개/로드에서 다시 만들지 않는다.

MQ09-03 장치와 감응 표식은 F로 활성화하면 저널에 각각 완료된다. 감응은 군후 돌진 예고를 기본값보다0.25초 길게 하는 고정 지원, 방벽 장치는 후방의 엄폐 그림/안전 통로 안내로 표현한다. 후자는 물리 피해 차단 능력이라고 표시하지 않는다. 세 척후는 기존 순차 KILL 카운트·보상 경로다. 모든 지원은 목표 완료 상태에서 파생되며 스탯 영구 버프나 신규 저장 상태가 아니다.

실행 상태 idle→active→objective_done 또는 suspended. 사망 시작 신호에서 즉시 판정/타이머/적 공격을 끄고 구역/보스 임시 개체를 정리한다. 지역 이탈도 동일하다. 같은 월드 부활 후 F로 재개한다. 로드 시 완료 카운트만 복원하고 idle로 시작한다. 자동 전투 시작은 없다. 전용 압박 적/보스 소환병은 시련처럼 공격 리졸버만 연결해 무보상으로 두며 일반 몬스터 보상 경로의 기본값은 바꾸지 않는다.

## 5. 군후 보스 계약

전장 소집 표식(256,448) F로 시작. 전장 bounds 안 중앙(640,448)에 군후1을 만들고 보스 HUD에 이름·HP·현재 예고를 표시한다. 첫 구현 수치: Lv68, HP24,000, 공격력500, 방어50, 이동3타일/s, is_boss=true. 야간 HP/공격 증폭 없음, 보스 등급 EXP는 기존 곡선 배율을1회 적용한다. 이 수치는 구현 출발값이며 C급/직업별 실전 난이도 승인값이 아니다.

| 단계 | HP / 패턴 | 판정·휴식 |
|---|---|---|
|1|100~65%: 전방 부채꼴 베기|반경64px·각100도, 방향은 예고 시작에 고정. 예고0.9초/판정0.12초/후딜0.9초, 기본공격×1.0|
|2|65~30%: 베기↔직선 돌진, 전환 때 척후2소환1회|돌진 길이160px/폭24px, 예고1.15초(기본0.9+감응0.25)/속도160px/s/후딜1.1초, ×1.2, 벽에서 정지|
|3|30~0%: 베기↔돌진↔충격환|원점은 예고 시작에 고정, 반경96px의 채운 원, 예고1.2초/판정0.12초/후딜1.2초, ×1.25|

65/30% 전환은 중복 실행하지 않는다. 큰 피해로 두 경계를 넘으면 낮은 HP 단계로 한 번만 전환하고 단계2 소환도 최대 한 번이다. 사망이 항상 단계 전환보다 우선한다. 전환은 현재 판정을 취소하고0.8초 회복 후 다음 예고로 넘어가며 무적/HP 회복은 없다. 소환병 처치는 보스 무적 해제 조건이 아니며 무보상·퀘스트 카운트 밖이다. 보스1+소환2로 상한4 이내다.

기존 정예 그로기 훅을 쓰되 넉백/통상 경직으로 보스를 무한 고정하지 않는다. HP25% 누적 피해로 그로기2초, 이후 게이지0; 그로기 진입 시 현재 예고/공격을 취소한다. 각 판정 구간은 플레이어당1회만 피해를 주고 재진입/동일 프레임 신호로 중복 타격하지 않는다. 예고 도형과 실제 판정 중심/폭/반경을 같은 데이터에서 읽는다. 공간 전체를 동시에 덮는 추적 장판이나 회피 불가능한 즉발은 없다.

플레이어 사망/이탈/로드는 보스 HP·단계를 초기화한다. 완료된 군후 KILL1은 저널에 남아 재생성하지 않는다. 보스 처치와 목표 갱신·EXP/드롭은 기존1회 사망 경로로 실행하며 피해 주입과 실제 공격 경로 검사를 분리한다. 보스 완료와 플레이어 사망이 같은 프레임이면 이미 유효하게 기록된 처치는 되돌리지 않는다. 단 보상 API 실패나 오류는 성공으로 삼지 않는다. 부분 HP 저장/중간 단계 저장은 지원하지 않음을 안내한다. 정상 저장 금지 판정은 그대로이며 이벤트 active 상태도 저장 거부 사유에 명시한다. 탈출은 허용하되 세션 상태를 먼저 중단한다.

## 6. 콘텐츠·저장·검증

`chapter_nine.json`은 장 표/배치/ENCOUNTERS·패턴 파라미터를 담고 기존 생성기가 정의를 만든다. 런타임 `encounter_controller.gd`, `warlord_monster.gd`와 주민 구역/HUD 부품은 공통 제품 설치에 연결한다. 새 장 전용 세션·후보 검증기 사슬은 만들지 않는다. UI 진척과 보스 단계는 런타임, 영구 진척은 기존 저널 state/counts에만 둔다. `INTERACT`는 F를 눌렀다는 뜻이 아니라 런타임이 조건 충족 후 발신하는 기존 이벤트 종류다. 일반 표식 스크립트로 대피 완료를 우회할 수 없도록 예약 source를 분리한다.

구 V7 개정1~7은 새 ID·9장 지역을 허용하지 않는다. 개정8은 통합 목록/의뢰 선행/지역 잠금/공훈 합계를 검증한다. 미래 개정은 unsupported_content로 백업 우회 없이 거부한다. V1~제품V6는 동결 원본 검증 후 이관, 기존 실제 저장은 자동 완료·레벨 보정·영지 초기화 없이 보존한다. 후보V8은 만들지 않는다.
