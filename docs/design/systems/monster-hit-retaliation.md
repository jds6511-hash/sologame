# 몬스터 피격 반격

- 2026-10-03 / Codex. 디렉터 요청: 몬스터가 내 공격에 맞으면 나를 공격하게 한다.
- 변경 이력: 토끼·점액의 빠진 피격 반격을 기존 공격 블록에 연결. 저장 형식·콘텐츠 개정 유지.

들개·거미·강도·임프 계열은 기존 피격 추격과 무리 어그로를 유지한다. 토끼와 점액은 실제 HP가 감소하고 살아남았으며 유효한 공격자가 있을 때 공격자를 대상으로 삼는다. 토끼는 추격 후 박치기, 점액은 투사체 사거리까지 접근 후 기존 조준·발사로 반격한다. 평시 토끼의 도주와 점액의 인지 행동은 유지한다.

새 반격은 스폰 위치에서 자신과 공격자 모두 16타일 안에 있을 때만 지속한다. 공격자가 사망·해제되거나 범위를 벗어나면 귀환하고, 스폰 도착 시 기존 귀환 함수대로 HP를 회복한다. 이 16타일은 토끼·점액에만 적용하며 기존 추격 종의 거리 규칙은 바꾸지 않는다. 지형 경로 탐색을 새로 추가하지 않으므로 장애물 뒤까지 도달함을 보장하지 않는다.

진행 중인 박치기·조준·쿨다운을 피격 때마다 재시작하지 않는다. 경직·그로기·점액의 핵 파괴/자폭은 기존 경로를 유지한다. 공격자 없는 환경 피해, 피해 0, 사망 타격은 새 반격을 시작하지 않는다.

검증 순서: 실패 테스트 → 대상 AI 회귀 → verify_all → 통합 검토. 별도 조작기 안정화나 재완주 요구는 하지 않는다. 이전 편의 검토의 토글 달리기 일시정지 해제는 현재 동작을 유지한다.
