## 1. 구조: "10개 직업 = 10개 계열, 전직은 계열 안에서 심화"

게임 컨셉의 "직업 총 10개(히든 2개), 모험가 시작 → 10레벨 전직 → 3차 전직까지"를 다음 구조로 확정 제안한다.

```
모험가 (Lv 1~10, 전원 공통)
   │  Lv 10 — 1차 전직: 10계열 중 선택 (일반 8 / 히든 2는 조건 해금)
   ▼
1차 직업 (Lv 10~40) ─ Lv 40 — 2차 전직: 같은 계열의 상위 직업 + 고유 게이지 해금
   ▼
2차 직업 (Lv 40~80) ─ Lv 80 — 3차 전직: 같은 계열의 최종 직업 + 궁극기 각성
   ▼
3차 직업 (Lv 80~100)
```

- **"직업 10개" = 계열 10개.** 전직은 계열 내 직선 심화(분기 없음)로, 전직할 때마다 직업명이 바뀌고 새 스킬·메커니즘을 얻는다.
- 분기 없는 직선 트리를 택한 근거: 실시간 액션에서 직업 1개의 비용은 애니메이션·히트박스·이펙트에 거의 선형으로 비례한다(combat-options.md A안 리스크). 분기를 만들면 계열 수 × 분기 수만큼 제작비가 늘어나므로, **가짓수는 계열 10개로 고정하고 깊이(전직 3단)로 성장 체감**을 만든다. 계열 내 빌드 다양성은 스킬 포인트 선택(`growth.md` 6장 — 전 스킬을 풀업할 수 없는 포인트 경제)으로 확보한다.
- 전직 레벨 10/40/80의 페이스: 플레이 시간 기준 약 **1.8시간 / 31.5시간 / 127.5시간** 지점 (`growth.md` 5장 곡선). 초반에 빠르게 정체성을 주고, 3차 전직이 중후반(전체 250시간의 약 절반 지점)의 큰 리프레시가, 3차 구간(80~100, 약 72시간)이 엔드게임의 몸통이 되도록 배치했다.

- **소환사 ↔ 감응자(히든) 차별화**: 소환사는 **독립 소환수(환수)를 지휘하는 간접 조작** — 본체가 취약한 대신 환수가 전선을 유지하고, 플레이어는 위치 선정과 지휘에 집중한다. 감응자는 **소환수가 없다** — 정령의 힘을 자기 몸에 둘러(스탠스) 직접 싸우는 변신형 근·중거리 전투. "부리는 자"와 "몸에 두르는 자"로 판이하게 갈린다.
- 히든 2종은 세계관의 종족 마법 체계(worldview.md 7.2 — 드워프의 룬, 엘프의 감응)를 인간 플레이어가 배우는 서사로 설계했다. 종족 서브퀘스트 라인과 직업 시스템이 맞물리는 지점.

공통 조작(`combat.md` 3장) 위에서 **우클릭(보조 동작) + 대시 특성 + 2차 게이지**로 손맛을 가른다.

| 계열 | 우클릭 (보조 동작) | 대시 특성 | 2차 게이지 (Lv40 해금) | 3차 각성 (Lv80) |
|---|---|---|---|---|
| 전사 | 차지 강타 (홀드, 슈퍼아머) | 2회, 표준 | **분노**: 피격·타격 시 충전 → 소모 시 강화 일격 | 궁극기 각성 + 차지 단계 3단으로 |
| 기사 | **가드** (홀드) / 적중 직전 가드 시 **저스트 가드** → 반격 창 | 2회, 거리 짧음(방패 스텝) | **용맹**: 가드 성공 시 충전 → 반격기 강화 | 가드 중 이동 가능 + 광역 도발 각성 |

| 궁수 | 조준 모드 (홀드 — 이동 느려지고 관통·사거리 증가) | 2회, 후방 점프 회피 | **집중**: 연속 명중 시 충전 → 필중 강화샷 | 조준 모드 중 이동 페널티 절반 |

| 격투가 | 잡기 (그로기 유발 보너스) | **3회**, 거리 매우 짧음 | **투기**: 연타로 충전 → 오의(연속기) | 오의 파생기 추가, 대시 공격 캔슬 |
| 룬각인사 | 룬 장치 회수/재배치 | 2회, 표준 | **과열**: 장치 가동으로 충전 → 전 장치 일제 기동 | 장치 동시 설치 2→3개 |
| 감응자 | 정령 스탠스 교대 (불=화력/바람=기동/물=회복) | 2회, 스탠스별 부가 효과 | **교감**: 스탠스 유지로 충전 → 정령 현신 (자신이 정령의 힘을 두르는 **변신 강화** — 소환수 아님) | 현신 지속 증가, 이중 스탠스 각성 |

- 설계 원칙: ① 우클릭 하나만 바꿔도 조작 리듬이 달라지게 (가드형/차지형/이동형/자세형/설치형/교대형) ② 게이지는 전부 "**잘 싸우면 차는**" 능동 충전 — 시간 충전 없음 ③ 3차 각성은 새 버튼 추가가 아니라 **기존 조작의 확장** (조작 복잡도 상한 유지).
- 각 직업의 스킬 개수: 모험가 공용 3 + 1차 4(궁극기 1 포함) + 2차 4 + 3차 4 = **직업당 총 15개** (스킬 계수·쿨다운은 `combat.md` 7장 규격 준수. 3차를 4개로 둔 것은 3차 구간이 Lv80~100, 약 72시간으로 가장 길기 때문). 애니메이션 제작비 통제: 스킬 모션은 계열 내에서 전직 후에도 **기존 모션 재사용 + 이펙트 교체**를 기본으로 한다 (combat.md 9장 완화 전략과 동일 기조).
- **소환사 밸런스 특칙**: 소환사의 기준 DPS는 **본체 + 환수 합산**으로 `combat.md` 7장 규격을 만족해야 한다 (환수 화력이 전체의 50~60% 담당). 환수는 직업 화력의 일부이므로, 펫의 "기준선 밖 보너스 +10% 상한"(`combat.md` 2-4)과는 별개 취급 — 소환사도 펫을 따로 데리고 다닌다.
- 생존 규격: 전 직업은 3차까지 **자가 회복 또는 피해 경감 스킬을 최소 1개** 보유해야 한다 (`combat.md` 5-4장 회복 규칙과 함께 "전 직업 솔로 클리어" 원칙을 보장).

## 4. 히든 직업 해금 조건

히든 직업은 **1차 전직 시점(Lv10)에는 선택할 수 없고**, 조건 달성 시 "특별 전직"으로 전환한다.

| 히든 직업 | 해금 조건 (3단계 모두 충족) | 전환 장소 |
|---|---|---|
| 룬각인사 | ① 드워프 서사 라인 서브퀘스트(두르간 '강철 조약' 관련) 완료 ② 룬 조각 5개 수집 (강철산맥 지역 특정 몬스터 저확률 드랍 — 도감 힌트 제공) ③ 드워프 장인 NPC의 시험 통과 | 카른두름 (드워프 자치령) |
| 감응자 | ① 엘프 서사 라인('잿빛 밤' 진상) 서브퀘스트에서 **화해 선택지** 진행 ② '정령의 눈물' 획득 (실비엔 대수림 히든 보스 드랍) ③ 대수림 제단 의식 수행 | 실비엔 대수림 제단 |

- **특별 전직 규칙**: 현재 직업 단계에 대응하는 히든 직업 단계로 전환된다 (1차↔1차, 2차↔2차). 레벨 유지, 스킬 포인트 전액 환급. **3차 전직 완료 후에는 전환 불가** (3차 각성 서사와 충돌 방지). 히든 → 일반 복귀는 재서임 정책(7장)을 따른다.
- 설계 근거: 해금 조건이 종족 서사 라인(중반 콘텐츠)에 걸려 있어 Lv10 시점 선택은 사실상 불가능하다. "발견하면 갈아탈 수 있는 비밀 직업"이 히든의 정체성이며, 도감·탐험 동기(룬 조각, 히든 보스)와도 맞물린다.
- 퀘스트 상세(단계·대사·배치)는 quest-designer 소관 — **퀘스트 연계 필요**: 해금 조건의 난이도·시점(권장 Lv 30~50 구간 달성 가능 — 2차 전직 Lv40 전후로, 히든 전환이 2차 초반의 큰 이벤트가 되는 배치)을 본 표와 맞출 것.

## 5. 무기 제한 · 스마트 드랍 · 무기 도감 (디렉터 확정 반영)

### 5-1. 무기 제한

- **계열당 전용 무기 1종** (2장 표). 타 직업 무기는 장착 불가.
- 모험가(Lv 1~10)는 공용 무기 **소검**만 사용. 전직하면 소검은 장착 불가가 되고 직업 무기로 교체된다 (전직 시 1차 직업 무기 C급 1개 지급).
- 방어구(모자/신발/갑옷/하의)·장신구(반지×2, 목걸이)는 **전 직업 공용** (장비 8슬롯 구조는 `growth.md` 3장). 단 방어구에 계열 태그(중갑/경갑/로브 선호)는 두지 않는다 — 슬롯이 8종으로 확정된 만큼 무기 1슬롯만 직업 제한으로 단순하게 유지.

### 5-2. 스마트 드랍 (디렉터 확정)

- 직업 확정(1차 전직) 후 필드 드랍 무기는 **자기 직업 무기만** 나온다. 모험가 구간은 소검만 드랍.
- 직업당 무기가 정확히 1계열이므로 스마트 드랍 구현이 단순해진다 (드랍 테이블에서 무기 계열 1개만 활성).
- 히든 직업 전환 시 드랍 테이블도 즉시 새 무기 계열로 전환. 기존 무기는 판매/보관 가능.
- **특수무기**(퀘스트 보상·특정 몬스터 한정 드랍, GAME_CONCEPT): 각 특수무기는 특정 계열 소속으로 설계하되, **퀘스트 보상형은 수령 시점의 직업 계열 버전으로 지급**한다(스마트 드랍 원칙 유지). 몬스터 한정 드랍형의 드랍률·성능 규격은 `economy-foundation.md` 4장(특수무기 2유형 규칙)에서 **확정 완료**.

### 5-3. 무기 도감 분리 집계 (디렉터 확정 절충안)

- 아이템 도감의 무기 탭은 **직업 계열별 11개 섹션**(10계열 + 공용 소검)으로 분리 집계한다.
- 도감 완성률·완성 보상은 **자기 직업 섹션 + 공용 섹션 기준**으로 판정 → 스마트 드랍 아래에서도 무기 도감 100%가 가능하다.
- 타 직업 섹션은 열람만 가능(미확인 실루엣 표시). 재서임/히든 전환으로 다른 계열을 플레이하면 해당 섹션도 채울 수 있다 (완성 판정에는 불요).
