## 실제 배치

던전 `novera_rift`는1024×640, 외곽 지형·기존 표식은 그대로다. 던전은16px 타일, x20/48의 방 사이 벽에 y17~23의 통로를 둔다. 기존 점액 AI·타일을 사용한 기능용 공간이며 완성 미술이 아니다.

## 의뢰 선택과 저장

후반 의뢰를 고르는 버튼은 새 후보 대화창에만 추가한다. 기존 두 지역의 실행 중 대화창에 스크립트를 갈아 끼우지 않는다. 선택 의뢰는 지역 이동에만 메타데이터로 넘기고 도착 시 선행/현재 상태를 다시 확인한다. 저장 필드로 추가하지 않으며 새 게임/불러오기에는 이 선택 전달을 하지 않는다.

내부 검토 낮음: 로드 후 서브만 active이고 MQ05가 미수락이면 지도는 active 서브를 우선하지만 HUD 접수원 안내는 MQ05 수락을 우선할 수 있다. 의뢰 선택/수행은 가능하며 다음 안내 개선 묶음에서 우선순위를 통일한다. 이를 해결됐다고 주장하지 않는다.

정상 플레이 저장은 `user://m7_closure_candidate_play`, 바로 체험은 `user://m7_closure_candidate_quick_play`, API 세션 검증과 전투 검증은 각각 별도 후보 폴더를 사용한다. V6 목록을 넓히지 않고 V7에서만 신규 지역·의뢰를 허용한다. 기본 채택/사용자 기존 파일 직접 이관은 수행하지 않는다.

## 검증의 의미

전체 GUT1139/1139(131 scripts), 신규 저장7건·콘텐츠2건을 포함한다. 콘텐츠 테스트는5개 지역 부팅·카탈로그/예산·표식/source 순서·가레스 보고·지형 충돌을 검사한다. 저장 테스트는 구버전 거부/원본 불변·멱등·새 지역/선행 조건을 검사한다.

API 세션은 준비 상태·좌표/목표 이벤트를 사용하고 중간/완료 파일을 별도 프로세스로 비교한다. 전투 배치는1장 완료만 준비하고 이후 입력으로 수행한다. 실제 포인터 이동·표시 버튼 신호가 있으며 네이티브 입력이나 사람 체감의 대체가 아니다. 최종 배치 결과와 EXP 실측은 통합 검토서에 기록한다.

고정3회 결과는0/3이다. 세 번 모두 첫4건 완료 후 누적EXP19,731(준비3,820+보고15,000+처치911), Lv10을 관측했다. 던전 실제 처치/유물 조사 이후 외곽 귀환 도보 제한으로 실패해 장 전체 처치 EXP·후반 보고 후 성장·최저 거래 잔액은 정상 입력으로 끝까지 측정하지 못했다. API 보상 합계 검증을 실제 전투 성장 실측으로 대체하지 않는다.
