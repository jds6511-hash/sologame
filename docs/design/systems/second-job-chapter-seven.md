# 7장 앞 2차 전직 상세 설계

2026-10-03 / Codex. **설계 검토 대기, 구현 전**. 의존: [2막 계획](../act-two-plan.md) P5, [직업](jobs.md), [전투](combat.md), [EXP 여유 계약](../100-hour-exp-margin.md), [성장 장부](../../qa/act-two-growth-ledger.md). 현행 제품 V7/개정5이며 아래 도입은 개정6을 제안한다. 옛 문서의 ‘검투사 무기 미발행·2차 UI 없음’은 현행 구현과 다르다.

## 범위와 진입

전사→검투사 완성, 궁수→명사수 추가를 7장 콘텐츠와 하나의 구현 묶음으로 만든다. 각4개 전용 스킬, 게이지/HUD, 계열 시련, Lv40 B 무기, 장비·스킬 지출·저장을 연결한다. 다른8계열·히든·3차·새 원화는 제외한다. 현행 V키 전직 화면과 공통 전직·경제 모델을 확장한다.

조건은 Lv40, 같은 계열 1차 직업, 해당 시련 완료다. 정상 승급 수수료는 없다. 기존 계열 스탯 배분·성장 곡선을 승계하며 SP+2와 계열 Lv40 B무기를 정확히1회 지급한다. 전직 지급은 기존 EconomyRuntime 한 경로를 사용하고 가방 공간 부족이면 직업·SP·장비·가방 전부 불변으로 거부한다. 취소는 아무것도 지급하지 않는다.

MQ-07-01은 전직·시련·선택 종족 의뢰 없이 보고할 수 있다. 최초 보고1,000,000EXP는 기존 메인 풀에서 앞당긴500,000과 확정 추가500,000이며 후속 보상에서 전자만 차감한다. 전직 이후 보상을 G40 이전 공급에 더하지 않는다.

**성장 선행 위험:** 4~6장 실제 데이터의 낮/개별 의뢰 모델은 기준 서브 포함 Lv35, 메인만 Lv30이다. 7장 첫 보고 후 전자는 G40을 넘지만 후자는499,983 부족하다. 따라서 모든 경로 즉시 전직은 미보장이다. 7장 구현 때 기초 첫 보고·필수 처치 및 B 경로(선택 서브 생략)를 현행 여유 계약과 함께 재계산한다. 합격선에 못 미치면 그 성장 연결을 미통과로 보고하며 시련 선보상·무료 레벨·의무 무한사냥으로 우회하지 않는다. 부족이 발생한 기존 처치 풀을 정상 콘텐츠로 공급하는 방안은 별도 수치 대조 후 제시한다.

## 시련과 재개

두르간의 훈련 담당NPC가 공용 소형 훈련장을 안내한다. 계열별 별도 ID `TR-WAR-02`, `TR-ARC-02`를 통합 의뢰 목록에 등록하되 장 메인6/서브13과 보고 예산 합계에서는 별도 분류한다. 목표 source는 `trial_war_heavy`, `trial_war_guard`, `trial_arc_near`, `trial_arc_far`처럼 계열/행동별로 분리한다. 훈련장 이동은 출입구별 간선·도착점을 쓰며 복귀는 잠그지 않는다.

- 전사: 예고를 가진 훈련 적2마리를 우클릭 차지 강타 등 **강 등급 타격**으로 마무리 → 회피 가능한 돌진 훈련 적1마리 처치 → 담당NPC 보고. 강 등급 마무리는 제품 사망 hit_grade와 source로 기록한다. 중 등급인 1키 기본 강타의 사용 여부를 검사하는 시련이 아니다.
- 궁수: 가까운 표적2개와 먼 표적2개를 실제 화살로 각각 명중 → 이동하는 훈련 적1마리 처치 → 담당NPC 보고. 거리 목표는 발사 순간 충돌 중심 간 거리(가까움≤4타일, 멂≥8타일)로 판정한다. 표적은 상태 주입용 버튼이 아니며 실제 투사체 피해 이벤트를 받는다.
- 실패는 사망/현장 이탈이다. 완료한 목표 count는 저널에 남기고 미완료 수만 재개한다. ‘재개’ 생성 수는 목표잔여−같은source의 살아 있는 개체 수이고 음수는0이다. 로드 직후 자동 교전은 없다. 목표를 채운 표적은 다시 진행을 주지 않는다.
- 시련 자체 EXP·골드·공훈은 **0 제안**이다. 목적은 조작 습득과 승급 자격이며 최종 전직SP·B무기가 보상이다. 오래된 의뢰 개요의 ‘60마리분 EXP·명성4’는 현행 장별 예산에 배정되지 않았으므로 자동 적용하지 않는다. 이 변경 방향을 설계 검토 질문에 포함한다.

시련 보고와 전직은 분리한다. 보고 완료 뒤 V에서 확정할 때 레벨·이전 직업·시련·소유 공간을 다시 검사한다. 이미 2차인 캐릭터는 버튼이 없고, 불러오기·월드 교체로 지급 이벤트를 다시 호출하지 않는다.

## 검투사

현행 회오리/돌격 강타/피의 함성/처형 4개와 분노 구현을 유지한다. 최대100, 처형≥50 전량 소비, 격노≥80 공격+12% 등 기존 정본 수치를 재설계하지 않는다. 현재 null인 지급 무기를 이미 발행된 `WPN-GS-40-B`에 연결하고 낡은 주석을 정정한다. 기존 검투사 저장을 되돌리거나 무기를 로드마다 새로 지급하지 않는다.

## 명사수 — 검토할 신규 수치

궁수 성장·기본 화살·우클릭 조준·공통1/2/3스킬을 승계한다. 슬롯4/Q/E/R의 1차 스킬을 아래4개로 대체하고 제거된 스킬 투자분은 기존 규칙으로 환급한다. 기본 사거리와 커서 조준 기준은 유지한다. 아래 계수는 공격력 배율이며 신규 초깃값으로 검토한다.

| 슬롯 | 기술 | 피해/효과 | MP / 재사용 | 집중 |
|---|---|---|---|---|
| 4 | 연속 정밀사격 | 커서 방향3발, 발당0.8배, 간격0.12초, 기존 사거리 | 18 / 6초 | 충전 가능, 시전당 최대10 |
| Q | 후퇴 사격 | 입력 방향 회피 후1.2배1발. 이동 충돌·회피 규칙은 기존 궁수와 동일 | 16 / 8초 | 충전 가능10 |

집중 최대100. 기본/대상스킬의 한 사격 묶음이 적에게 유효 피해를 주면10, 직전 사격 묶음도 성공이면 추가5(시전당 최대15, 연속정밀은 별도 상한10). 피격 시20 감소, 유효 명중5초 없이 지나면 초당10 감소한다. 호흡 정돈은 시전만으로 충전하지 않고 다음 성공 묶음에만20을 더한다. 효과가 만료되면 보너스는 사라지고 중첩하지 않는다. 사격하지 않고 이동하는 동안 연속 성공 수만 유지해 무한 충전하지 않는다. 사망/직업변경/월드교체/로드 시0이며 일시정지 중 감쇠하지 않는다. 저장 안전 조건은 기존 사격·스킬·전투 조건을 유지한다.

사격 묶음은 발사시 고유ID, 예정 투사체 수, 유효피해 여부, 미결투사체 수를 가진다. 한 발이라도 유효 피해면 성공1회다. 관통·다중 표적·동일 프레임 중복 충돌로 충전이 늘지 않는다. 모두 수명 종료/지형충돌/월드제거될 때까지 피해가 없으면 실패로 연속 성공을 끊는다. 발사 취소·무기 교체 등으로 실제 투사체를 만들지 못하면 자원/쿨다운/사격 기록을 확정하지 않는다. 발사 후 대상 사망은 날아간 투사체가 다른 적을 맞힐 수 있고, 끝내 피해가 없으면 실패다.

‘강화샷’은 위 관통탄이며 자동 명중이나 벽 통과가 아니다. 커서 방향과 실제 충돌을 따른다. 표적 읽기/조작기 보정은 제품 조준에 넣지 않는다. 화면에는 집중 수치와 소비 가능 여부, 개별 재사용 시간을 표시한다.

## 장비·저장·구버전

명사수 ID `sharpshooter`, 활 `WPN-BW-40-B`를 경제 정본의 Lv40 B 생성식으로 발행한다. 임의 공격력/가격을 따로 정하지 않는다. 장착 조건·스마트 드롭·툴팁·스킬 manifest·직업 선택·복원은 공통 목록을 확장한다. 명사수는 활 계열, 검투사는 대검 계열을 유지한다.

영구 상태는 기존 직업ID·스킬지출·가방·의뢰count에 들어가므로 **형식 V7 유지/콘텐츠 개정6**을 제안한다. 집중·분노·발사 묶음은 일시 상태로 저장하지 않는다. 새 직업/스킬/시련의 도입 개정을 목록에 기록하고 낮은 content_revision에서 새ID를 주장하면 거부한다. V1~제품V6 동결 검증기는 수정하지 않는다.

기존 검투사 저장에는 시련 완료가 없다. 이를 로드 거부하거나 완료 시련/보상을 만들어 넣지 않는다. 로드는 기존 직업·레벨·스킬 규칙으로 허용하고, 시련 조건은 **새 전직 행위의 조건**으로 검사한다. 이 호환 선택 때문에 저장 파일만으로 ‘과거 시련 수행 사실’을 증명한다고 주장하지 않는다. 현행 직업을 개정6으로 다시 저장해도 시련 부재 때문에 다음 로드가 막히지 않게 테스트한다.

## 구현·검증 순서

1. 발사ID·종료/유효피해 신호와 집중 단위 테스트, 기존 궁수 명중·방향·소비 회귀.
2. 명사수 정의/4스킬/무기/HUD와 검투사 지급 연결, 공간 부족·취소·중복·복원.
3. 표/생성기 기반 시련·7장 지역/메인6/서브13/신규5종, S7 보상 선후와 성장 경로 대조.
4. 단일 verify_all: 전체 GUT, 두 계열 시련·전직·명중/실패·실제피해·장비·스킬 지출·프로세스 복원, 실제 저장 해시. 조작기 전투는 참고 옵션이며 승인 관문으로 부활시키지 않는다.
5. 7장과 하나의 구현 검토. 현재6장 중간 체감은 별도이며 다시1막 재완주를 요구하지 않는다.

변경 이력: 2026-10-03 승인 계획의 2차 전직을 구체화. 신규 명사수 수치·시련 무EXP안·기존 검투사 호환은 설계 검토 전이며 제품에 적용하지 않았습니다.
