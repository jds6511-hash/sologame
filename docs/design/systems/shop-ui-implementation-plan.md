# 상점·기능 메뉴 재설계 구현 계획

- 날짜: 2026-09-30 / 담당: Codex
- 근거: [승인된 재설계](shop-inventory-typography.md). 디렉터의 적용 지시에 따라 추가 승인 없이 실행한다.
- 변경 이력: 최초 작성. 내부 단계는 나누되 외부 검토는 제품 기능 한 묶음으로 한다.

목표: ESC 게임 관리 분리와 상점/가방/장비의 목적별 조작을 실제 게임에 적용한다.

- [x] `integrated_menu.gd`, `save_menu.gd`, `economy_panel.gd`: ESC와 B/I/C/K/J/M 진입, 저장 복귀, pause 소유권 연결. 중복 창/ESC 이중 입력 회귀 검사.
- [x] `economy_panel.gd` 및 표시 도우미: 세로 상품 행, 6열 가방, 고정 거래 영역, 장비 슬롯/후보/비교. 구매/착용 단일 확정, 판매 확인, 수량과 오류 표시. 기존 런타임/저장 모델을 재사용한다.
- [x] `economy_runtime.gd`: 거래에서 저장용 대기를 분리하고 사망/잠금/거리/재진입을 보존한다. 장비 변경 시 캐릭터 화면 갱신.
- [x] 경제 UI/메뉴 테스트와 기존 경제 probe를 새 조작 계약으로 갱신한다. 전체 GUT, 경제 별도 프로세스 복원, 렌더/입력 검사를 실행한다.
- [x] 실행 안내·설계 구현 상태·기존 통합 검토서·진행/인계를 갱신하고 명시 경로만 커밋한다. 다른 작업자의 PNG와 임시 로그는 제외한다.

검증 종료 기준: 변경 경로의 검증 통과, 실제 렌더 확인, 미구현 항목과 사람 체감을 구분한다. 경제 UI 변경으로 기존 M6 전투 1/3 결과를 통과로 바꾸지 않는다.

구현 중 람다 연쇄 호출의 포맷 결과를 엔진이 거부한 사례는 취소 콜백을 독립 함수로 분리해 해결했다. 최종 코드로 전체 GUT와 경제/렌더 검증을 다시 실행한다.
