## 0. 설계 전제와 Lv40 곡선 컨텍스트

검투사 활동 구간은 Lv40~80이다. 밸런스 정합의 기준점은 전직 직후인 **Lv40**(`combat.md` 8-2 곡선)이다.

| 항목 | Lv40 값 | 용도 |
|---|---:|---|
| 플레이어 물리 공격력 | 265 | 스킬 계수 × 공격력 = 실데미지 |
| 기준 DPS(=물공×1.7) | 450.5 | 지속 화력 기대값 — 검투사 킷+분노의 평균 DPS가 이 근처를 유지해야 함 |
| 플레이어 최대 HP | 1,065 | 분노 피격 충전·자가 유지기 힐 캡의 기준 |
| 잡몹 HP / 공격력 | 1,880 / 263 | 처형 처형보너스·피격 예산 검산 |
| 보스 HP / 공격력 | 75,200 / 658 | 분노 충전 페이스·피격 예산 검산 |
| 피격 예산 | 잡몹 10대 / 보스 스킬 4대 | `combat.md` 5-1 — 검투사 스킬이 이 예산을 훼손하지 않아야 함 |

- **핵심 정합 원칙**: `combat.md` 7장 "기준 DPS = 물공 × 1.7"은 기본 공격 + 스킬 로테이션의 지속 화력이다. **검투사 4종 + 분노 피니셔는 이 로테이션의 일부**로 취급하며, 분노 피니셔의 높은 계수는 낮은 발동 빈도(분노 게이지 축적 필요)로 상쇄되어 평균 DPS가 규격을 크게 넘지 않도록 설계했다. 정밀 지속 DPS는 B-3(스킬 포인트)·C-3(손맛 튜닝)·G3-1 실측에서 확정한다.

## 1. 슬롯 수용 모델 — 15스킬 vs 7슬롯 (설계 결정 + 디렉터 확인 필요)

`jobs.md` 3장은 "직업당 스킬 15개(모험가3 + 1차4 + 2차4 + 3차4)"를 규정하지만, `combat.md` 3장 슬롯은 **6칸(1·2·3·4·Q·E) + 궁극기 R + 우클릭(보조)**로 고정이다. 2차 전직 시 신규 4종이 어디에 들어가는지가 M2에서는 정의된 적 없는 공백이다. 본 문서는 아래 **승계형 교체 모델**로 설계한다.

### 1-1. 승계형 교체 모델 (본 문서 채택안)

`jobs.md` 3장의 애니메이션 제작비 통제 원칙("전직 후에도 기존 모션 재사용 + 이펙트 교체")을 그대로 따라, **2차 스킬 3종이 1차 직업 스킬 3종을 같은 슬롯에서 승계(교체)**한다. 4번째 스킬(분노 피니셔)은 **신규 키를 추가하지 않고** 우클릭의 조건부 파생으로 넣는다.

| 슬롯 | 키 | 1차(전사) | → 2차(검투사) | 승계 방식 |
|---|---|---|---|---|
| 슬롯 1 | 1 | 강타 | **강타 (유지)** | 모험가 공용 — 전 티어 유지 |
| 슬롯 2 | 2 | 질주 | **질주 (유지)** | 모험가 공용 — 전 티어 유지 |
| 슬롯 3 | 3 | 응급 처치 | **응급 처치 (유지)** | 모험가 공용 — 전 티어 유지 |
| 슬롯 4 | 4 | 분쇄 베기 | **검투 선풍** | 슬롯 승계(모션 확장 + 신규 계수/이펙트) |
| 슬롯 Q | Q | 돌격 | **난입 강타** | 슬롯 승계(돌진 모션 재사용 + 그로기 연계 추가) |
| 슬롯 E | E | 결의의 외침 | **혈투의 함성** | 슬롯 승계(포효 모션 재사용 + 방어형→공세형 전환) |
| 우클릭 | 우클릭 | 차지 강타 | **차지 강타 (유지) / 분노 ≥ 50 → 처형 일격** | 조건부 파생 — 분노가 처형 하한(50) 이상이면 우클릭이 피니셔로 대체 |
| 궁극기 | R | 대지 분쇄 | **대지 분쇄 (유지)** | 3차(검성)에서 각성 진화 — 범위 밖 |

- 검투사 활성 슬롯 = 모험가 공용 3 + 검투사 3(슬롯4/Q/E) + 궁극기 R + 우클릭(차지 강타/분노 ≥ 50 시 처형 일격) = **7슬롯 그대로, 신규 키 0개**. `jobs.md` 3장 "3차 각성 = 새 버튼 추가가 아니라 기존 조작의 확장" 철학을 2차에도 선적용한 것.
- **1차 직업 스킬 3종(분쇄 베기·돌격·결의의 외침)은 2차 전직 후 사라진다** — 검투사 승계판으로 대체. 모험가 공용 3종만 남는다.

### 1-2. 대안 (누적 로드아웃) — 디렉터 결정 필요

승계형 대신 "15스킬 전부 보유 + 7개 장착(로드아웃 선택)"도 가능하다. 트레이드오프:

| 축 | 승계형 교체 (채택안) | 누적 로드아웃 (대안) |
|---|---|---|
| 조작 복잡도 | 낮음 (슬롯 배치 불변) | 높음 (로드아웃 UI·교체 규칙 필요) |
| 성장 체감 | "같은 슬롯이 강해진다" (직관적) | "선택지가 늘어난다" (빌드 다양성↑) |
| 제작비 | 낮음 (모션 재사용) | 높음 (버려지는 슬롯 없이 15종 다 살려야 함) |
| M3 목표 정합 | ◎ (변수 최소화 — G3-1 판정 명료) | △ (판정 변수 증가) |

> **디렉터 결정 필요 (D3-A2-1)**: 2차+ 스킬 슬롯 모델을 **승계형 교체**(권장)로 확정할지, **누적 로드아웃**으로 갈지. M3의 목표가 "재미/난이도를 판정 가능하게"이므로 변수를 줄이는 승계형을 권장한다. 로드아웃은 이후 마일스톤에서 빌드 다양성 축으로 별도 도입 여지.

## 2. 분노 게이지 (2차 고유 메커니즘) — `jobs.md` 3장 정의 준수

`jobs.md` 3장 정의: **"분노: 피격·타격 시 충전 → 소모 시 강화 일격"**, 설계 원칙 ②(게이지는 전부 "잘 싸우면 차는" 능동 충전, **시간 충전 없음**). 본 장은 이를 구현 가능한 규칙으로 확정한다.

### 2-1. 기본 규격

| 항목 | 값 | 근거 |
|---|---|---|
| 최대치 | **100** | 직관적 백분율 게이지 |
| 시작치 | 0 (전투 진입·리스폰·거점 휴식 시) | 시간 충전 없음 원칙 |
| 사용 최소치 | **50** (처형 일격 발동 하한) | 게이지 절반 축적 = "언제 터뜨릴까" 판단 시작점 |
| 격노 상태 | 게이지 **≥ 80** 도달 시 자동 진입, **80 미만으로 내려가면 자동 해제** | 처형 하한 50과 간격을 두어 선택을 만든다 — 아래 확정 근거 |

**격노 임계 = 80 확정 (문서 내부 불일치 해소, 2026-07-29)**

초판에서 2-1장 표는 "100(만땅) 도달 시 격노", 2-3장은 "80 이상(격노) 공격력 +12%"로 서로 모순이었다. **80으로 확정**하며 근거는 다음 세 가지다.

- **리듬 근거(주근거)**: 격노 임계가 100이면 "격노 진입"과 "최대 처형 계수(5.0)"가 **같은 순간에 동시 도달**한다 → 100에 닿는 즉시 방출하는 것이 항상 최적이 되어 게이지 상단 구간의 판단이 사라진다. 80이면 게이지가 3개 구간으로 갈라진다: **50~79(약한 처형을 지금 쓸까, 격노까지 참을까)** / **80~99(격노 딜 +12%를 누리며 계수를 더 채우는 창)** / **100(최대 처형)**. 2-3장이 이미 설계한 "지금 터뜨려 리셋 vs 유지해 격노 딜을 누리기" 트레이드오프는 임계 80에서만 성립한다.
- **자기 검산 정합**: 2-5장 잡몹 무리 시나리오의 충전 합계는 +64~72(치명타 가산 포함 약 70~78)로 **100에 미달**한다. 임계 100이면 "무리당 1회 격노"라는 같은 장의 판정이 성립하지 않는다 — 80이어야 문서 내 검산이 일관된다.
- **구현 정합**: C-1(커밋 bf08f62) 구현이 이미 `rage_finisher_min = 50` / `rage_enrage_threshold = 80`이다(`godot\scripts\player\gladiator_skill_data.gd`). 80 확정은 구현 재작업이 0이며, 반대로 100을 택하면 위 두 근거를 잃고 코드까지 고쳐야 한다.
- **해제선**: 구현은 매 변동마다 `현재 분노 ≥ 80`을 재평가한다(`player_rage_module.gd` `_refresh_enrage`) → 전투 이탈 감쇠(2-4장)로 80 미만이 되면 격노가 자동 해제된다. 처형 일격 발동 시에는 전량 소모로 0이 되어 해제된다. 이것이 의도된 규칙이므로 표에 명문화했다.

### 2-2. 충전 규칙 (능동 충전 — 잘 싸우면 찬다)

| 충전원 | 충전량 | 비고 |
|---|---:|---|
| 기본 공격 명중 | **+4** / 명중 | 대검 2타 콤보 각 타 명중 시 |
| 스킬 명중 | **+8** / 캐스트 | 다수 대상 명중해도 캐스트당 1회만(폭주 방지). 검투 선풍·난입 강타 포함 |
| 치명타 명중 | 위 충전량 **×1.5** | 전사는 치명 확률이 낮아(민첩 비주력) 손맛용 소량 가산 |

- **설계 의도**: 피격 충전(+12)이 타격 충전보다 크다는 점이 전사의 "슈퍼아머로 버티며 분노를 쌓는" 정체성을 수치로 표현한다. 회피만 하는 소극적 플레이는 분노가 느리게 차고, 맞으면서 파고드는 공세적 플레이가 격노를 빨리 얻는다 — `combat.md` 8장 "위험을 감수하면 이득" 축과 일관.

## 4. 검투사 스킬 4종 — 상세 규격

### 4-1. 검투 선풍 (슬롯 4, 즉발·광역) — 분쇄 베기 승계

| 항목 | 값 |
|---|---|
| 계수 | **3.0** (일반 스킬 규격 1.8~3.5 상단. 분쇄 베기 2.4 → +25% 승계 강화) |
| 쿨다운 | 9초 (분쇄 베기 7초 → 계수↑에 비례해 상향, `combat.md` 7장 "계수↑=쿨다운↑") |
| MP | 12% |
| 판정 범위 | **자기 중심 360° 원형, 2.2타일** (분쇄 베기 부채꼴 120°/2.0 → 전방위 확장) |
| 타격 판정 | **대상당 1회 (단발 판정, 계수 3.0 전량)** — 판정 창 0.4초 동안 원형 히트박스 유지, 같은 대상 재타격 없음 |
| 모션·이펙트 | **2회전 연출 유지** (회전 애니메이션 2바퀴 + 궤적 2겹) — **연출이며 판정 회차와 무관** |
| 모션 시간 | 선딜 0.3초 / 판정 0.4초(회전 2바퀴 연출) / 후딜 0.4초 (총 1.1초) |
| 슈퍼아머 | 없음 (일반 스킬 — 회전 중 경직 가능) |
| 히트스톱 | 중 (일반 스킬) |
| 분노 충전 | 캐스트당 +8 (다수 명중 무관, 2-2장) |

- **승계 델타**: 부채꼴 120° → 360°로 판정 형태가 바뀌어 "포위당한 검투사가 원을 그리며 쓸어내는" 난전 정체성을 만든다. 다수전 효율이 1차 대비 확연히 오른다.

**"2회전 다단히트" 규격 확정 = 판정 1회 × 계수 3.0 (2026-07-29)**

초판의 "2회전 다단히트(판정 지속 동안 2회 판정)"는 계수 총량과의 관계가 불명확했다(2회 × 3.0이면 규격 상한 3.5를 넘고, 1.5×2회면 총량 3.0). **총량 3.0 유지 + 판정 1회**로 확정하며, "1.5×2회"는 채택하지 않는다. C-1 구현(단발 3.0)이 곧 확정본이다.

| 축 | 판정 1회 × 3.0 (**확정**) | 1.5 × 2회 (기각) |
|---|---|---|
| 다수 대상 명중 보장 | 판정 창 0.4초 + 360° 원형 히트박스가 이미 보장 — 다단히트의 통상적 존재 이유가 성립하지 않음 | 동일(추가 이득 없음) |
| 히트스톱 예산 | 대상 3~4마리 × 중(0.06초) 1회 | 대상 3~4마리 × **2회** → 회전 구간에 히트스톱이 겹쳐 체감 프리즈가 `combat.md` 5-3 "중=0.06초" 프리셋 의도를 초과 |
| 결과 분산 | 일정 (한 번에 확정) | 슈퍼아머가 없어 **1회전 후 경직되면 2회전 판정이 소실** → 같은 입력의 딜이 운에 갈림 |
| 손맛 | "원을 그려 한 번에 쓸어낸다" — 광역 청소기 정체성 | 다단 타격감이지만, 검투사의 다단·강 타격감은 이미 **처형 일격(강 히트스톱)** 이 담당 |

- **결론**: 총량이 같으므로 밸런스 차이는 없고, 판정 1회가 **히트스톱 예산·결과 분산·역할 분담** 세 축에서 우월하다. 다수 대상 명중은 판정 창(0.4초)이 보장하므로 다단 분할의 실익이 없다.
- **연출은 유지**: 회전 애니메이션 2바퀴와 궤적 2겹은 그대로 살린다(8-2장). "보이는 회전 수 ≠ 판정 수"이며, 이는 히트스톱이 한 번만 걸려 오히려 회전 모션이 매끄럽게 이어지는 이점도 있다. vfx-artist는 궤적 2겹을 **판정과 무관한 연출**로 제작한다.

### 4-2. 난입 강타 (슬롯 Q, 이동기) — 돌격 승계

| 항목 | 값 |
|---|---|
| 계수 | **1.5 + 이동** (이동기 규격 1.0~1.5 상한. 돌격 1.3 → +0.2 승계) |
| 쿨다운 | 11초 (돌격 10초 → 소폭 상향) |
| MP | 10% |
| 돌진 거리 / 시간 | 2.5타일 / 0.3초 (돌격과 동일 — 모션 재사용) |
| 판정 범위 | 돌진 경로 직선, 폭 1.3타일 |
| 부가 효과 (잡몹) | 명중 시 넉백 + **기절 0.4초**(돌격 0.3초 → 강화) |
| 부가 효과 (정예·보스) | **그로기 게이지 = 해당 개체 최대치의 25%** 축적 (대상별 각각 25%). 넉백·기절은 슈퍼아머로 무효 |
| 무적 프레임 | 없음 (이동기 공통 규칙) |
| 모션 시간 | 선딜 0.12초 / 돌진(=판정) 0.3초 / 후딜 0.35초 (총 0.77초) |
| 슈퍼아머 | 없음 |
| 히트스톱 | 중 (일반 스킬) |
| 분노 충전 | 캐스트당 +8 |

- **승계 델타**: 돌격의 단순 진입기 → **그로기 축적기**로 역할 심화. 정예·보스의 그로기 게이지(`combat.md` 5-2)를 크게 밀어 올려 **그로기 → 처형 일격**의 딜 콤보를 셋업한다. 검투사의 "붙잡아 처형" 리듬의 시작점.

**그로기 축적량 확정 = 최대치의 25% (절대값 아닌 비율, 2026-07-29)**

초판의 "그로기 게이지 대량 축적"에 수치가 없어 C-1에서 구현이 보류됐다. **비율(최대치의 25%)로 규정**하며 절대 포인트는 두지 않는다.

- **왜 비율인가(소유권·정합)**: 그로기 게이지의 **최대치는 몬스터 측 데이터**다(`combat.md` 5-2는 "타격 누적으로 상승 → 가득 차면 3초 그로기"만 규정하고 최대치를 정하지 않았다). ai-dev가 정예 공용 프레임 구현에서 **정예 HP×6·TTK 약 30초**(`combat.md` 2-1·8-1)로 최대치를 역산하는 중이므로, 플레이어 스킬 문서가 절대 포인트를 박으면 그 확정값과 즉시 어긋난다. **비율로 두면 ai-dev의 최대치가 무엇으로 확정되든 자동 정합**되고, 이후 최대치 튜닝에도 스킬 문서 개정이 불필요하다.
- **25%의 근거(사용 빈도 역산)**: 쿨다운 11초, 정예 TTK 약 30초 → 정예전 1회당 난입 강타 **약 3회**(0초·11초·22초) 사용 가능. 3회 = 최대치의 **75%** → **난입 강타만으로는 그로기를 열 수 없고**, 반드시 기본 공격·검투 선풍의 일반 타격 누적과 합산되어야 게이지가 찬다. 즉 난입 강타는 **그로기를 여는 촉매**이지 단독 개시기가 아니다 — 이것이 "붙잡아 처형" 리듬(진입 → 축적 → 그로기 → 처형)에서 의도한 역할이다. 동시에 1회 25%는 게이지가 눈에 띄게 차오르는 체감을 준다(5% 수준이면 "대량 축적"이라는 서술과 어긋난다).
- **상한 규칙**: 1회 명중당 25%가 상한이며, 경로상 다수 대상 명중 시 **대상별로 각각 25%**(플레이어 이득을 대상 수로 곱하지 않음 — 대상마다 독립 게이지이므로 인플레가 아니다).
- **기절 0.4초의 적용 범위 명시**: `combat.md` 5-2에 따라 정예·보스는 슈퍼아머이므로 **기절·넉백이 무효**다. 따라서 난입 강타의 정예·보스 대상 부가 효과는 **그로기 축적이 전부**이고, 기절 0.4초는 잡몹 전용이다. 초판이 이를 구분하지 않아 "정예에게도 기절이 걸린다"고 읽힐 여지가 있었다.
- **후속 검산 — 완료 (2026-07-31, M3 Phase D 7장): `groggy_gain_ratio` 0.25 유지 확정.** ai-dev 확정 구현(게이지 최대치 = `유효 최대 HP × groggy_gauge_hp_ratio(0.25)`, 일반 타격은 최종 피해량 1:1 축적, 그로기 지속 3.0초, **그로기 중에는 게이지가 전혀 축적되지 않음**)을 기준으로 재검산한 결과다.
  - **난입 강타 1회 = 게이지 최대치의 25% = 지속 화력 1.875초분 = 명목 정예전(30초) 화력의 6.25% ≈ 일반 타격 약 3타분.** 참고 산정의 "약 5타분"은 최대치를 일반 타격 20회분으로 가정한 값이었고, 실제 최대치는 **약 12회분**(30초 ÷ 2.5초/타)이라 난입 강타는 3타분이 된다 — "대량 축적"이라는 서술의 하한은 지킨다.
  - **전투당 그로기 횟수: 2.86회(난입 없음) → 3.39회(현행 0.25)**. 무방비 시간 10.2초 = **무방비 비중 33.9%**(설계 의도 "최대 30%" 대비 +3.9pp). ai-dev 우려였던 "3회 → 4~5회(40%+)"는 **과대 평가**였다 — 난입 강타 쿨다운 11초가 그로기 사이클(약 8.6초)보다 길어 모든 사이클에 캐스트를 넣을 수 없고, 전투 전체로는 3캐스트(총 5.6초분) = 총 축적량의 약 19%에 그친다.
  - **0.20 하향은 무의미**: 무방비 비중을 33.9% → 32.9%(**1.0pp**)밖에 줄이지 않는다. 축적의 **81%가 일반 타격**이므로 난입 강타 비율은 지배 항이 아니다. 실제 유효 레버는 몬스터 측 **`groggy_gauge_hp_ratio`**(0.25 → 0.30이면 30.6%, 0.35면 28.1%)이며, 이 역시 현행 유지로 판정됐다.
  - **3.9pp 초과의 주된 원인은 난입 강타가 아니라 기본 공격 캐이던스**(기준 DPS의 1.23배 → 정예 TTK가 명목 30초 대신 24.5초)다. `combat.md` 8-2에서 캐이던스를 수용 확정했으므로 그로기도 같은 축에서 수용하며, **캐이던스 예약 레버를 나중에 당기면 무방비 비중은 39.0% → 33.9%로 자동 하강**한다.
  - **M3 플레이 범위에서는 이 조합이 재현 불가**하다 — 난입 강타는 검투사(2차 전직 **Lv40**) 스킬이고 구현된 유일한 정예는 **포효 임프장 Lv16**이라, Lv40 검투사가 만나면 TTK가 약 9.9초로 줄어 검산 전제(30초)가 무너진다. **Lv40대 정예 미구현**이므로 G3-1에서 관찰할 수 없고 문서 확정만 가능한 항목이다. G3-1에서는 일반 타격만의 2.68~2.86회 리듬만 확인한다(관찰 항목 **O-7**). 상세 `m3-balance-phase-d.md` 7장.

### 4-3. 혈투의 함성 (슬롯 E, 버프·자가 유지) — 결의의 외침 승계

| 항목 | 값 |
|---|---|
| 효과 | 8초간 ① **흡혈 12%**(가한 피해의 12%를 HP 회복, **1회 발동당 총 회복 상한 = 최대 HP 30%**) ② **분노 충전량 +50%** ③ 슈퍼아머 2초 |
| 쿨다운 | 22초 (결의의 외침 20초 → 소폭 상향) |
| MP | 20% (버프·힐 규격 고정값) |
| 판정 범위 | 자기 자신 (논타겟) |
| 모션 시간 | 선딜 0.4초(포효 모션 재사용) / 즉시 발동 / 후딜 0.3초 (총 0.7초, 시전 중 이동 시 취소) |
| 히트스톱 | 해당 없음 (타격 없는 자가 버프) |
| 분노 충전 | 없음 (버프 캐스트 자체는 명중 아님) |

- **승계 델타**: 결의의 외침(방어형: 슈퍼아머+방어 +20%) → **공세형(흡혈+분노 가속)**으로 성격 전환. 검투사의 "맞으면서 흡혈로 버티고 분노를 폭발시키는" 공격적 생존을 표현한다.
- **`combat.md` 5-4 자가 유지기 규격 충족**: 검투사의 "자가 회복 또는 피해 경감 스킬 최소 1개" 요건을 이 스킬이 충족한다. 흡혈 총 회복은 **최대 HP 30% 하드 캡**(`combat.md` 7장 버프·힐 힐 총량 20~30% 준수)으로, 무한 흡혈로 규격을 넘지 않는다. (1차의 결의의 외침이 승계로 사라지므로, 검투사 단계 자가 유지기 요건은 이 스킬이 단독 승계한다.)

### 4-4. 처형 일격 (우클릭 분노 파생, 분노 소모 피니셔) — 신규

| 항목 | 값 |
|---|---|
| 발동 조건 | **분노 ≥ 50** (이 조건을 만족하면 우클릭이 차지 강타 대신 처형 일격으로 대체된다. 격노(≥80)는 별도의 강화 상태이며 발동 조건이 아니다 — 2-1·2-3장) |
| 계수 | **소모 분노 비례 3.5(50) ~ 5.0(100) 선형** |
| **처형 보너스** | 대상 현재 HP **≤ 25%**면 계수 **×1.5**(잡몹·정예). **보스는 ×1.15로 감쇠** |
| 자원 소모 | 발동 시 **보유 분노 전량** (2-3장) |
| 쿨다운 | 없음 (자원=분노 게이지가 곧 발동 제한. 남발 불가) |
| MP | 0% (분노가 자원이므로 MP 미소모) |
| 판정 범위 | 전방 부채꼴 120°, 2.4타일 (단일~소수 집중) |
| 슈퍼아머 | 선딜~판정 전 구간 유지 (`combat.md` 5-1, 피해는 그대로) |
| 모션 시간 | 선딜 0.35초(대검 치켜듦) / 판정 0.15초 / 후딜 0.5초 (총 1.0초) |
| 히트스톱 | **강 (고정)** — `combat.md` 5-3 "차지 강타·궁극기 = 강" 계열 피니셔로 강 등급 |
| 분노 충전 | 없음 (분노를 소모하는 스킬) |

- **규격 이탈 명시**: 계수 3.5~5.0은 `combat.md` 7장 일반 스킬 상한(3.5)을 초과한다. **근거**: 우클릭 자원 소모형 피니셔로, `m2-warrior-skills.md` 3장 차지 강타(계수 1.6~3.0, "규격 외 별도 슬롯")와 동일한 예외 계열이다. 쿨다운이 없는 대신 **분노 게이지 축적(약 15~22초)이 사실상의 재사용 제한**이므로 평균 발동 빈도는 일반 스킬보다 낮다. 계수 상한 5.0은 궁극기 하한(6.0) 아래로 억제해 **궁극기 대지 분쇄(8.0)의 위상을 침범하지 않는다**.
- **처형 보너스의 밸런스 통제**: 잡몹·정예 대상 HP 25% 이하 ×1.5는 "낮은 HP 적을 처형하는" 손맛이다. **보스는 ×1.15로 감쇠**해 보스전 후반 즉살 방지(패턴 학습형 보스의 딜 체크를 무의미화하지 않도록). 처형 보너스는 대상 HP를 소거할 뿐 **플레이어 피격 수와 무관**하므로 피격 예산 불변이다. 잡몹 마무리에 쓰면 TTK가 소폭 단축되나 발동 빈도(격노 필요)로 상쇄된다.

## 7. 기존 7종과의 시너지·손맛 대비 (2차가 1차 대비 무엇이 달라지는가)

### 7-1. 무엇이 강해지는가

| 축 | 1차 전사 | 2차 검투사 | 강화 방향 |
|---|---|---|---|
| 다수전 | 분쇄 베기 부채꼴 120° | 검투 선풍 360° | 포위 대응력 확 상승 |
| 셋업 | 돌격(진입·기절) | 난입 강타(진입·기절·**그로기 축적**) | 그로기 → 처형 콤보 성립 |
| 생존 | 결의의 외침(방어 버프) | 혈투의 함성(**흡혈**+분노 가속) | 수동 방어 → 능동 흡혈 유지 |
| 버스트 | 차지 강타(우클릭 홀드) | 차지 강타 + **처형 일격**(분노 ≥ 50) | 조건부 초강타 추가, 우클릭 이원화 |
| 자원 축 | MP·쿨다운만 | + **분노 게이지**(격노 딜·처형) | 새 자원 관리 리듬 |

### 7-2. 손맛 리듬이 어떻게 달라지는가

- **1차 리듬**: 쿨다운·MP 관리 + 우클릭 차지로 "무겁게 한 방" — 자원 하나(MP)와 홀드 하나.
- **2차 리듬**: 위에 **분노 순환**이 얹힌다. ① 난입 강타로 진입·그로기 축적 → ② 검투 선풍·기본 공격·피격으로 분노 충전 → ③ 격노 진입 시 공격력 +12%로 딜 강화 → ④ 그로기/저HP 타이밍에 우클릭이 **처형 일격**으로 변해 방출 → ⑤ 리셋. "쌓고 → 격노로 즐기고 → 처형으로 터뜨리는" 사이클이 추가돼, 1차의 정적인 쿨다운 관리보다 **공세적이고 리듬감 있는** 손맛이 된다.
- **모험가 공용 3종(강타·질주·응급 처치)은 그대로 유지**되어 조작 학습 연속성을 지킨다 — 바뀌는 것은 슬롯 4/Q/E와 우클릭의 분노 파생(≥50)뿐.

## 9. 구현 참고 — 데이터 스키마 확장 (gameplay-dev, 코드 생성 아님)

기존 `godot\scripts\player\warrior_skill_data.gd`(단일 스키마 `WarriorSkillData`)를 그대로 재사용하되, 분노 관련 필드 추가가 필요하다. **본 문서는 필요 필드만 명시**하며 구현은 C-1(gameplay-dev) 소관이다.

| 추가 필요 필드 | 용도 | 해당 스킬 |
|---|---|---|
| `rage_gain_on_hit` (기본 4 / 스킬 8) | 명중 시 분노 충전량 | 전 타격 스킬·기본 공격 |
| `rage_cost_min` (50) / `rage_full` (100) | 처형 일격 발동 하한·만땅 | 처형 일격 |
| `execute_hp_threshold` (0.25) / `execute_multiplier` (1.5) / `execute_boss_multiplier` (1.15) | 처형 보너스 | 처형 일격 |
| `lifesteal_percent` (0.12) / `lifesteal_total_cap_percent` (0.30) | 흡혈·회복 캡 | 혈투의 함성 |
| `rage_gain_buff_percent` (0.50) | 분노 충전 가속 | 혈투의 함성 |
| `enrage_attack_buff_percent` (0.12) / `enrage_threshold` (80) | 격노 공격력 버프 진입선 — **80 확정(2-1장)** | 분노 상태(플레이어 컨트롤러) |
| `hitbox_angle_deg = 360` | 원형 광역 | 검투 선풍 (기존 필드로 표현 가능 — 스키마 주석대로 360=원형) |
| **`groggy_gain_ratio` (0.25)** | 명중 시 **대상 그로기 게이지 최대치에 대한 비율** 축적 (4-2장). 절대 포인트가 아니라 비율 — 몬스터 측 최대치(ai-dev 확정)와 자동 정합 | 난입 강타 |

- 검투 선풍의 360° 원형은 기존 `hitbox_angle_deg` 필드(주석: "360=원형 광역")로 표현 가능 — 대지 분쇄와 동일 방식. 신규 판정 형태 코드 불요. **판정은 대상당 1회**이므로 다단 판정 타이머·재타격 방지 집합도 불요하다(4-1장).
- `groggy_gain_ratio`는 **플레이어 스킬 측 필드**이고, 게이지 최대치·일반 타격 축적량·그로기 3초 지속은 **몬스터 측(ai-dev 정예 공용 프레임)** 소유다. 적용 인터페이스는 "대상에게 `최대치 × groggy_gain_ratio` 만큼 축적 요청"으로, 스킬이 최대치를 알 필요가 없게 둔다(결합도 최소).
- 처형 일격은 `SkillType.CHARGE`(우클릭 계열)를 재사용하되 발동 조건을 분노로 전환하거나, 신규 enum값 `RAGE_FINISHER`를 추가할지는 gameplay-dev 판단(스키마 확장 방식 위임).
