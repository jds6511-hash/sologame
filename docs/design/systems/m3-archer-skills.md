## 2. 궁수 정체성·조작감 — 전사와의 손맛 대비

### 2-1. 한 줄 정체성 (jobs.md 2장)

> "차징과 거리 유지(카이팅)의 리듬" — 주스탯 **민첩**, 전용 무기 **활**. 슈퍼아머가 없어 본체는 취약한 대신, 거리를 지배하며 원거리 연사와 **치명타**로 녹인다.

### 2-2. 전사(근접) ↔ 궁수(원거리) 손맛 대비표 — G3-1 판정 축 ②(2직업 차별화)

| 축 | 전사 (M2 기준선) | 궁수 (신규) | 손맛이 갈리는 지점 |
|---|---|---|---|
| 교전 거리 | 초·근접 (1.5~2.2타일) | 원거리 (5~8타일 유지) | "파고드느냐" vs "벌리느냐" — 정반대 리듬 |
| 기본 공격 | 대검 2타 콤보(1.0→1.5), 무거운 두 방 | 활 연사(1.0 단발 반복), 빠른 다발 | 타격 텐션 vs 연사 텐션 |
| 우클릭 | 차지 강타(홀드) — **슈퍼아머로 맞으며 버팀** | 조준 모드(홀드) — **이동 느려지고 무방비, 관통·사거리↑** | 둘 다 "멈춤 리스크"지만, 전사는 슈퍼아머로 상쇄하고 **궁수는 상쇄 수단이 없어 진짜 리스크**다 |
| 회피 | 표준 대시(입력 방향) | **후방 점프**(자동으로 거리 확보) | 전사는 회피로 파고들 수도, 궁수 회피는 카이팅 그 자체 |
| 피격 감수 | 슈퍼아머 스킬로 "맞으면서 딜" | 슈퍼아머 없음 — 붙잡히면 근접 대응기 부족 | 전사 = 맷집 싸움, 궁수 = **거리 관리 실력이 곧 생존** |
| 성장 축 | 힘/체력 (치명타 거의 놀았음) | **민첩 → 치명타**(5장) + 매의 눈(E)으로 크리티컬 창 | 새 성장 변수(G3-1 판정 축 ①) |
| 근접 대응 | 본체가 근접기 | **강타(공용)를 "접근당했을 때의 견제 근접타"로 전용** | 궁수의 최후 견제 — 3-1장 |

### 2-3. 카이팅 리듬 (핵심 루프)

```
정지·조준 사격(딜) → 적 접근/예고 모션 인지 →
  ├ 여유: 후방 점프 회피(Space) 또는 질주(2)로 물러나 재조준
  ├ 붙잡힘 직전: 곡예 사격(Q)으로 굴러 빠지며 사격(거리 재확보 + 딜)
  └ 완전 밀착: 강타(1)로 근접 견제(밀어내기 없음 — 거리는 스스로 벌려야) → 다시 물러남
→ 재조준 사격. 다수전이면 조준 모드(우클릭)로 관통 사격해 일렬 정리
```

- **조준 모드의 텐션**: "멈춰서 관통·장거리 딜(이동 40%)" vs "움직여 생존". `combat.md` 3장의 "서서 쏘느냐, 움직여 피하느냐"가 궁수에서 가장 순수하게 드러난다 — 전사의 차지 강타는 슈퍼아머로 이 텐션을 완화하지만, 궁수 조준 모드는 무방비라 텐션이 그대로 살아 있다.
- **2차 게이지 "집중"(Lv40, M3 범위 밖 — 문맥용)**: `jobs.md` 3장 정의 = "연속 명중 시 충전 → 소모 시 필중 강화샷". M3에서 궁수는 게이지 없이 MP만으로 운용(전사 1차가 분노 없이 MP만 쓰는 것과 대칭). 집중 게이지의 존재는 5장의 "민첩→치명타" 축과 맞물려 2차에서 **확정 치명타(필중)** 경로를 열어 주는 예고편이다. M3 구현 대상 아님.

## 3. 모험가 공용 스킬 3종 — 재사용 명세

전 직업 공용이며 전직 후에도 슬롯 1·2·3에 그대로 남는다. `m2-warrior-skills.md` 4장에서 **최초 확정된 값을 궁수가 그대로 재사용**한다 — 신규 사양·수치 변경 없음. 아래는 재사용 확인 및 궁수 운용 맥락만 기술한다.

| 슬롯 | 스킬 | 재사용 값 (m2-warrior 4장 그대로) | 궁수 운용 맥락 |
|---|---|---|---|
| 1 | 강타 | 계수 1.8 / cd 5초 / MP 8% / 전방 직선 2.0타일 폭 1.0타일 / 중 히트스톱 | **접근당했을 때의 견제 근접타.** 궁수에게 유일한 근접 판정기 — "밀착당하면 강타로 한 번 견제하고 거리를 벌린다". 넉백은 없으므로(m2 4-1 스펙) 거리는 회피·이동기로 스스로 만든다 |
| 2 | 질주 | 순수 이동기(계수 없음) / cd 8초 / MP 10% / 2.0타일 0.25초 / 무적 없음 | 카이팅 재배치의 기본 축. m2 4-2장이 "공용 이동기는 판정 없이 단순하게"로 확정했으므로 궁수에서도 순수 이동 — 원거리 직업과의 정합성이 이미 보장돼 있다 |
| 3 | 응급 처치 | 자기 최대 HP 20% 회복 / cd 15초 / MP 20% / 논타겟 | 전 직업 자가 유지기 요건(`combat.md` 5-4) 충족. 궁수는 슈퍼아머가 없어 이 힐의 가치가 상대적으로 크다 — 카이팅 실패 시의 보험 |

- **강타의 근접 판정에 대한 정합성 판단**: 강타는 근접형(전방 2.0타일)이라 원거리 궁수에게 이질적으로 보일 수 있으나, m2-warrior 4장이 "공용 3종은 전 계열이 **그대로** 재사용"으로 확정했고, 질주(순수 이동)·응급 처치(논타겟 힐)와 달리 강타는 유일하게 판정을 가진 공용기다. 궁수에게는 이를 **근접 견제기**로 재해석(2-2장)해 자연스러운 역할을 부여한다 — 새 사양을 만들지 않는 **최소 델타** 선택이며, "궁수도 밀착당하면 대응할 최소 수단이 있다"는 생존 여지를 제공한다. G3-1 세션에서 손맛이 어색하면 튜닝 관찰 대상(9장) — 방향 변경 아님.

## 4. 궁수 1차 스킬 4종 (Lv10 전직 시 습득)

모든 계수·쿨다운·MP는 `combat.md` 7장 규격 범위 내(6장 대조표에서 검산). 궁수 1차는 게이지 소모가 없다(집중은 2차) → **MP 단일 자원**.

### 4-1. 속사 (슬롯 4, 즉발·3연사)

| 항목 | 값 |
|---|---|
| 계수 | **0.8 × 3발 = 합계 2.4** (일반 스킬 규격 1.8~3.5 중간값) |
| 발사 형태 | 조준 방향으로 화살 3발 **연속 발사**(발 간격 0.08초), 각 화살 **단일 명중(비관통)** |
| 치명타 | **화살마다 독립 치명타 판정**(3회 굴림) — 5장 크리티컬 시너지의 핵심 |
| 쿨다운 | 7초 |
| MP | 10% |
| 사거리 / 투사체 속도 | 5.5타일 / 16타일·초(기본 화살 속도) |
| 판정 범위 | 조준 방향 직선, 폭 0.6타일(화살 히트박스). 3발은 자동 조준(±35° 스냅, 3-1장 QoL) 대상에 집속 |
| 모션 시간 | 선딜 0.2초 / 연사 0.24초 / 후딜 0.25초 (총 0.69초, 연사 중 이동 시 취소 — 캐스팅 규칙) |
| 히트스톱 | 중 (일반 스킬. 개별 화살이 치명타면 그 타격만 강) |

- **버스트 딜 + 치명타 시너지**: 단발이 아니라 3발로 나눠 "명중 수 = 치명타 굴림 수"를 늘렸다 — 민첩 성장(치명타 확률)이 실제 딜 분산으로 체감되게 하는 장치(5장 연계). 다중 화살이나 **단일 직선 집속**이라 광역 zone이 아니다.

### 4-2. 곡예 사격 (슬롯 Q, 이동기 + 투사체)

| 항목 | 값 |
|---|---|
| 계수 | **1.3 + 이동** (이동기 규격 1.0~1.5 + 이동) |
| 쿨다운 | 10초 |
| MP | 10% |
| 이동 | **회피(입력) 방향으로 2.5타일 / 0.3초 구르기** — 이동 방향은 자유, 사격 방향은 마우스 조준(둘 독립) |
| 발사 형태 | 구르는 동시에 조준 방향으로 화살 1발(단일 명중), 16타일·초 / 사거리 5.5타일 |
| 무적 프레임 | **없음**(이동기 공통 규칙 — 회피 Space와 차별) |
| 판정 범위 | 화살 직선 폭 0.6타일 |
| 모션 시간 | 선딜 0.1초 / 구르기(=사격) 0.3초 / 후딜 0.2초 (총 0.6초) |
| 히트스톱 | 중 (일반 스킬 취급) |

- **카이팅 핵심기**: "물러나며 쏜다"를 한 버튼으로. 이동(생존)과 사격(딜)을 동시에 수행해 거리를 벌리면서도 딜 로스가 없다 — 궁수 카이팅 리듬(2-3장)의 심장. Space 후방 점프(무적 있음, 딜 없음)와 역할 분담: 곡예 사격은 무적이 없는 대신 딜·방향 자유가 있다.

## 5. 우클릭 — 조준 모드 (스탠스·홀드)

## 6. 원거리 투사체·조준 파라미터 — 균열 점액 대비 재사용/신규 델타

### 6-2. 신규 델타(궁수 화살에서 새로 필요 — gameplay-dev/ai-dev 구현)

| # | 델타 | 내용 | 균열 점액과의 차이 |
|---|---|---|---|
| 1 | **충돌 레이어/마스크 반전** | 화살은 **몬스터 히트박스**를 맞힌다(플레이어 발사) | 균열 점액은 **플레이어**를 맞힘 — 레이어·마스크만 반전 |

## 7. 민첩 → 치명타 성장 축 (combat.md 6장 연계) — 궁수에서 실제로 작동하는 방식

`combat.md` 6장 데미지 공식의 **치명타 발동 확률 = 5% + 민첩×0.05%(상한 40%), 배율 1.5 고정**. 전사(힘/체력 중심)에서 거의 놀았던 이 축을 궁수가 처음으로 굴린다(M3_PLAN 3-2장 근거 3).

### 7-1. 궁수 민첩·치명타 곡선 (growth.md 2-1 배분으로 산출)

- 산출식: `민첩(L)` = 초기 8 + 모험가 9레벨분(×1.5) + 궁수 (L−10)레벨분(×2.6) = **21.5 + (L−10)×2.6** (`growth.md` 2-1 배분·소급 규칙).
- `치명타 확률(L)` = min(40, 5 + 민첩(L)×0.05).

| Lv | 궁수 민첩 | 치명타 확률(스탯만) | (참고) 전사 민첩 | (참고) 전사 치명타 | 궁수 우위 |
|---:|---:|---:|---:|---:|---:|
| 10 (전직 직후) | 21.5 | 6.08% | 21.5 | 6.08% | 동률(전직 시점) |
| 20 | 47.5 | 7.38% | 31.5 | 6.58% | +0.80%p |
| 40 (2차 전직) | 99.5 | 9.98% | 51.5 | 7.58% | +2.40%p |
| 60 | 151.5 | 12.58% | 71.5 | 8.58% | +4.00%p |
| 80 (3차 전직) | 203.5 | 15.18% | 91.5 | 9.58% | +5.60%p |
| 100 (만렙) | 255.5 | 17.78% | 111.5 | 10.58% | +7.20%p |

- **읽는 법**: 궁수의 스탯만 치명타는 만렙에도 17.8%로 상한 40%에 크게 못 미친다 — 이는 **의도된 설계**다(`growth.md` 4장 "치명타 상한 40%는 랜덤 편차 안전선"). 나머지는 **반지 2개(치명타 옵션) + 매의 눈(E) + 칭호**로 채운다 → 궁수 빌드의 성장 여지를 장비·수집 콘텐츠와 능동 버프에 남긴다.

**40% 도달 구조 정정 (economy-designer 검산 반영, 2026-07-29)**

초판 서술은 "나머지 40%까지는 장비·칭호로 충당"이었으나, `economy-foundation.md` 3-3장의 반지 치명타 옵션 확정 수치로 검산한 결과 **장비만으로는 40%에 닿지 않는다**. 아래가 정확한 구조다 — **본 문서의 수치는 변경되지 않았고 서술만 정정**한다.

| 구성 | 기여 | 성격 |
|---|---:|---|
| 스탯(민첩) — 만렙 | 17.78% | 상시 (7-1장 표) |
| 반지 2개 (Lv100 S급, `economy-foundation.md` 3-3) | +7.40%p (3.70 × 2) | 상시 — **장비 단독 상한은 여기까지** |
| **장비까지의 상시 합계** | **25.18%** | 상시 최대 |
| 매의 눈 (E, 4-3장) | +15.00%p | **8초 발동 창 한정** |
| 발동 창 합계 | **40.18% → 상한 40% 도달** | 버프 창에서만 |
| 칭호 (`growth.md` 7장) | 소량 (개별 효과 소소, 별도 축) | 상시 — 상한 여유분 소진용 |

- **결론**: 궁수의 치명타 정체성은 "상한에 상주한다"가 아니라 **"상시 약 25% + 매의 눈 창에서 40%"의 이중 구조**다. 반지 MAX(3.7%p)를 40% 도달용으로 올리는 것은 `economy-foundation.md` 2-2장 **TTK ±40% 검산의 입력을 바꾸는 일**이라 채택하지 않았다(경제 측 판단, 본 문서도 이를 수용).
- 4-3장 매의 눈의 "상한 40% 안에서 작동" 서술은 위 구조와 일관되며 변경 없다(Lv20 기준 7.4%→22.4%). 7-2장의 저레벨 체감 장치 설명도 그대로 유효하다 — 오히려 **매의 눈이 만렙 엔드게임에서도 상한 도달의 필수 조건**이라는 점에서 이 스킬의 위상이 초판 서술보다 높아진다.
- **전사 대비**: 동일 레벨에서 궁수 치명타가 전사보다 항상 높고 격차가 레벨에 따라 벌어진다(Lv40 +2.4%p → Lv100 +7.2%p). "궁수는 크리티컬 직업"이라는 정체성이 스탯 곡선으로 뒷받침됨.

### 7-2. M3 플레이 구간(Lv10~20대)에서 치명타를 "느끼게" 하는 장치

저레벨 스탯 치명타는 6~8%로 낮아 방치하면 크리티컬이 잘 안 논다. 이를 능동 스킬로 보완한다:

| 장치 | 효과 | 크리티컬 체감 |
|---|---|---|
| 매의 눈 (E, 4-3장) | 치명타 +15%p, 8초 | Lv20 기준 7.4% → **22.4%**(약 3배). 8초 폭딜 창 |
| 속사 (슬롯 4, 4-1장) | 3발 = 치명타 3회 굴림 | 단발보다 "이번엔 크리 떴다"가 자주 발생 → 체감 빈도↑ |
| 관통 폭사 (R) | 관통한 적마다 개별 굴림 | 일렬 다수에 크리티컬 다발 가능 |
| (2차 예고) 집중 게이지 | 필중 강화샷 = **확정 치명타** | Lv40+ 콘텐츠 — 확정 크리 경로로 축 완성 |

- 결론: M3 구간에서 궁수의 치명타 정체성은 **스탯(느리게 성장) + 매의 눈·속사(즉시 체감)의 이중 구조**로 살아난다. G3-1 판정 축 ①(레벨업 성장감)에 "치명타가 실제로 자란다"는 새 변수를 더한다.

### 7-3. DPS 정합 — 기준선 이탈 여부

- **공격력**: 궁수 물공 = 활 공격력 + 민첩×2. Lv10에서 전사와 동률(67, 모험가 균등 성장), Lv100에서 궁수 679 vs 전사 661(**+2.7%**, 민첩 성장 2.6 > 힘 2.5). 궁수 기본 공격력이 근소 우위지만, 원거리 특유의 손실(투사체 이동 시간·조준 모드 이동 페널티·카이팅 중 딜 로스)로 실효 지속 DPS는 근접과 근사하게 상쇄되도록 설계했다.
- **기준 DPS 유지**: `combat.md` 7장 `기준 DPS(L)=물공×1.7`(기본 공격 + 스킬 로테이션 블렌드)이 `8장 몬스터 HP 곡선(TTK 5초)`의 입력이다. 궁수 기본 연사(1.0×약 2.0발/초)와 위 스킬 4종은 전사와 동일 규격 내에 있어 **블렌드 지속 DPS가 1.7×물공 근처에 유지 → 8장 몬스터 곡선 재산출 불요**. 궁수의 근소한 물공 우위(+2.7%)와 치명타 우위는 원거리 손실분과 상쇄되는 방향이며, **최종 DPS 패리티는 G3-1 세션 튜닝 대상**(정상 절차).
