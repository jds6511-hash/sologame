# M6 경제·장비 후보 통합 실행 계획

- 날짜: 2026-09-30 / 담당: Codex
- 설계: [M6 통합 계약](m6-economy-equipment-loop.md)
- 변경 이력: 디렉터의 큰 묶음 진행 지시에 따라 보관된 M6 설계를 재개한다.
- 실행: Codex 직접 구현. 기존 승인 범위 안에서 진행하며 V5 기본 배포는 별도 검토한다.

목표: 전 레벨 공급·거래·장착·스탯·구 저장 보존을 같은 후보 모델로 연결하고 검증한다. 기존 V4 실행과 저장 경로는 후보 검증 중 유지한다.

1. `scripts/economy/`의 명시 공급 카탈로그·가격·장착 규칙·순수 스탯 합성, `test/economy/`의 전 레벨/직업 회귀를 작성한다. 기존 ID 의미는 유지한다.
2. 거래와 장착 상태 변경을 성공 때만 확정하고, 신호 재진입·골드/수량 상한·가방 포화·보존품 회수를 검증한다.
3. V1~V4 원본 검증 후 V5 후보 변환, 초과 보관·장비 조건·최대치·멱등·파일 재실행 검사를 연결한다. 기존 검증을 V5 규칙으로 바꾸지 않는다.
4. 후보 UI·런타임 연결과 기존 V4 회귀를 검사한다. 공급/밸런스 차이가 설계의 제품 전환 조건을 충족하는지 먼저 측정한다.
5. 변경 파일·실행 결과·미검증·커밋을 통합 보고한다. 단순 보완만으로 리뷰를 재요청하지 않는다.

게이트: G3는 기능 부분 통과/체감 판정 대기이며 개발 진행 허용. G4 기준6의 디렉터 저장·종료·재실행 판정은 미기록이다. G5 MQ01~05 기능 증거는 확보됐으나 전체 콘텐츠/사람 안내 체감 승인으로 확대하지 않는다.
