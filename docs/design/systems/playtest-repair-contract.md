## 1. 아이템 소유권과 줍기

바닥 아이템은 플레이어의 충돌 레이어 2를 감지한다. 가까이에서 F를 누르면 가방에 넣고, 성공했을 때만 바닥 오브젝트를 제거한다. 가방이 차면 아이템을 그대로 남긴다.

장비 교체는 **가방에서 새 장비를 한 개 꺼낸 뒤 기존 장비를 되돌려 넣을 공간이 있는지** 먼저 검사한다. 새 장비 중첩이 남아 가방 칸이 비지 않는 경우도 계산한다. 기존 장비와 같은 ID의 중첩이 있으면 그 칸을 사용할 수 있다. 장비 해제는 가방에 반환할 수 있을 때만 장착 상태를 지운다. 실패하면 장비·수량·스탯을 유지하고 가방 포화 시그널만 발신한다. 반지 두 슬롯에도 같은 규칙을 적용한다.

0개·음수 수량 버리기는 거절한다. 소유권 보존은 이후 장비 UI와 저장 기능이 연결돼도 유지해야 할 불변 조건이다. M3의 가상 B급 장비 기반 전투 성장 규칙은 별개이며, 이번 수정으로 실제 장착 스탯을 추가 합산하지 않는다.

## 2. 5번 퀵슬롯의 회복 포션

퀵슬롯 지정 UI가 없는 현재 버전에서는 **보유 중이고 레벨 제한을 충족하는 회복 포션 중 회복량이 낮은 종류부터** 사용한다. 같은 회복량은 아이템 ID 순으로 결정한다. 상급 포션을 먼저 주웠어도 하급 재고부터 소비하며, 하급이 소진되면 다음 사용 가능한 종류로 넘어간다. HUD에는 선택된 종류의 수량과 이름·회복량 툴팁을 표시한다. 6번 퀵슬롯 배정은 후속 범위다.

포션 종류·양수 회복량·사용 레벨·재고를 확인한 다음 기존 쿨다운과 보스전 사용 제한을 검사한다. 성공 시 아이템 데이터의 고정 회복량을 적용하고 1개 차감한다. 재고 없음·쿨다운·사망·레벨 부족 등 실패에서는 차감과 회복 모두 없다. 최대 HP를 넘는 부분은 버린다. 최대 HP 상태에서 사용하면 기존 정책대로 1개를 소비한다.

**일반 플레이의 최대 HP 30% 기본 회복은 폐기한다.** 하급 포션은 100, 중급은 320이며 이후 티어도 경제 문서의 고정량을 따른다. 스탯 컴포넌트의 무인자 비율 회복 API는 기존 독립 테스트·디버그 호환용으로만 남고, 일반 키 입력과 인벤토리 사용 경로에서는 호출하지 않는다. 인벤토리에 성장 노드가 없는 단독 구성은 Lv1로 취급한다.

## 3. 전직과 강화 포인트

전직 후 로드아웃에 남아 있는 스킬은 강화 레벨을 유지한다. **교체돼 더는 사용할 수 없는 스킬은 레벨 1로 초기화하고 실제 지출한 포인트 전액을 돌려준다.** 다른 이름의 상위 스킬은 새로 강화한다. 일반·궁극기의 비용 차이를 임의로 환산하거나 승계하지 않는다. 같은 스킬이 여러 슬롯에 있어도 중복 환급하지 않는다.

강화할 때 스킬별 실제 지출 장부를 기록한다. 환급액은 현재 비용표로 다시 계산하지 않는다. 따라서 비용 데이터가 조정돼도 과거 투자 이상을 환급하지 않는다. 전직 보너스 +2는 환급과 별개이며 전직 자격 검증 후 한 번만 지급한다. `잔여 + 사용 = 총 획득`을 보존한다. 전직 환급은 게임이 강제한 스킬 교체의 보상이므로 무료다. 사용자가 임의로 선택하는 유료 초기화와 구분한다.

기존의 **총 105포인트 대 누적 스킬 풀업 118포인트** 비교는 교체 전 스킬까지 동시에 강화할 수 있다고 보는 계산이므로 빌드 선택의 증거로 사용하지 않는다. 지급·강화 단가는 유지하고, 최종 직업에서 동시에 사용할 수 있는 스킬 목록을 기준으로 빌드 예산을 다시 검증한다. 미구현 3차 직업의 최종 비용은 확정된 수치처럼 쓰지 않는다.

현재 스킬 식별자는 기존 표시명 기반이다. 저장 기능 구현 전 안정적인 스킬 ID와 **강화 레벨·실제 지출 장부·잔여/사용 포인트**의 일관된 저장·이관 규칙을 확정해야 한다. 이번 수정은 저장 시스템 구현이나 기존 저장 마이그레이션 완료를 뜻하지 않는다.

## 4. 전투와 미니맵의 실행 계약

하나의 적에 대한 사망 효과 구독은 한 번만 연결하고, 사망 순간의 위치에서 효과를 재생한다. 공격할 때마다 현재 위치를 인자로 묶어 새 구독을 만들지 않는다.

히트스톱이 시간 배율을 0으로 유지하는 동안에는 `CharacterBody2D.move_and_slide()`를 호출하지 않는다. 위치·속도의 유한성 복구는 그대로 수행하고, **양수 시간 배율과 양수 물리 델타**일 때만 이동 계산을 실행한다. 플레이어와 몬스터 6종 모두에 적용한다. 기존 히트스톱 길이·쿨다운·복원 정책은 유지한다.

몬스터 기본 클래스는 씬 진입 시 `monsters` 그룹에 등록한다. 미니맵과 자동 조준은 같은 실체를 참조한다. 미니맵은 사망·삭제 예정 개체를 제외하고, 재스폰한 개체는 정상 표시한다. 지형 미니맵·NPC·퀘스트 마커는 후속 범위다.

## 5. 검증과 범위

기존 실행의 바닥 아이템 회수 실패, 빈 가방 회복, 반복 타격 오류, 미니맵 적 표시 누락, 비유한 벡터 경고를 재현한 뒤 같은 실제 월드 검사로 비교한다. 장비 포화 교체·해제, 포션 실패 시 보존, 전직 강화 유지·환급, 반복 전직 거절은 자동 회귀 테스트로 확인한다.

재실행 도구: [월드 입력 검사](../../qa/tools/runtime_playtest_2026_09_11.gd). 전체 테스트는 `godot --headless --path godot -s addons/gut/gut_cmdln.gd -gdir=res://test -ginclude_subdirs -gexit`를 사용한다. 최신 검사 수치와 실행 환경은 진행 현황에 기록한다. 재미·손맛·장시간 성장 페이스·G3 디렉터 승인은 별도다.
