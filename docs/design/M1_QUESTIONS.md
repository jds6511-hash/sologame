# M1 기획 질문 목록

작성일: 2026-07-15
출처: 외부 검토 의견에서 추출. M1(기획 기반) 단계에서 각 담당 에이전트가 안을 만들어 디렉터 승인을 받는다.
확정된 전제: 싱글플레이 전용, PC(Windows), 배포 없음 — 멀티/PvP/서버/경매장/수익 모델 질문은 제외했다.

## 0. 최우선 결정 (다른 모든 시스템의 전제)

- [ ] **전투 방식**: 실시간 액션 vs 턴제 — 담당: systems-designer가 양쪽 안 제시, 디렉터 결정

## 1. 세계관 — narrative-designer

- [ ] 3종족(인간/엘프/드워프) 간 관계 — 대립 구도, 계급과 종족의 연동 여부
- [ ] 세계관 톤(밝은 판타지 vs 다크 판타지), 시대적 배경
- [ ] 마법 체계가 로어 차원에서 존재하는지 (원리/제약)
- [ ] 왕국이 하나인지 여러 개인지, 국가 간 정치/전쟁 요소
- [ ] 스토리 반전 설계 (spoilers\에만 기록)

## 2. 직업 시스템 — systems-designer

- [ ] 최대 레벨과 전직 단계별 레벨 구간 (예: 모험가 1~10, 1차 11~40, …)
- [ ] 직업 10개 목록과 히든 직업 2개의 해금 조건
- [ ] 전직 초기화(되돌리기) 가능 여부
- [ ] 직업별 무기/장비 제한
- [ ] 역할군(탱커/딜러/힐러) 구분 여부 — 싱글플레이이므로 동료 NPC/펫 편성과 연동해 검토

## 3. 퀘스트 — quest-designer

- [ ] 퀘스트 유형 다양성 (토벌/채집/호위/탐사/제작 등)
- [ ] 반복 퀘스트(일일/주간) 존재 여부
- [ ] 선택지 분기 — 플레이어 선택이 결말/반전에 영향을 주는지 (narrative-designer와 협의)

## 4. 명성·영지 — systems-designer + economy-designer

- [ ] "계급 사회"(세계관)와 "명성"(수치) 시스템의 관계 정의 — 같은 것인지 별개인지
- [ ] 도시 하사 이후의 엔드콘텐츠 (영지 확장 등)
- [ ] 영지 관리 콘텐츠 구체화 (건설/세금/치안/몬스터 침공 방어 등)
- [ ] 명성 하락 요소 (범죄, 퀘스트 실패 등)

## 5. 아이템 — economy-designer

- [ ] 강화/제작 시스템 존재 여부
- [ ] 내구도 시스템
- [ ] 세트 아이템 개념

## 6. 수집 콘텐츠 — systems-designer

- [ ] 펫 획득 방식(포획/부화/구매)과 전투 참여 여부
- [ ] 칭호 100개 — 스탯 효과 vs 순수 장식
- [ ] 도감 완성 보상(업적) 존재 여부

## 7. 시간·이벤트 — systems-designer

- [ ] 낮/밤이 NPC 스케줄, 몬스터 출현, 상점 운영에 영향을 주는지
- [ ] 게임 내 1년 길이, 계절 시스템 존재 여부
- [ ] 왕국 이벤트 종류 목록 (플레이 중에만 진행되는 싱글 콘텐츠로 확정됨)

## 8. 기본 기능 — ux-designer + systems-dev

- [ ] UI/UX 목록: 인벤토리, 맵/미니맵, 퀘스트 저널
- [ ] 캐릭터 커스터마이징 여부
- [ ] 튜토리얼/온보딩
- [ ] 옵션 (사운드, 접근성 등)

## 9. 콘텐츠 배분 — producer

- [ ] 200시간 목표의 대략적 배분 (메인퀘스트 vs 서브퀘스트 vs 파밍/수집 비중)
